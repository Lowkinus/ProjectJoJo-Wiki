CLIENT OPTIONS & SANDBOX

Stand Targeting Mode

Mouse / Pointer 按光标方向 • Facing Direction 按角色朝向 • Controller Aim 使用手柄攻击/瞄准轴，进入死区时回退到角色朝向。

例：使用 Project Viewpoint 又不想依赖可见光标时，Facing Direction 会让攻击跟随角色朝向；前方墙体和身体仍会阻挡。

HUD / Personal Audio

Normal / Minimal / Hidden；透明度 20–100%，缩放 70–150%，个人 Project JoJo 音量 0–100%。这些是玩家个人偏好，不改变服务器平衡。

HARVEST Search、ATUM 小游戏、Heaven's Door Book/Command 等必要玩法界面，即使被动 HUD 隐藏也仍可使用。

Super Arrow

默认关闭。关闭时替身之箭从已加载 Stand Pool 随机抽取；开启后使用 Arrow 会显示当前真正注册的替身选择列表，包括已启用的官方 Addon。

重要：Super Arrow 只是把随机改成直接选择，不会让 Arrow 无限使用；除非同时开启 Infinite Stand Arrow，否则仍是 3 次成功使用。

Arrow Drop Multiplier

控制替身之箭出现频率。默认 1x 时僵尸基础掉落约 1/250，同时也可在世界战利品中出现。

Stand Damage

调整整个世界/服务器的替身总体伤害，不需要逐个技能修改。

Stand Level System

开启 = 每个替身独立保存 Lv.1–100；关闭 = 替身以完整强度运行，但已保存进度仍保留。

例：Star Platinum Lv.70 与 The World Lv.20 是两条独立进度；换替身不会删除 SP 的 Lv.70。

Give Stand Arrow on Join

可让玩家加入时直接拿到 Arrow，适合不想让整队在开始使用 Mod 前先刷箭的服务器。

Infinite Stand Arrow

普通 Arrow 成功使用三次：3/3 → 2/3 → 1/3 → 消失。开启后成功使用不再损失 Condition。

Reset Options / Keybinds

Reset Visual / Audio / Targeting 重置 HUD、透明度、缩放、个人音量和瞄准方式，不动按键；Reset Keybinds 单独恢复 Caps Lock 与技能 1–4。

共享战斗规则

进入尸群前必须知道

DIRECTIONAL FIRST-CONTACT

技能按真实射程检查攻击线上的第一个有效接触。把鼠标指得更远不会让攻击穿过前方身体或墙。

BARRAGE CLASH

支持的攻击型 Barrage 在距离足够近、双方确实互相面对/瞄准时会碰撞；碰撞的 hit 会先互相抵消。

BARRAGE GUARD

支持的 Barrage 会形成前方防线，可挡住 TW Knife、SC Rapier Shot、CD Glass 等指定投射物；侧后方和 AOE 使用不同规则。

TIME STOP

SP 停时 5 秒、TW 9 秒。被冻结的角色、延迟伤害与移动投射物会在时间恢复后继续。

TIME STOP vs TIME ERASE

两套时间系统不会自由叠加。若 Erase 先开始，进入的 Stop 时长会先抵消剩余 Erase，再把剩余部分变成真正的停止时间。

SUMMONED STAND DEFENSE

已注册替身处于召唤状态时，替身使者受到的净伤害降低 33%。这不是无敌。

PvP / SAFETY

玩家 HP 伤害尊重 Project Zomboid PvP/Safety；部分 Utility/CC 有独立规则，Pull、Freeze、位移前请先看对应替身页。

VEHICLE / WORLD SAFETY

攻击仍尊重车辆与世界碰撞，同时有 safeguard 防止高频替身 hit 把不支持的车辆/custom object 状态打坏。
