PROJECT JOJO — 完整系统指南

Singleplayer / Host / Multiplayer 共用规则：替身之箭、瞄准、Barrage、时间系统、成长、PvP 与 Official Addons。

当前 Mastery：LV.1 = 50% Damage，LV.100 = 120%；新 XP 曲线约 1,059 次 Stand 击杀，许多技能会获得基于等级的 cooldown mastery。打开完整冷却表 →

1) STAND ARROW

默认僵尸掉落约 1/250。一支 Arrow 有 3 次成功使用：3/3 → 2/3 → 1/3 → 移除。Super Arrow 把随机抽取改为已加载替身选择；Infinite Stand Arrow 防止 Condition 损失。

2) CONTROLS / CHARGE

CAPS LOCK 召唤/收回；1–4 使用技能。许多技能有 Tap/Hold：SP/TW Skill 4 = Time Dash / Time Stop，KC Skill 4 = Time Dash / Time Erase。

3) TARGETING / FIRST CONTACT

支持 Mouse、Facing Direction、Controller Aim。输入模式不会绕过碰撞或 first-contact 规则。

4) BARRAGE CLASH / GUARD

支持的攻击型 Barrage 可以 Clash 并互相消耗 hit。SP/TW/CD/SC/KC 拥有前方 Barrage Guard，可挡 TW Knife、SC Rapier、CD Glass 等支持的投射物；这不是 360° 免疫。

5) TIME STOP

SP 停时 5 秒；TW 9 秒。角色、动画与支持的投射物被冻结；延迟伤害在时间恢复后结算。Core .282+ 加入硬动画冻结、incoming-damage firewall 与 MP projectile temporal parity。

6) TIME STOP vs TIME ERASE

时间能力不会自由叠加。已有 Time Erase 会按 temporal authority 规则消耗进入的 Time Stop 时长。KC Time Erase 持续 10 秒；LV100 时 Skill 4 cooldown 为 20 秒。

7) STAND LEVEL / MASTERY

每个替身分别保存 LV.1–100；只有 Stand zombie kill 给 EXP。LV.1 = 50% damage，LV.100 = 120%。基础 cooldown 会随等级逐渐插值到各技能自己的 Mastery 目标。重抽替身不会清除旧进度。

8) SUMMONED STAND DEFENSE

已注册替身处于召唤状态时，主人获得 33% NET damage reduction；不是无敌。

9) PvP / SAFETY

HP 伤害尊重 Project Zomboid PvP/Safety；Time Stop、THREE FREEZE、Space Pull、Epitaph 与 Official Addon 指令等 Utility/CC 有独立规则。

10) CLIENT OPTIONS / SANDBOX

Client：Targeting Mode、HUD mode、opacity、scale、个人音量与 keybind。Sandbox：Arrow Drop、Stand Damage、Stand Level、Arrow on Join、Infinite Arrow、Super Arrow 与 addon-specific settings。
