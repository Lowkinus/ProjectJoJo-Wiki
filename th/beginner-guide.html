BUILD 42+SP / HOST / MPCORE v0.23.0.250
01 • STAND ARROW

ศรหาได้จากไหน?

ซอมบี้มีโอกาสดรอปพื้นฐานประมาณ 1 / 250 และยังเจอในกล่องตามโลกได้ด้วย ถ้าจะตั้งใจหา ให้ลองพวกโรงรถ กล่องเครื่องมือ ร้านช่างหรือชั้นช่างก่อน เพราะน้ำหนักดีกว่ากล่องทั่วไป ส่วนของในรถมีได้ แต่ตั้งใจให้หายากกว่า

02 • USE THE ARROW

ปกติสุ่ม — เปิด SUPER ARROW แล้วเลือกได้

ศรใช้ Condition ของเกมตรง ๆ: 3/3 → 2/3 → 1/3 → หาย และจะเสีย Condition หลังระบบมอบ Stand สำเร็จแล้วเท่านั้น ค่าเริ่มต้นยังสุ่ม Stand ตามปกติ

เจ้าของโลก/เซิร์ฟเวอร์สามารถเปิด Super Arrow ใน Sandbox ได้ เมื่อเปิดแล้ว การใช้ Stand Arrow จะขึ้นรายชื่อให้เลือกแทนการสุ่ม รายชื่อสร้างจาก Stand ที่ลงทะเบียนและโหลดอยู่จริง ดังนั้นถ้าเปิด Official Addon อย่าง ATUM, HARVEST หรือ HEAVEN'S DOOR ตัวนั้นจะเข้ารายชื่อให้อัตโนมัติ แต่จะไม่แจก Stand จาก Addon ที่ไม่ได้ติดตั้ง/เปิดใช้งาน

Super Arrow ไม่ได้ทำให้ศรใช้ไม่หมด Condition ยังลดตามปกติ เว้นแต่เปิด Infinite Stand Arrow เพิ่มด้วย

03 • CONTROLS

เรียก Stand แล้วกดอะไรต่อ?

Caps Lock = เรียก / เก็บ Stand
1 / 2 / 3 / 4 แถวบน = สกิล

หลายตัวมีท่าแบบ กดสั้น กับ ชาร์จเต็ม ที่คนละอย่างกันเลย ตัวอย่างเช่น Time Dash → Time Stop, The Hand Dash → Pull และ Killer Queen First Bomb → SHA

ปุ่มและค่าการแสดงผล/การเล็งส่วนตัวของ Project JoJo อยู่ที่ Options → Mods → Project JoJo

04 • STAND LEVEL

Lv.1 ยังไม่ใช่พลังเต็ม

แต่ละ Stand มีเลเวลของตัวเองตั้งแต่ 1–100 ตอน Lv.1 จะอยู่ประมาณ 50% ของดาเมจบาลานซ์ แล้วค่อย ๆ ขึ้นจนเต็มที่ Lv.100 ฆ่าซอมบี้ด้วย Stand จริงจะได้ EXP และสุ่ม Stand ใหม่ไม่ลบ Progress ของตัวเก่า

ระหว่างเรียก Stand ที่ลงทะเบียนอยู่ เจ้าของยังได้รับ ดาเมจสุทธิลดลง 33%

05 • TARGETING MODE

ไม่อยากใช้เมาส์เล็งก็ไม่ต้องใช้

เข้า Options → Mods → Project JoJo → Stand Targeting Mode แล้วเลือกได้ 3 แบบ:

  • Mouse / Pointer — ค่าเริ่มต้นแบบเดิม สกิลใช้ทิศตามเมาส์
  • Facing Direction — ไม่ใช้ตำแหน่งเมาส์เป็นทิศโจมตี แต่ให้ Stand ออกท่าไปทางที่ตัวละครกำลังหันหน้า เหมาะกับคนเล่นคีย์บอร์ด/จอย หรือเล่นมอดกล้องแนว immersive อย่าง Project Viewpoint ที่ซ่อนหรือไม่อยากพึ่งเคอร์เซอร์
  • Controller Aim — ใช้แกนเล็ง/Attack Indicator ของจอยใน Project Zomboid โดยตรง ถ้าอนาล็อกอยู่ใน dead-zone จะ fallback ไป Facing Direction

เปลี่ยนโหมดแล้วไม่ได้กลายเป็น auto-lock ทะลุทุกอย่าง ระบบยังใช้ Directional First-Contact: สกิลใช้ระยะจริง ตัวหรือจุดปะทะแรกตามแนวโจมตีโดนก่อน และกำแพง ประตู หน้าต่าง รถ ยังบังท่าที่ควรโดนบัง

06 • BARRAGE

รัวหมัดตามโหมดเล็งที่เลือก

Mouse Mode จะหันตามเมาส์, Facing Direction จะหันตามตัวละคร และ Controller Aim จะตามแกนเล็งจอยระหว่างรัว ระบบเก็บ contact เก่าไว้ประมาณ 240 ms ตอนมีช่องว่างสั้น ๆ และเฟรมช้าอาจชดเชยได้สูงสุด 3 hit ต่อ update

ถ้า Barrage โจมตีสองฝั่งชนกันในระยะและหันเข้าหากัน ก็เข้า Barrage Clash ได้

07 • BARRAGE GUARD

ใช่ บาง Stand ปัดกระสุนได้

SP / TW / Crazy Diamond โหมดโจมตี / Silver Chariot / King Crimson เปิดแนวบังด้านหน้าระหว่าง Barrage ได้ กว้างรวมประมาณ 2.5 ช่อง

กระสุนต้องวิ่งผ่านแนวบังจริงจากด้านหน้า ถ้ามาจากข้างหรือหลังยังโดน และพวกระเบิด ไฟพื้นที่ หรือ THREE FREEZE ไม่ใช่ของที่จะปัดด้วยหมัดได้

08 • HUD / เสียงส่วนตัว

ปรับหน้าจอให้เหมาะกับตัวเอง

หน้า Project JoJo ใน Mods เลือก Stand HUD Normal / Minimal / Hidden, HUD Opacity, HUD Scale และ Personal Project JoJo Volume ได้แยกต่อผู้เล่น ไม่เปลี่ยนบาลานซ์ของ Server

Minimal เหลือชื่อ Stand + Cooldown ของสกิล 1–4 ส่วน Hidden ซ่อน Passive HUD แต่หน้าจอที่จำเป็นต่อการเล่นอย่าง ATUM Minigame และ HARVEST Search Command ยังเปิดได้

09 • RESET SETTINGS

ปรับเละแล้ว? รีเฉพาะส่วนที่ต้องการได้

Reset Visual / Audio / Targeting คืน HUD Mode, Opacity/Scale, Personal Volume และ Targeting Mode เป็นค่าเริ่มต้นโดยไม่ยุ่ง Keybind

Reset Keybinds แยกอีกปุ่ม คืน Caps Lock และ 1 / 2 / 3 / 4 แถวบน

10 • PVP / SAFETY

Safety กันดาเมจ แต่ Utility บางท่ามีกฎแยก

ดาเมจเลือดจาก Stand ยังเคารพ PvP/Safety ของ Project Zomboid แต่ท่าที่ไม่ได้ทำ HP damage ตรง ๆ บางตัวมีพฤติกรรมของมันเอง เช่น THREE FREEZE, Space Pull, Epitaph

ถ้าจะเล่นกับเพื่อน แนะนำให้อ่านหน้าของ Stand ตัวเองก่อน โดยเฉพาะตัวที่มี CC, Pull, Time หรือกับดัก

แค่นี้ก็เริ่มเล่นได้แล้ว
ถ้าจะเอาระบบแบบละเอียดจริง ๆ ไปหน้าคู่มือระบบ ส่วนคอมโบกับวิธีเล่นอยู่หน้า Stand แต่ละตัว
คู่มือระบบเต็ม →Targeting, Time Stop / Erase, PvP, Guard, Sandbox และระบบกลางทั้งหมดเลือก Stand →ดูสกิล ค่าสถานะ กลยุทธ์ และคอมโบของ Stand ปัจจุบัน
