SKILLS & MECHANICS

SPEED GAUGE

Idle 0.1/s · Walk 1/s · Run 11/s · Sprint 20/s

Real movement replenishes Speed quickly. Use movement between costly sword attacks.

ARMOR OFF — HOLD CAPS LOCK

Drain 5 Speed/sec · Clone damage 50%

While summoned, full-hold CAPS LOCK to activate Armor Off. Its cooldown blocks only reactivation, never normal Summon/Dismiss. Cooldown is 90s plus active time, with cleanup before dismiss.

Skill 1 — STAB

CD 0.22s · Range 3.1

Fast single-target rapier poke; no Speed cost.

Skill 2 — RAPIER RUSH

CD 3s · Range 3.4 · Cost 18

Fast multi-hit sword sequence; spend Speed for concentrated pressure.

Skill 3 — CIRCLE SWEEP

CD 3.5s · Cost 25

Wide swing against close surrounding threats.

Skill 4 — RAPIER SHOT

CD 5.2s · Range 8.2

Ranged rapier projectile; supported Barrage Guard can intercept it.

ARMOR OFF COOLDOWN FIX

While Armor Off is cooling down, CAPS LOCK can still summon or dismiss Silver Chariot. Only full-hold Armor Off reactivation remains unavailable. This is independent from regular Stand control.
