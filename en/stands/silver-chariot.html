PLAYSTYLE • Fast sword fighter • Speed Gauge • Armor Off

SILVER CHARIOT

A movement-driven sword Stand. Speed Gauge refills much faster while running/sprinting, and Armor Off can be used to push its combat tempo further.

Core v0.23.0.322 • Armor Off dismiss-safe
DifficultyMedium
Speed max100
Rush cost18
Sweep cost25

SPEED GAUGE

Idle 0.1/s • Walk 1/s • Run 11/s • Sprint 20/s

Standing still barely refills Speed. Real movement is how you recharge quickly.

Example: After spending Speed on a Sweep, sprint a short safe loop instead of standing still waiting for the bar.

ARMOR OFF — HOLD CAPS LOCK

Speed drain 5/sClone damage 50%Cooldown = 90s + actual active time

While Silver Chariot is summoned, hold CAPS LOCK to full charge to activate Armor Off. Armor Off cooldown only blocks reactivating Armor Off; it never blocks normal Stand Summon/Dismiss.

If you Dismiss while Armor Off is active, clone/model/state cleanup runs first, Armor Off ends, and the cooldown is based on the actual active duration. Dismissing again while that cooldown is running does not restart it.

Easy rule: tap CAPS LOCK = normal Summon/Dismiss • full hold CAPS LOCK = Armor Off when available.

Skill 1 — STAB

CD 0.22s • Range 3.1

Fast single-target sword poke for reliable damage without spending Speed Gauge.

Example: Use Stab while rebuilding Gauge; save the expensive skills for when movement has refilled you.

Skill 2 — RAPIER RUSH

CD 3s • Range 3.4 • Cost 18

Rapid sword rush. Strong for focused pressure but spends Speed, so repeated use requires movement between engagements.

Example: Rush one target, disengage and run, then come back with the Gauge you earned from movement.

Skill 3 — CIRCLE SWEEP

CD 3.5s • Area • Cost 25

Wide sword sweep for multiple nearby threats. It costs more Speed than Rush.

Example: Use it when the group is actually surrounding you; using 25 Speed on one lone zombie wastes the Stand’s resource.

Skill 4 — RAPIER SHOT

CD 5.2s • Range 8.2

Launches one real rapier projectile. It gives Silver Chariot a ranged answer and can be stopped by supported Barrage Guard.

Example: Shoot a dangerous target before it enters melee range, then use your movement speed to choose whether to close in or back off.

HOW TO THINK ABOUT THIS STAND

Movement is your resource engine

Rush/Sweep spend Speed, so weave real movement between attacks instead of trying to stay planted and spam skills.

Armor Off never owns Dismiss

You can still Dismiss and resummon Silver Chariot while Armor Off is cooling down; only Armor Off itself remains unavailable.
