HARVEST

HARVEST มีทรัพยากรหลักก้อนเดียวคือ “จำนวนฝูง” สูงสุด 500 ตัว ทุกอย่างตั้งแต่ยิง, เกาะเป้า, Storm ไปจนถึง Search แย่งจำนวนจากก้อนเดียวกัน

เริ่มใช้ HARVEST ยังไง

เปิด Project JoJo Core พร้อม HARVEST Addon แล้วใช้ Stand Arrow ปกติ HARVEST จะเข้ารวมใน Stand Pool และจะขึ้นใน Super Arrow เมื่อเซิร์ฟเปิดตัวเลือกนั้น

CONTROLS

CAPS LOCK — เรียก / เก็บ Stand
1 — HARVEST SHOT
2 — NEEDLE SWARM
3 — HARVEST SEARCH COMMAND
4 — HARVEST STORM

สกิลต่อสู้ใช้ Targeting Mode ของ Core ส่วน Search Command เป็นหน้าจอ gameplay UI และใช้ pointer สำหรับเลือกของ/จำนวน/crew

COLONY — 0 / 500

HARVEST ใช้ฝูงร่วมกันสูงสุด 500 ตัว สกิลต่อสู้และ Search ใช้ pool เดียวกัน ตัวที่ถูกส่งออก Search จะถูก reserve จึงลดเพดานที่คุณรีกลับมาได้จนกว่างานจะจบหรือ Recall

อัตราฟื้นฐานปัจจุบัน:

  • ยืนนิ่ง: 0.80 / วินาที หลังช่วง grace
  • นั่ง / อยู่ในรถ: 4.05 / วินาที
  • Rest: 9.00 / วินาที
  • Sleep: 14.40 / วินาที

เดิน/วิ่งไม่ใช่สถานะฟื้นฝูงปกติ และ Sandbox Harvest Regeneration Speed ใช้คูณความเร็วฟื้น ไม่ได้ทำ Search ให้เร็วขึ้น

ตัวอย่าง: ส่ง 150 ตัวไป Search = ระหว่างงานนั้นเพดานฝูงพร้อมใช้จะลดเหลือประมาณ 350 ไม่ใช่ปล่อยให้รีกลับ 500 แล้วได้ 150 ตัว “ฟรี” ซ้อนอีกก้อน

SKILL 1 — HARVEST SHOT

ใช้ 1 Harvest ส่งตัวหนึ่งพุ่งไปโจมตีระยะไกล ดาเมจเบาและมี mini knockback/CC กดค้างเพื่อส่งต่อเนื่องทีละตัว

Barrage Guard ที่รองรับสามารถกัน Shot จากด้านหน้าได้

เหมาะกับ: กวนเป้า, เก็บตัวที่ใกล้ตาย, บังคับระยะ โดยไม่ต้องลงฝูงก้อนใหญ่ทันที

SKILL 2 — NEEDLE SWARM

ใช้ขั้นต่ำ 7 Harvest กดค้างเพื่อเพิ่มจำนวนที่ commit ทีละขั้น ยิ่งถือไว้นานระบบเลือกจำนวนก้อนใหญ่ขึ้น ฝูงที่เลือกจะไปเกาะเป้าเดี่ยวแล้วโจมตีพร้อมกันหลังช่วงรอ

ถ้าเป้าตาย/หาย/หลุดเงื่อนไขก่อน resolve งานจะถูกยกเลิกและตัวที่ reserve สำหรับสกิลนี้ถูกคืนตามระบบ

ตัวอย่าง: ตัวถึกหนึ่งตัวเดินนำฝูงมา คุณสามารถลง 40–60 ตัวกับมันโดยไม่ต้องเท 500 ทั้งก้อน แล้วเก็บที่เหลือไว้ Shot/Storm หรือ Search

SKILL 3 — HARVEST SEARCH COMMAND

กด Skill 3 เปิดหน้าต่าง Search เลือก ไอเท็มจริงที่อยู่ใน inventory เป็น template จากนั้นตั้งจำนวนของและจำนวน Harvest ที่ส่งไปทำงาน

ของแบบไหนเลือกเป็น Template ได้

ระบบไม่ได้จำกัดอยู่แค่ยา/ผ้าพันแผล และมองของในกระเป๋าซ้อนด้วย รายการที่ state ต่างกัน เช่นภาชนะของเหลวเต็ม/ครึ่ง/ว่าง, condition หรือ weapon state ที่สำคัญ จะพยายามแยก template แทนการรวมเพียง FullType เดียว

สำหรับไอเท็มจากมอด ระบบฝั่ง authority จะ preflight ความสามารถในการสร้าง/ส่งของตอนกด START SEARCH ถ้าไอเท็ม runtime นั้นสร้างกลับอย่างปลอดภัยไม่ได้ จะเตือนเรื่อง compatibility ก่อน reserve Harvest แทนการกินทรัพยากรไปแล้วค่อยพัง

จำนวนของ / Crew

  • Quantity: x1–x500
  • x1–x20 = ต้องมี crew อย่างน้อย 20 Harvest
  • x21–x500 = crew ขั้นต่ำเท่าจำนวนของที่ขอ
  • ส่ง crew มากกว่าขั้นต่ำ = งาน Search เร็วขึ้น
  • น้ำหนักรวมของ batch เพิ่มเวลาขนส่ง

Stand Level ของ HARVEST ช่วยลดช่วง “ทำงานค้นหา” ได้ตาม progression แต่ช่วงเดินออก, เดินกลับ และส่งของไม่ได้ถูกบีบหายจนกลายเป็นวาร์ปทันที

ACTIVE JOBS / RECALL

ทำหลาย Search Job แยกกันได้ หน้าจอแสดง phase/ETA ของแต่ละงาน และปุ่ม RECALL ยกเลิกเฉพาะงานนั้น คืน Harvest ที่ reserve ทันที และของที่งานยกเลิกยังไม่ได้ส่งจะไม่ถูกเสกเข้ากระเป๋า

เสียง Search ผูกกับงาน/ตำแหน่งของฝูงจริง จึงรองรับหลายงานเล่นเสียงพร้อมกัน และ Personal Project JoJo Volume มีผลกับเสียง Search ด้วย

SKILL 4 — HARVEST STORM

ใช้ขั้นต่ำ 33 Harvest ปล่อยฝูงก้อนหนึ่งรอบตัวเพื่อกดพื้นที่ซ้ำ ๆ มี mini knockback/interrupt และเหมาะกับฝูงซอมบี้ ยิ่ง commit จำนวนมากยิ่งอยู่ได้นานขึ้นจนถึงเพดานของสกิล

Barrage Guard ตรวจเป็นรายผู้เล่น ดังนั้นคนที่ Guard สำเร็จสามารถกัน hit ของ Storm ที่โดนตัวเองได้ โดยไม่ได้ลบ Storm ออกจากโลกสำหรับทุกคน

วิธีบริหารฝูง

อย่าคิด 500 เป็น “กระสุนที่ต้องใช้ให้หมด” ให้คิดว่าเป็นงบเดียวที่ต้องแบ่งระหว่าง สู้ตอนนี้ กับ ส่งไปทำงานเพื่ออนาคต

ตัวอย่าง: ถ้าส่ง 300 ไปหาไอเท็ม เหลือ 200 สำหรับป้องกันตัว การลง Storm ใหญ่ทันทีอาจทำให้คุณแทบไม่มี Shot/Swarm เหลือ ถ้าพื้นที่อันตรายควร Recall บางงานหรือส่ง Search crew น้อยลงก่อน

CLIENT / SANDBOX OPTIONS

HARVEST ใช้ HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Volume และ Targeting Mode ของ Core หน้าจอ Search ยังเปิดได้เมื่อ Hidden เพราะเป็น gameplay UI

Addon มีตัวเลือก Harvest Regeneration Speed สำหรับสเกลความเร็วฟื้นของ Colony โดยไม่เร่ง Search และไม่ทะลุเพดานที่ถูกหักจาก Harvest ที่กำลังทำงาน

วงจรง่าย ๆ: ดู Colony ที่เหลือ → ตัดสินใจว่าจะลงทุนกับเป้า/Storm เท่าไร → ก่อนส่ง Search ให้นึกเสมอว่าจำนวนนั้นจะหายจากงบต่อสู้จนกว่าจะกลับ
