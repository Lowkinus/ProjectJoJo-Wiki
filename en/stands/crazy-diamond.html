CRAZY DIAMOND

Crazy Diamond is not a passive healer. Fight in Attack Mode to refill Restore, then spend that resource on healing, repair and Glass Homing.

Current guide refresh • Project JoJo Core
DifficultyHigh
Restore max100
Passive regen0.01/sec
Glass range9 tiles

RESTORE GAUGE

Max 100 • very slow passive refill

Passive refill is intentionally tiny. Real offensive CD hits are the main way to refill: Punch, Rush and Glass all add Restore when they actually connect.

Example: If you spend the whole bar healing, return to Attack Mode and land hits instead of waiting several minutes for passive refill.

Skill 1 — DORAAA / RESTORE PUNCH

CD 0.37s • Range 2.8

Attack Mode deals damage and builds Gauge. Restore Mode heals another valid target and only spends Gauge on a successful heal.

Example: Use quick Restore Punches between fights for controlled healing instead of dumping everything through Rush.

Skill 2 — DORA RUSH / RESTORE RUSH

CD 5s • 17 / 25 hits

Attack Rush is offensive and creates Barrage Guard. Restore Rush becomes repeated healing ticks and does not use Barrage Clash.

Example: If knives/projectiles are coming, stay in Attack Mode if you need Barrage Guard; Restore Rush is not the defensive version.

Skill 3 — ATTACK / RESTORE

Instant toggle

Changes what Skills 1, 2 and 4 do. Attack builds resources; Restore spends them on support.

Example: Get used to checking the mode before pressing Skill 2; the same button can mean “damage” or “heal”.

Skill 4 — GLASS SHOT / GLASS HOMING

CD 5.2s • Range 9

Attack Mode fires glass and creates a mark. Restore Mode spends Restore to send glass that first flies straight, then curves toward the mark. Walls, vehicles and bodies can still intercept it.

Example: Mark a tough target, move to a different angle, switch Restore and send Homing so the return path approaches from somewhere less predictable.

HOW TO THINK ABOUT THIS STAND

Do not memorize jargon

Focus on the loop: what builds your resource, what spends it, and which skill solves the problem in front of you.

Use the examples

The examples above are not fixed combos. They are situations that explain why the mechanic exists, so you can adapt it to your own fight.
