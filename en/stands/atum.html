ATUM

ATUM is not just a damage Stand. Its identity is reading real attacks, marking souls and turning contact into RPS, Baseball or Racing with their own rules.

HOW TO GET ATUM

Enable Project JoJo Core and the ATUM addon, then use the normal Stand Arrow. ATUM joins the shared Stand Pool; it does not have a separate Arrow. If Super Arrow is enabled, ATUM appears in the choice list while the addon is active.

CONTROLS

CAPS LOCK — Summon / Dismiss
1 — Punch
2 — Barrage
3 — Mind Read
4 — Gamble

Normal combat follows the Core targeting mode: Mouse / Pointer, Facing Direction or Controller Aim. Minigame screens are gameplay UI and still use the pointer/controls needed by that game.

MIND GAUGE — 0 / 100

Mind Points power Skill 3. Arming a read costs 1 point, so reading every harmless movement without a plan can leave you empty when a real attack arrives.

  • RPS / Baseball win: +0 to +3
  • Racing win: +2 to +5
  • Correct FULL-S3 prediction + win: +1 extra

SKILL 1 — PUNCH

Basic close-range pressure and a useful reference for the real contact range shared by several ATUM interactions.

SKILL 2 — BARRAGE

ATUM's close-range rush. It uses Project JoJo's shared Barrage targeting/contact systems where supported.

SKILL 3 — MIND READ

Tap / release before FULL — DODGE READ

Spend 1 Mind Point and arm a roughly 10-second attack read. It does not trigger just because something walked close — the attacker must commit a supported real attack.

A successful read against a non-player attacker applies a 3-minute Soul Mark. Players are never Soul Marked.

Example: A zombie enters bite range → DODGE READ is armed → the real bite triggers the read → the attacker becomes marked for later Gamble interactions.

Hold until FULL — GAMBLE READ

Spend 1 point to prepare the YES / NO prediction route for Skill 4. This is not the same as Tap-S3's dodge read. The prepared prediction is consumed when Gamble makes real contact.

Manually cancelling an unused read before it is triggered/consumed can refund its Mind Point. Triggered, consumed or expired reads do not.

SOUL MARK / MULTI-SOUL GAMBLE

Soul Marks are tracked per ATUM owner. When a Gamble starts, living marked non-player targets near the main target can be bound into the same wager.

The UI still plays against the main target, but Soul Extraction can affect the bound marked souls. The bound count is locked when the wager starts; new marked targets do not jump into the game halfway through.

SKILL 4 — GAMBLE / AUTO GAMBLE

Tap 4 must make real contact, then authority chooses one of three games:

  • Rock Paper Scissors
  • Baseball
  • Racing

Hold Skill 4 to FULL toggles AUTO GAMBLE PASSIVE. While it is active, normal Tap-4 is disabled and a successful DODGE READ can automatically challenge the exact attacker that triggered it.

FULL S3 → Tap S4 is the Prediction combo and adds the YES/NO read phase.

ROCK PAPER SCISSORS

The challenged side responds within the game window; AI choices are handled authoritatively. FULL-S3 prediction adds the YES/NO reading phase.

BASEBALL

The Pitcher chooses HIGH / MIDDLE / LOW. If a player fails to answer before timeout, the server can randomize the pitch and continue rather than handing out a free instant win. Prediction reads the real locked pitch.

Correct timing/choice wins the exchange, with better Home Run conditions near the end of the timing window.

RACING

The longest ATUM game, so its base Mind reward is higher. Players manage vehicle HP and position using BOOST / ATTACK / BLOCK. Launch Mash can start as soon as the Racing screen opens by rapidly tapping Skill 1, with diminishing returns and a hard cap.

A car that is knocked out/off-road can lose, but the surviving side still needs to satisfy the finish-line rule instead of receiving every win immediately.

WINNER'S HIGH

The actual human winner gets a full mental clean: Stress, Panic, Unhappiness and Boredom are set to 0. If the current Build/Framework exposes Anger or Fear in a supported way, ATUM also attempts to clear them.

This is not physical healing: Hunger, Thirst, Fatigue, Pain and injuries are not restored.

MINIGAME PROTECTION

Participants are temporarily protected/phased from normal outside combat while a game is active, then visibility/protection is restored during resolution/cleanup.

CLIENT OPTIONS

ATUM follows the Core Stand HUD Normal / Minimal / Hidden modes, HUD Opacity/Scale, personal Project JoJo Volume and Targeting Mode. Required minigame UI remains available because it is part of gameplay.

How to think about ATUM: read a real threat → create Marks/information → choose when a Gamble is worth starting → keep enough Mind for the next read.
