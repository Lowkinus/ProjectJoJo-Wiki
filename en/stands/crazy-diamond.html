CRAZY DIAMOND

v0.23.0.237

Attack/Restore contact uses the current mouse corridor with no sticky old target. Glass uses First-Contact. Barrage Guard works only during Attack Barrage.

PUNCH / BARRAGE

Attack Mode deals damage • Restore Mode is used for supported healing/repair.

ATTACK RESTORE-GAUGE GAINS

Punch +0.30 • Barrage +0.09375 per hit • Glass +0.375.

GLASS SHOT

Fires along mouse direction and stores the latest valid target/impact mark.

GLASS HOMING

Restore Mode can curve the shard back toward the stored mark using real travel.

Aiming in this version

Attacks covered by Directional First-Contact use mouse direction and the skill's real range. The first body intersecting the attack corridor is selected first, while existing obstacles and PvP/Safety rules still apply.
