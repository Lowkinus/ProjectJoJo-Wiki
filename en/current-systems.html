CORE v0.23.0.350 — TEST PATCH

Numbers shown on legacy Stand pages may change with Stand Levels and balance settings. v.350 is a test patch; runtime validation is still required.

CORE COMBAT & REAR-HIT REACTIONS

Normal Stand damage and critical rolls are processed by the shared Core. The test patches improved directional knockback when the victim faces away, but B42 stagger animations can still affect visuals; do not treat this as universally resolved.

ENVIRONMENT HITS & MATERIAL DROPS

For supported world objects such as doors and trees, the updated environment path attempts to use Project Zomboid Vanilla WeaponHit behavior so salvage and wood can drop normally. This depends on the object type and the skill actually using the environment profile; test patched addons before a stable release.

KING CRIMSON — 77% REAR CRITICAL

Base chance is 15%; a target whose back is exposed to King Crimson is eligible for 77% crit on that target. HUD crit reflects the likely aimed target; this is not a universal 77% buff.

MAGICIAN'S RED — ALTERNATE SKILLS

Skill 1: CROSS FIRE/FIRE TRAP. Skill 3: FIRE CONTROL/DETECTOR. The slash means one skill key has an alternate action. Fire Gauge is built by Cross Fire and spent on area fire.

SILVER CHARIOT — ARMOR OFF

Hold CAPS LOCK to activate Armor Off when summoned and ready. Armor Off cooldown blocks Armor Off reactivation, but not normal Stand Summon/Dismiss.

KILLER QUEEN — HELD INPUT

Holding a supported skill during its cooldown is intended to trigger it when ready, as long as the key remains held. Some addon-specific skills have their own input paths.

TIME STOP / TIME ERASE

The temporal skills cannot simply stack without restrictions. Delayed damage and projectile states require careful cleanup. Epitaph’s overlapping-hit protections are scoped to its active counter/teleport phase.

ECHOES ACT 3 — BARRAGE / THREE FREEZE

Skill 1 uses rush attacks and target-marking; Skill 2 points the right open hand and applies THREE FREEZE for nine seconds. The current Diamond Records model and multiple clone-arm effects are still test-build work.

OFFICIAL ADDON INTEGRATION

ATUM normal Punch/Rush and Harvest damage paths share Core rules, while unique mini-games/search and Heaven’s Door Fly Away keep specialized logic. The .349/.350 tests adjusted overlapping reactions and environment interactions without rewriting all addon powers.

PvP / MULTIPLAYER / VEHICLE SAFETY

Stand damage checks PvP/Safety in supported paths; utility control can have separate behavior. Time Stop, vehicle collisions, owner isolation and addon network effects require in-game multiplayer tests.
