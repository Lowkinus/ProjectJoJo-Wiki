ADDON • อ่านใจ / Soul Mark / การพนัน

ATUM

Stand สาย Mind Game: อ่านการโจมตี ทำ Soul Mark และเปลี่ยนการสัมผัสเป็น RPS, Baseball หรือ Racing

ไว้ใจสัญชาตญาณตัวเองแค่ไหน?

ATUM เป็น Addon ที่เน้นอ่านใจ ทำนาย Soul Mark และการพนัน มากกว่าชนะด้วยพลังหมัดตรง ๆ

รองรับ Singleplayer / Host / Multiplayer

คู่มือนี้อิง Core ปัจจุบัน v0.23.0.250

วิธีได้ ATUM

ใช้ Stand Arrow ปกติของ Project JoJo ได้เลย ATUM อยู่ใน Stand Pool เดิม ไม่มี ATUM Arrow แยก

ถ้าโลก/เซิร์ฟเวอร์เปิด Super Arrow และ Addon นี้เปิดอยู่ ATUM จะขึ้นในรายชื่อ Stand ให้เลือกอัตโนมัติ ถ้าปิด Super Arrow ตัวนี้ยังอยู่ใน Stand Pool สำหรับการสุ่มตามปกติ

ปุ่ม

CAPS LOCK — เรียก / เก็บ Stand

1 — Punch

2 — Barrage

3 — Mind Read

4 — Gamble

สกิลต่อสู้ของ ATUM ใช้ Targeting Mode กลางของ Core: Mouse / Pointer, Facing Direction, Controller Aim. ถ้าไม่อยากใช้เมาส์ เลือก Facing Direction ให้โจมตีตามหน้าตัวละคร หรือ Controller Aim ให้ตามแกนเล็งจอย. หน้าจอ Minigame ยังเป็น Gameplay UI และใช้เมาส์ได้ตามปกติเมื่อจำเป็น

SKILL 3 — MIND READ

Tap / ปล่อยก่อน FULL — DODGE READ

ใช้ 1 Mind Point และเปิดการอ่านหลบ 10 วินาที การโจมตีที่รองรับสามารถทำให้ Dodge ทำงานได้

ถ้า DODGE READ หลบสำเร็จกับ เป้าหมายที่ไม่ใช่ผู้เล่น ผู้โจมตีจะติด Soul Mark 3 นาที ผู้เล่นจะไม่ถูก Soul Mark

Hold จน FULL — GAMBLE READ

ใช้ 1 Point เพื่อเปิดเส้นทาง YES / NO สำหรับ Skill 4 และจะถูกใช้เมื่อ Gamble สัมผัสเป้าหมายจริง หน้าต่าง YES/NO เป็น mouse-through จึงไม่บังปุ่มของ Minigame ด้านล่าง

ยกเลิก Read ที่ยังไม่ถูกใช้ก่อนหมดเวลาจะคืน 1 Mind Point

SOUL MARK / MULTI-SOUL GAMBLE

Soul Mark แยกตามเจ้าของ ATUM แต่ละคน

ตอนเริ่ม Gamble ระบบจะดึงม็อบที่ยังมีชีวิต Mark ยังไม่หมด และอยู่ในระยะประมาณ 18 ช่อง / ต่างชั้นตามกฎ เข้าเดิมพันเดียวกัน Minigame ยังคงเล่นกับเป้าหมายหลักเพียงตัวเดียว

  • ATUM ชนะ → เป้าหมายหลัก + Soul ที่ถูกผูกเข้า Gamble โดน Soul Extraction ทั้งหมด
  • ATUM แพ้ → Blackout 3 วินาทีเท่าเดิม แต่ Skill Silence = 7 วินาที × จำนวนเป้าที่เข้าเดิมพัน
  • จำนวนเดิมพันถูกล็อกตอนเริ่มเกม

Skill 4 HUD แสดงจำนวน Soul Mark ที่ดึงเข้า Gamble ได้จริงในขณะนั้น และแสดง AUTO GAMBLE PASSIVE บริเวณเดียวกัน

SKILL 4 — GAMBLE / AUTO GAMBLE

Tap 4 พุ่งสัมผัสด้วยระยะเดียวกับ Punch เมื่อโดนจริง Server สุ่มเกมแบบเท่ากัน 1/3:

  • Rock Paper Scissors
  • Baseball
  • Racing

Hold 4 จน FULL เปิด/ปิด AUTO GAMBLE PASSIVE ระหว่างเปิด Passive จะกด Tap 4 แบบปกติไม่ได้ และถ้า Tap-S3 DODGE READ หลบสำเร็จจะท้าคนที่โจมตีคนนั้นอัตโนมัติ

FULL S3 → Tap 4 คือคอมโบทำนาย

เกม

RPS — ฝั่งที่ถูกท้ามีเวลา 8 วิ ซอมบี้สุ่มฝั่ง Server และ FULL-S3 จะมีช่วง YES/NO

BASEBALL — Pitcher เลือก HIGH / MIDDLE / LOW ถ้าผู้เล่นไม่ตอบทัน Server จะสุ่มลูกให้อัตโนมัติ ตีตรงตำแหน่ง = ชนะ; ตีถูกใน 2 วินาทีท้ายการันตี HOME RUN ส่วนการตีถูกปกติมีโอกาส Home Run 10%

RACING — Intro 8.8 วิ + READY 4.5 วิ + แข่งหลัก 36 วิ รถมี 100 HP ใช้ BOOST / ATTACK / BLOCK และมี Hidden Launch Mash กด Skill 1 รัวได้ตั้งแต่เปิดหน้าจอ Racing; 5 ครั้งขึ้นไปเริ่มโบนัสออกตัวและยิ่งกดมากยิ่งแรงแบบ diminishing return พร้อม hard cap

Racing ใช้เวลานานกว่าเกมอื่นจึงให้ Mind Reward พื้นฐานสูงกว่า

MIND GAUGE / REWARD

0 / 100

Skill 3 ใช้ 1 Point

  • ชนะ RPS / Baseball: +0 ถึง +3
  • ชนะ Racing: +2 ถึง +5
  • FULL-S3 ทายถูกและชนะ: +1 เพิ่ม

WINNER'S HIGH

ผู้เล่นที่ชนะจริง เป็นคนได้รับโบนัส ลด Stress / Unhappiness / Boredom / Panic เล็กน้อย โดย Racing ให้มากที่สุดเพราะใช้เวลานานสุด

ถ้าเจ้าของ ATUM ใช้ FULL S3 ทายถูกและชนะ Winner's High จะคูณ ×1.25

ไม่ฟื้น Hunger / Thirst / Fatigue / Pain / Sickness หรือบาดแผล

MINIGAME PROTECTION / CLIENT OPTIONS

ระหว่าง Minigame ผู้เข้าร่วมถูกป้องกัน/phase ออกจากการต่อสู้ภายนอกชั่วคราว และคืนสถานะหลังจบเกม

ATUM รองรับ Stand HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Volume และ Targeting Mode ของ Core โดยหน้าจอ Minigame / YES-NO ที่จำเป็นต่อการเล่นจะยังแสดงตามปกติ Core v0.23.0.250 มีปุ่ม Reset การแสดงผล/เสียง/Targeting และ Reset Keybind แยกกัน
