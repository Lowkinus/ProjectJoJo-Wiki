PROJECT JOJO — CURRENT SYSTEM GUIDE

Targeting

Options → Mods → Project JoJo now offers Mouse / Pointer, Facing Direction, and Controller Aim. Facing/Controller modes feed a forward ray into Directional First-Contact, so the first valid target/contact wins and walls/windows/vehicles still matter. Controller Aim reads Project Zomboid's controller aiming axis and falls back to Facing Direction inside the dead-zone.

Personal HUD & Audio

Stand HUD can be Normal / Minimal / Hidden, with 20–100% opacity, 70–150% scale and 0–100% personal Project JoJo volume. These are client preferences, not Sandbox authority. Required addon gameplay screens remain usable.

Summoned Stand Defense

While a registered Stand is summoned, the owner takes 33% less net damage. The refund is calculated from observed health/body-part loss after vanilla/other-mod reductions.

World / Vehicle Safety

Stand attacks still collide with vehicles, but rapid environment hits no longer mutate vehicle durability/state. Unknown custom-map objects are protected unless they opt in to Stand damage. Known vanilla doors/windows/trees/barricades/thumpables continue to use their supported damage paths.

Core combat

Directional First-Contact, Barrage Contact, Barrage Guard, Time Stop, Time Erase, Barrage Clash, PvP / Safety integration and multiplayer synchronization remain shared systems.

Stand progression

Each Stand keeps separate Lv.1–100 progression. Low levels deal reduced damage; Lv.100 reaches full level scaling. Switching Stands keeps previous Stand progress.

Official addons

ATUM — Soul Marks, Mind Gauge, prediction and RPS/Baseball/Racing wagers.

HARVEST — 500-unit colony, Search Command, level-scaled Search and area control.

Server vs client settings

Sandbox controls shared gameplay balance such as Arrow Drop Rate, Stand Damage, Levels, Arrow on Join and Infinite Arrow. Targeting mode, HUD density/scale/opacity and personal volume are per-client options.
