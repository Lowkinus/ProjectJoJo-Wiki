ATUM

ADDON — requires the main Project JoJo mod

ATUM uses Project JoJo's normal Stand Arrow and shared framework instead of creating a second Stand system. It shares the main mod's Level, PvP/Safety, HUD, targeting and multiplayer systems.

Skill 1 — PUNCH

ATUM's basic punch uses Project JoJo's shared First-Contact and targeting rules. It gives ATUM a normal combat option while the gambling system is not active.

Skill 2 — BARRAGE

A mouse-directed rush using the main mod's Rush / First-Contact framework. ATUM can fight normally, but it is intentionally more about mind games than standing still and trading with a pure brawler.

Skill 3 — MIND READ / YES–NO

Spend Mind Gauge to activate the read. Pressing Skill 3 again while it is still active turns it off without paying another point. The state can be used to read choices before Skill 4 and can also act as a dodge against supported committed attacks.

MIND GAUGE

Starts at 0/100. Winning an ATUM game rolls 0–3 points. If the prediction was correct and ATUM wins the game, the reward is guaranteed to be at least 1 point, giving a chance to recover the point spent on the read.

Skill 4 — GAMBLE

ATUM must make real contact with a valid target before a game begins. The system then selects one of three games: Rock Paper Scissors, Baseball or Racing. During a minigame, the participants are isolated from normal combat and protected from outside damage until the game finishes.

ROCK PAPER SCISSORS

RPS

Choose Rock, Paper or Scissors. Zombie targets use an automatic choice, while player targets receive their own choice UI.

Mind Read

If Skill 3 was active, a separate prediction phase happens before the real game timer. A correct read produces YES; a wrong one produces NO.

BASEBALL

HIGH / MIDDLE / LOW

Match the target's hidden pitch lane. A correct lane becomes a hit; a wrong lane misses.

HOME RUN

A successful hit can become a Home Run, with the late timing window acting as the special high-reward timing mechanic.

RACING

BOOST

Hold to convert vehicle HP into speed. Stronger use means more HP management.

ATTACK

Charge, then automatically ram the opponent to deal vehicle damage and disrupt speed.

BLOCK

Spend a small amount of HP for a short full-defense window. A well-timed Block can counter an incoming Attack.

FINAL STRETCH

After the main race, the real lead/gap is carried into a final sprint. Steering locks and BOOST / ATTACK / BLOCK decide who actually crosses first.

HOW TO ACTUALLY PLAY IT

S3 → S4

ATUM's core route is Mind Read into Gamble: use the YES/NO information to reduce uncertainty before the game resolves.

Do not waste Gauge

Mind Gauge is not free. If there is no reason to read yet, keeping the point is usually better.

Racing is HP management

BOOST trades HP for speed, ATTACK creates damage and disruption, and BLOCK is the counter. Spamming one option is predictable.

Not a pure brawler

Punch and Barrage keep ATUM functional in normal combat. Its real strength is reading the opponent and dragging them into ATUM's rules.

Remember: ATUM is a Project JoJo addon, so the main mod must be enabled. Skill 4 also needs real target contact before the game can start.
