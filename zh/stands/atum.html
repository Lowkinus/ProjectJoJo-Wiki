ATUM

ATUM 不只是伤害替身。它的核心是读取真正攻击、标记灵魂，再把接触变成 RPS、Baseball 或 Racing。

如何获得 ATUM

启用 Project JoJo Core 与 ATUM addon，然后使用普通 Stand Arrow。ATUM 会加入共享 Stand Pool，不需要专用 Arrow。开启 Super Arrow 时，只要 addon 已加载，ATUM 也会出现在直接选择列表。

操作

CAPS LOCK — Summon / Dismiss
1 — Punch
2 — Barrage
3 — Mind Read
4 — Gamble

普通战斗遵循 Core Targeting Mode：Mouse / Pointer、Facing Direction、Controller Aim。小游戏界面属于 gameplay UI，会继续使用对应小游戏所需的鼠标/按键。

MIND GAUGE — 0 / 100

Mind Point 为 Skill 3 提供资源。每次武装一次 read 花 1 点；如果对无害动作乱读，会在真正攻击来临时没点可用。

  • RPS / Baseball 胜利：+0 到 +3
  • Racing 胜利：+2 到 +5
  • FULL-S3 预测正确并获胜：额外 +1

SKILL 1 — PUNCH

基础近战压制，也作为多个 ATUM 接触交互的真实距离参考。

SKILL 2 — BARRAGE

ATUM 的近战 Rush；在支持处使用 Project JoJo 共用 Barrage targeting/contact 系统。

SKILL 3 — MIND READ

Tap / 未到 FULL 就释放 — DODGE READ

消耗 1 Mind Point，武装约 10 秒攻击读取。不是敌人走近就触发；攻击者必须真正发动支持的攻击。

成功读取一个非玩家攻击者会施加 3 分钟 Soul Mark；玩家永远不会被 Soul Mark。

例：僵尸进入咬人距离 → DODGE READ 已武装 → 真正 bite 触发读取 → 攻击者被标记，可用于后续 Gamble。

Hold 到 FULL — GAMBLE READ

花 1 点准备 Skill 4 的 YES / NO 预测路线。它不是 Tap-S3 的 dodge read；准备好的预测会在 Gamble 真正接触时被消耗。

未触发/未消耗前手动取消一个 read 可以退回 Mind Point；已经触发、消耗或自然过期不会退。

SOUL MARK / MULTI-SOUL GAMBLE

Soul Mark 按 ATUM 拥有者分别追踪。Gamble 开始时，主目标附近存活的已标记非玩家目标可被绑定到同一场赌局。

UI 仍然只与主目标对局，但 Soul Extraction 可影响被绑定的 marked souls。绑定数量在赌局开始时锁定，新标记目标不会中途加入。

SKILL 4 — GAMBLE / AUTO GAMBLE

Tap 4 必须真实接触，然后 authority 从三种游戏选择：

  • Rock Paper Scissors
  • Baseball
  • Racing

Hold Skill 4 到 FULL 切换 AUTO GAMBLE PASSIVE。开启期间普通 Tap-4 禁用，成功 DODGE READ 可以自动挑战真正触发读取的那名攻击者。

FULL S3 → Tap S4 是 Prediction combo，会加入 YES/NO 读取阶段。

ROCK PAPER SCISSORS

被挑战方在游戏窗口内回答；AI 选择由 authority 处理。FULL-S3 prediction 会加入 YES/NO reading phase。

BASEBALL

Pitcher 选择 HIGH / MIDDLE / LOW。玩家超时没选时，服务器可随机球路继续比赛，而不是免费判 ATUM 立即胜利；Prediction 读取锁定后的真实球路。

正确 timing/choice 赢下交换；越靠近 timing window 末端越容易满足更好的 Home Run 条件。

RACING

ATUM 最长小游戏，所以基础 Mind 奖励更高。玩家使用 BOOST / ATTACK / BLOCK 管理车辆 HP 与位置。Racing 屏幕一打开就能通过快速点 Skill 1 开始 Launch Mash；收益递减且有硬上限。

车辆被打爆/出界可能判负，但仍存活的一方通常仍需满足 finish-line 规则，不会所有情况都立刻拿胜利。

WINNER'S HIGH

真正的人类胜者会完整清理心理状态：Stress、Panic、Unhappiness、Boredom 设为 0。若当前 Build/Framework 以支持方式暴露 Anger/Fear，ATUM 也会尝试清除。

这不是身体治疗：Hunger、Thirst、Fatigue、Pain 与伤势不会恢复。

MINIGAME PROTECTION

小游戏进行期间，参与者会暂时从普通外部战斗中受到保护/phase，结算与清理后恢复可见性和保护状态。

CLIENT OPTIONS

ATUM 遵循 Core 的 Stand HUD Normal / Minimal / Hidden、HUD Opacity/Scale、个人 Project JoJo Volume 与 Targeting Mode。必要小游戏 UI 因为属于玩法本身，会继续显示。

ATUM 的思路：读取真正威胁 → 获得 Mark/信息 → 决定什么时候值得开 Gamble → 为下一次 read 留够 Mind。
