HARVEST

HARVEST ใช้ฝูงก้อนเดียวร่วมกันทั้งต่อสู้และ Search จุดสำคัญคือบริหารจำนวน เพราะตัวที่ส่งออกไปคือจำนวนที่คุณยังเอากลับมาใช้ไม่ได้จนกว่าจะกลับ

คู่มือ Addon เวอร์ชันปัจจุบัน • v0.4.21
HOW TO GET HARVEST

ใช้ Stand Arrow ปกติ เมื่อเปิด Addon นี้ HARVEST จะเข้ารวมใน Stand Pool และจะขึ้นใน Super Arrow ถ้าเซิร์ฟเปิดตัวเลือกนั้น

CONTROLS

Caps Lock — เรียก/เก็บ
1 — HARVEST SHOT
2 — NEEDLE SWARM
3 — HARVEST SEARCH COMMAND
4 — HARVEST STORM

COLONY — 0 / 500

ต่อสู้และ Search ใช้ฝูงร่วมกันสูงสุด 500 ตัว Harvest ที่ออกไป Search จะถูกจองและลดเพดานการฟื้นจนกว่าจะกลับหรือ Recall อัตราฟื้นพื้นฐาน: ยืนนิ่ง 0.80/วิ, นั่ง/อยู่รถ 4.05/วิ, Rest 9.00/วิ, Sleep 14.40/วิ

SKILL 1 — HARVEST SHOT

ใช้ 1 Harvest ยิงกวนระยะไกล ดาเมจเบาและมีแรงผลักเล็กน้อย กดค้างเพื่อส่งทีละตัวต่อเนื่อง Barrage Guard ที่รองรับสามารถกันได้

SKILL 2 — NEEDLE SWARM

ขั้นต่ำ 7 Harvest กดค้างเพื่อเพิ่มจำนวน ฝูงที่เลือกจะเกาะเป้าเดี่ยวแล้วโจมตีพร้อมกันหลังดีเลย์ ถ้าเป้าตาย/ใช้ไม่ได้จะคืนตัวที่จองไว้

SKILL 3 — SEARCH COMMAND

เลือกไอเท็มในกระเป๋าเป็นต้นแบบ เลือกจำนวนและจำนวนลูกน้อง Quantity x1–x500; x1–x20 ต้องมีอย่างน้อย 20 Harvest; x21+ ต้องส่งขั้นต่ำเท่าจำนวนที่ขอ ส่งเยอะขึ้นช่วยลดเวลางาน และน้ำหนักรวมเพิ่มเวลาเดินทาง งานแต่ละงานกด RECALL แยกกันได้

SKILL 4 — HARVEST STORM

ขั้นต่ำ 33 Harvest ปล่อยฝูงส่วนหนึ่งรอบตัวเพื่อกดพื้นที่ซ้ำ ๆ ยิ่งลงทุนจำนวนมากยิ่งอยู่นานจนถึงเพดานที่ตั้งไว้ Barrage Guard ป้องกันผู้เล่นที่กำลัง Guard จากฮิต Storm ได้โดยไม่ลบ Storm ทั้งก้อน

PRACTICAL EXAMPLE

ถ้าส่ง 150 ตัวออก Search เพดานที่ใช้งานได้จริงจะเหลือ 350 จนพวกนั้นกลับ ถ้าเอาจำนวนก้อนใหญ่ไปลง Storm ต่อทันที คุณอาจเหลือฝูงใช้งานแทบไม่พอ
