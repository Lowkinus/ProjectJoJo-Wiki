HARVEST

Stand ฝูงของชิเงจิไม่ได้ชนะด้วยหมัดหนักแบบตัวประชิด แต่ชนะด้วย “จำนวน” ผู้เล่นต้องบริหาร Harvest สูงสุด 500 ตัว ยิงกวนจากระยะไกล ส่งฝูงไปเกาะเป้า ส่งทีมออกค้นหาไอเท็ม และเทฝูงลงเป็น Storm คุมพื้นที่ ยิ่งส่งออกไปทำงานมากเท่าไร ก็ยิ่งเหลือตัวไว้ป้องกันตัวน้อยลงเท่านั้น

เกจ HARVEST — 0 / 500

สูงสุด 500เดิน/วิ่ง = ไม่รีต้องนิ่ง 0.65 วิSearch ลดเพดานรี

HARVEST ใช้ “จำนวนฝูงจริง” แทนเกจพลังทั่วไป สกิล 1–4 แย่ง Harvest จากกองเดียวกันทั้งหมด ตัวที่ถูกส่งไป Search จะถือว่า ออกไปทำงาน และรีกลับมาทับไม่ได้จนกว่าทีมนั้นจะกลับจริง

ตัวอย่าง: ส่ง Search 100 ตัว → เพดานรีเหลือ 400 / 500 ต่อให้พักนานแค่ไหนก็ไม่เกิน 400 จนกว่าทีม Search จะกลับ และข้างเกจจะแสดง −100 สีแดง ให้เห็นว่าหายไปทำงานกี่ตัว

การฟื้นฟูฝูง

ยืนนิ่ง 0.80 / วินั่ง / อยู่ในรถ 4.05 / วิRest 9.00 / วิSleep 14.40 / วิ

เดินหรือวิ่งเมื่อไรการฟื้นฟูจะหยุด ต้องยืนนิ่งต่อเนื่อง 0.65 วิก่อนจึงเริ่มรีแบบช้า การนั่งเร็วขึ้นมาก ส่วน Rest และ Sleep เป็นวิธีคืนฝูงที่ดีที่สุด

Sandbox ของ HARVEST มีตัวเลือก ความเร็วการฟื้นฟู Harvest (%) ปรับได้ 25–500% และค่าเริ่มต้นคือ 100% ค่านี้เพิ่มเฉพาะความเร็วรี ไม่เร่ง Search และไม่สามารถรี Harvest ที่ยังถูก reserve อยู่ข้างนอกกลับมาได้

สกิล 1 — HARVEST SHOT

ใช้ 1 HarvestCD 0.26 วิระยะ 9ดาเมจพื้นฐาน 0.045

ยิง Harvest หนึ่งตัวไปตามเมาส์ แตะเพื่อยิงทีละนัด หรือกดค้างเพื่อยิงต่อเนื่องตามคูลดาวน์ ดาเมจตรงตั้งใจให้เบา แต่จุดเด่นคือยิงได้ถี่และมีแรงกระแทก/mini-CC เล็ก ๆ ไว้ขัดตัวหน้าของฝูงซอมบี้และซื้อระยะถอย

Barrage Guard: กระสุนนี้สามารถถูกปัด/กันด้วย Barrage Guard ตามระบบกลางของ Project JoJo

สกิล 2 — NEEDLE SWARM

ขั้นต่ำ 7 HarvestCD 1.0 วิระยะ 6เกาะเป้า 9.0 วิ

ปล่อยสกิลเพื่อส่งฝูงที่เลือกไปเกาะเป้าหมายเดี่ยว 9 วินาที แล้วแทงพร้อมกัน กดค้างเพื่อเพิ่มจำนวนแบบ +1 ทีละตัว และจังหวะ +1 จะเร็วขึ้นเรื่อย ๆ เมื่อค้างนานขึ้น

ขั้นต่ำ 7 Harvest สร้างดาเมจประมาณ 0.145 raw และยิ่งลง Harvest เพิ่ม ดาเมจจะไต่ต่อเนื่องอย่างต่อเนื่องจนสูงสุดประมาณ 0.650 raw ที่ 500 Harvest

ถ้าเป้าตาย หาย หรือหลุดระยะก่อนครบ 9 วิ งานจะยกเลิกและคืนตัวที่ค้างอยู่ แต่ถ้าแทงสำเร็จ Harvest ชุดนั้นถือว่าใช้ไปจริง

สกิล 3 — SEARCH ITEM

เปิด Search Command UI โดยตรงเลือกจำนวน x1–x500ขั้นต่ำ = max(20, จำนวนของ)20 → 500 Harvest = Search 1.0× → 7.2×

กด สกิล 3 เพื่อเปิดหน้าต่างใหญ่ HARVEST SEARCH COMMAND โดยตรง การตั้งค่า Search และการจัดการงานทั้งหมดอยู่ในหน้าจอนี้ ทำให้ HUD หลักของ Stand เหลือเฉพาะข้อมูลการต่อสู้ที่จำเป็น

ฝั่งซ้ายของหน้าต่างจะแสดง ไอเท็มที่มีอยู่ใน Inventory ตอนนั้นจริง พร้อมรูป จำนวนที่มี และน้ำหนัก คลิกเลือกไอเท็ม จากนั้นกำหนดจำนวนของที่ต้องการหา กำหนดจำนวน Harvest ที่จะส่ง แล้วกด START SEARCH หน้าต่างจะปิดและ HARVEST เริ่มงานพร้อมเสียง/เอฟเฟกต์ของ Skill 3 ตามปกติ

x1–x20

ต้องใช้ขั้นต่ำ 20 Harvest

x21–x500

ขั้นต่ำเพิ่มตามจำนวนของแบบ 1:1 เช่น x21 ต้อง 21 Harvest, x100 ต้อง 100 และ x500 ต้อง 500

ส่งเกินขั้นต่ำ

ทำได้ถ้ายังมี Harvest เหลือ ยิ่งส่งมาก Search ยิ่งเร็ว จุดความเร็วทีมปัจจุบันคือ 20 / 100 / 200 / 350 / 500 ≈ 1.0× / 1.8× / 3.27× / 5.14× / 7.2×

จำนวนชิ้นเพิ่มเวลาจริง: เวลาค้นหาพื้นฐานถูกคูณด้วยจำนวนของก่อนหารด้วยความเร็วทีม ดังนั้นที่ Crew เท่ากัน งาน x5 จะมีงานค้นหาประมาณ 5 เท่าของ x1

น้ำหนักคิดทั้งชุด: เวลาขนใช้ น้ำหนักต่อชิ้น × จำนวนชิ้น เช่นของหนัก 5.0 จำนวน x5 จะคิดน้ำหนักรวม 25 และขนนานกว่าของหนัก 5.0 จำนวน x1

ก่อนกดเริ่ม หน้าสั่งงานจะแสดงไอเท็ม จำนวนที่ขอ จำนวน Crew น้ำหนักรวม และ เวลาค้นหา/ขนโดยประมาณ ให้ดูก่อนตัดสินใจ

งานที่กำลังทำก็อยู่หน้าเดียวกัน: ส่วนล่างแสดงทุก Search job พร้อมไอเท็ม xN, จำนวน Crew, สถานะ และ ETA แต่ละงานมีปุ่ม RECALL สำหรับเรียกเฉพาะทีมนั้นกลับและคืน Harvest ที่ Reserve อยู่เข้ากองทันที ของที่ยังส่งไม่ถึงจากงานนั้นจะถูกยกเลิก

สกิล 4 — HARVEST STORM

ขั้นต่ำ 33 HarvestCD 1.2 วิพื้นที่ 3.4ตีทุก 0.5 วิ

เท Harvest ส่วนหนึ่งให้วนรุมรอบตัวเป็นแรงกดดันแบบต่อเนื่อง Storm ขั้นต่ำ 33 Harvest อยู่ประมาณ 14 วินาที และยิ่งใส่ Harvest เพิ่ม ระยะเวลาจะไต่ต่อเนื่องจน 500 Harvest ชนเพดาน 38 วินาที

Storm ไม่ใช่ท่า Burst แต่เด่นจากการตีหมู่ซ้ำ ๆ พร้อมแรงผลัก/mini-CC เล็ก ๆ จึงซื้อพื้นที่กับฝูงซอมบี้ได้ดี หนึ่งจังหวะรองรับได้สูงสุด 16 เป้าหมาย ระหว่าง Storm ยังใช้ S1–S3 จาก Harvest ที่เหลือได้ แต่การรีฝูงจะหยุดจน Storm จบ

กด Skill 4 ซ้ำเพื่อหยุดก่อนเวลาได้ และ Barrage Guard ป้องกัน hit ของ Storm สำหรับผู้เล่นที่กำลัง Guard ได้ โดยไม่ได้ลบ Storm ทั้งวงหรือช่วยเป้าอื่นที่ไม่ได้ Guard

การจัดสรร HARVEST

Needle / Storm

สกิล 2 และสกิล 4 ยังใช้ระบบกดค้าง: เพิ่มครั้งละ +1 Harvest และจังหวะ +1 จะเร็วขึ้นเมื่อค้างนานขึ้น

Search

สำหรับ Search ให้เปิด Search Command UI แล้วเลือกจำนวน Crew ที่ต้องการส่งโดยตรง

กองเดียวกัน

Needle, Search และ Storm ใช้ทรัพยากรจากกอง 500 ตัวเดียวกันทั้งหมด การเท Crew ให้งานหนึ่งมากเกินไปจะลดตัวที่เหลือสำหรับสกิลอื่นทันที

วงจรของ SEARCH

เก็บ Stand

งาน Search ที่ส่งออกไปแล้วทำต่อได้ เพราะ Harvest ชุดนั้นออกไปทำงานอยู่จริง

เปลี่ยน/ถอด Stand

งาน Search ถูกยกเลิกและคืน Harvest ที่ reserve เพื่อไม่ให้เปลี่ยนไปใช้ Stand อื่นพร้อมกับปล่อย HARVEST ฟาร์มของต่อ

ตาย

ยกเลิกงาน ไม่แจกไอเท็ม และคืน Harvest ที่ reserve ก่อนล้างงาน

ออกเกม/กลับเข้าเกม

สถานะงานถูกเก็บไว้แต่เวลา Search ไม่เดินตอน Offline ช่วงขากลับ/ส่งของจะกลับมาทำต่ออย่างปลอดภัยโดยไม่แจกของซ้ำ

วิธีเล่น HARVEST

เหลือกองสำรองไว้

อย่าส่ง 500 ออก Search ถ้ายังไม่มั่นใจว่าพื้นที่ปลอดภัย เพราะ Search เร็วก็จริง แต่จะไม่มี Harvest เหลือใช้สู้จนกว่าทีมจะกลับ

S1 ซื้อระยะ

ยิงกวนตัวหน้าของฝูงเพื่อทำให้แนวซอมบี้เสียจังหวะแล้วถอยเปลี่ยนตำแหน่ง ดาเมจเบาแต่แรงผลักรัวคือคุณค่าหลัก

S2 คือการลงทุนกับเป้าเดียว

Needle ต้องรอ 9 วิ จึงเหมาะกับเป้าที่รู้ว่าจะยังอยู่ในระยะและคุ้มกับจำนวนฝูงที่ยอมลงไป

S4 ใช้คุมฝูง

Storm เด่นที่สุดตอนมีซอมบี้หลายตัวพยายามเข้าช่องเดียวกัน mini-CC รัวช่วยเปิดพื้นที่ให้หนี รีโหลด รักษาตัว หรือจัดตำแหน่งใหม่

จำไว้: HARVEST เก่งที่สุดเมื่อ “บริหารฝูง” ไม่ใช่เททุกอย่างออกทีเดียว Search, Needle และ Storm แย่งทรัพยากรจากกอง 500 ตัวเดียวกันทั้งหมด
