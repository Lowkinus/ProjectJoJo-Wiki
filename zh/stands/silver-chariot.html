SILVER CHARIOT

由移动驱动的剑士替身。跑步/冲刺会大幅提高 Speed Gauge 回复，Armor Off 可进一步推高战斗节奏。

当前中文完整指南 • 与 TH / EN 结构对齐
难度中等
Speed max100
Rush cost18
Sweep cost25

SPEED GAUGE

Idle 0.1/s • Walk 1/s • Run 11/s • Sprint 20/s

站着不动几乎不回 Speed；真正移动才是快速充能方式。

示例：Sweep 花掉 Speed 后，绕一小圈安全 sprint，比原地等条更快。

ARMOR OFF — HOLD CAPS LOCK

Speed drain 5/sClone damage 50%Cooldown = 90s + actual active time

Silver Chariot 已召唤时，长按 CAPS LOCK 充满可开启 Armor Off。Armor Off cooldown 只阻止“再次开启 Armor Off”，不会阻止普通 Stand Summon/Dismiss。Dismiss 时会先清理 clone/model/state，结束 Armor Off，并按真实持续时间计算冷却；冷却中再次 Dismiss 不会重启冷却。

示例：简单规则：点按 CAPS LOCK = 普通召唤/收回；长按到 FULL = Armor Off（可用时）。

Skill 1 — STAB

CD 0.22s • Range 3.1

快速单体刺击，不消耗 Speed Gauge。

示例：补 Gauge 时用 Stab 输出，把昂贵技能留到移动已经回好资源。

Skill 2 — RAPIER RUSH

CD 3s • Range 3.4 • Cost 18

快速剑 Rush，适合集中压制，但会消耗 Speed，因此连续使用需要穿插移动。

示例：Rush 一个目标 → 拉开跑动 → 用移动赚回 Gauge → 再回来。

Skill 3 — CIRCLE SWEEP

CD 3.5s • Area • Cost 25

大范围横扫附近多个威胁，消耗比 Rush 更高。

示例：真正被包围时再用；为一只落单僵尸花 25 Speed 很浪费。

Skill 4 — RAPIER SHOT

CD 5.2s • Range 8.2

发射一枚真实 rapier projectile，提供远程解法，并可被支持的 Barrage Guard 挡下。

示例：危险目标还没进近战范围前先射一发，再利用移动速度决定追上还是后退。

这个替身应该怎么理解？

不要只背术语

先理解循环：什么会产生资源、什么会消耗资源、眼前的问题该由哪一个技能解决。

把示例当作思路

示例不是唯一连段，而是用来解释机制为什么存在；实战时根据距离、资源和敌人数量调整。
