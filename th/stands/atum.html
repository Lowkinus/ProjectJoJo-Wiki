ADDON — ต้องใช้ Project JoJo ตัวหลัก

สกิล 1 — PUNCH

หมัดพื้นฐานของ ATUM ใช้แนว First-Contact และระบบเล็งของ Project JoJo ตัวหลัก เหมาะสำหรับต่อสู้ปกติระหว่างที่ยังไม่ได้เปิดเกมเดิมพัน

สกิล 2 — BARRAGE

หมัดรัวตามทิศเมาส์ ใช้ระบบ Rush / First-Contact ของมอดหลัก ATUM ยังตั้งใจให้เด่นด้าน Mind Game มากกว่าการยืนแลกตรง ๆ กับ Stand สาย Brawler

สกิล 3 — MIND READ / YES–NO

เปิดสถานะอ่านใจโดยใช้แต้มจาก Mind Gauge ถ้ากดซ้ำขณะสถานะยังทำงานจะปิดเองโดยไม่เสียแต้มเพิ่ม ใช้เพื่ออ่านการตัดสินใจก่อน Skill 4 และใช้เป็นระบบหลบการโจมตีที่เข้าเงื่อนไขได้ด้วย

MIND GAUGE

เริ่มที่ 0/100 การชนะเกมของ ATUM จะสุ่มให้แต้มเพิ่ม 0–3 หากอ่านใจถูกและชนะเกม ระบบจะการันตีอย่างน้อย 1 แต้ม เพื่อมีโอกาสคืนแต้มที่ใช้เปิด Mind Read

สกิล 4 — GAMBLE

ATUM ต้องพุ่งไปสัมผัสเป้าหมายจริงก่อน เกมจึงเริ่ม จากนั้นจะสุ่มหนึ่งใน 3 เกม: Rock Paper Scissors, Baseball หรือ Racing ระหว่างเกมผู้เล่นที่เกี่ยวข้องจะถูกแยกออกจากการต่อสู้ปกติและป้องกันดาเมจจากภายนอกจนจบเกม

ROCK PAPER SCISSORS

เป่ายิ้งฉุบ

เลือก Rock / Paper / Scissors เพื่อชนะอีกฝ่าย ถ้าเป้าหมายเป็นซอมบี้ระบบจะสุ่มคำตอบ ถ้าเป็นผู้เล่นอีกฝ่ายจะมี UI ของตัวเอง

อ่านใจ

ถ้าเข้าด้วย Skill 3 จะมีช่วงทายแยกก่อนเกมจริง ทายถูกขึ้น YES ทายผิดขึ้น NO แล้วค่อยเริ่มเวลาของเกม

BASEBALL

HIGH / MIDDLE / LOW

เลือกตำแหน่งตีให้ตรงกับตำแหน่งที่เป้าหมายเลือก ถ้าตรงถือว่าตีโดน ถ้าผิดถือว่าพลาด

HOME RUN

ตีถูกมีโอกาสเกิด Home Run และการตีถูกในช่วงท้ายของเวลาเป็นจังหวะพิเศษที่ให้ Home Run ตามระบบของเกม

RACING

BOOST

กดค้างเพื่อเร่งความเร็วโดยแลกกับ HP รถ ยิ่งใช้มากยิ่งต้องบริหาร HP ให้ดี

ATTACK

ชาร์จก่อนพุ่งชนอัตโนมัติ ใช้ทำดาเมจและรบกวนความเร็วของอีกคัน

BLOCK

เสีย HP เล็กน้อยเพื่อเปิดช่วงป้องกันเต็ม ใช้เคาน์เตอร์ ATTACK ได้ถ้ากดถูกจังหวะ

FINAL STRETCH

เมื่อช่วงแข่งหลักจบ จะเข้าสู่ช่วงเข้าเส้นชัยโดยจำระยะนำ–ตามไว้ แล้วแข่งกันด้วย BOOST / ATTACK / BLOCK ต่อจนมีรถเข้าเส้นชัย

วิธีเล่นจริง / กลยุทธ์

S3 → S4

แกนหลักของ ATUM คือเปิดอ่านใจ ก่อนใช้ Gamble เพื่อเอาข้อมูล YES/NO มาลดความเสี่ยงในมินิเกม

อย่าเผา Gauge ทิ้ง

Mind Gauge ไม่ได้ฟรี ถ้าไม่มีเหตุผลจะอ่านใจ เก็บแต้มไว้ก่อนมักคุ้มกว่า

Racing ต้องบริหาร HP

BOOST ใช้ HP แลกความเร็ว, ATTACK ใช้ดาเมจ+ขัดจังหวะ และ BLOCK ใช้ตอบโต้ จึงไม่ควรกดท่าเดียวตลอดเกม

ไม่ใช่ Brawler

Punch/Barrage ทำให้ ATUM สู้โลกปกติได้ แต่จุดแข็งจริงคือการอ่านคนและบังคับอีกฝ่ายเข้าสู่เกมของตัวเอง

จำไว้: ATUM เป็น Addon ของ Project JoJo ต้องเปิดมอดหลักด้วย และ Skill 4 ต้องสัมผัสเป้าหมายจริงก่อนเกมถึงจะเริ่ม
