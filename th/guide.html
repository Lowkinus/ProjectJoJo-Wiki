หน้านี้อธิบายระบบร่วมของ Project JoJo แบบภาษาง่าย: ระบบทำอะไร, ผู้เล่นต้องรู้อะไร และมีตัวอย่างให้เห็นภาพเมื่อกติกาดูซับซ้อน

PROJECT JOJO — คู่มือระบบเต็ม

1) STAND ARROW — ได้ Stand ยังไง

Stand Arrow หาได้จาก loot ในโลกและมีโอกาสดรอปจากซอมบี้ ที่ค่าเริ่มต้น 1x โอกาสดรอปจากซอมบี้อยู่ประมาณ 1 / 250 พื้นที่แนวโรงรถ กล่องเครื่องมือ ร้านช่าง หรือ mechanic storage เป็นจุดที่เหมาะกับการหา ส่วน vehicle loot ตั้งใจให้หายากกว่า

Arrow ใช้ Condition ของ Project Zomboid โดยตรง: 3/3 → 2/3 → 1/3 → หาย หรือพูดง่าย ๆ คือ 1 ดอกใช้สำเร็จได้ 3 ครั้ง และ Condition จะลดหลังการให้ Stand สำเร็จ

ตัวอย่าง: ถ้าใช้ Arrow แล้วเปลี่ยนจาก Star Platinum ไป The World เลเวลที่เคยเก็บของ Star Platinum ไม่ถูกลบ วันหลังกลับมาได้ SP อีกก็เล่นต่อจาก Progress เดิมของตัวละครนั้นได้

2) SUPER ARROW — สุ่มหรือเลือกเอง

Super Arrow ปิดเป็นค่าเริ่มต้น ถ้าปิด การใช้ Stand Arrow จะสุ่มจาก Stand Pool ที่เกมโหลดอยู่ตามปกติ

ถ้าเจ้าของโลก/เซิร์ฟเปิด Super Arrow การใช้ Arrow จะเปิดรายการ Stand ที่ลงทะเบียนอยู่จริงให้เลือก Core Stands และ official addons ที่เปิดใช้งานจะเข้ารายการอัตโนมัติ ส่วน Addon ที่ไม่ได้ติดตั้ง/ไม่ได้เปิดจะไม่โผล่มาให้เลือก

การเลือกยังถูกตรวจจากฝั่ง authority ก่อนให้ Stand เพื่อให้ SP / Host / Multiplayer ใช้กติกาเดียวกัน

อย่าสับสนกับ Infinite Arrow: Super Arrow ทำให้ “เลือกได้” แต่ Arrow ยังเสีย Condition ตามปกติ ถ้าอยากใช้ Arrow ซ้ำไม่จำกัดต้องเปิด Infinite Stand Arrow แยกอีกตัวเลือก

3) การควบคุมพื้นฐาน / Tap กับ Hold

CAPS LOCK เรียกหรือเก็บ Stand และปุ่มเลขแถวบน 1 / 2 / 3 / 4 คือ Skill 1–4

หลายสกิลมีผลต่างกันระหว่างกดสั้นกับชาร์จเต็ม เช่น Star Platinum / The World Skill 4 กดสั้นเป็น Time Dash แต่ชาร์จเต็มเป็น Time Stop, King Crimson Skill 4 กดสั้นเป็น Dash แต่ชาร์จเต็มเป็น Time Erase

ตัวอย่าง: ถ้าเพิ่งได้ Stand ใหม่ อย่าลองแค่แตะปุ่ม 1–4 แล้วสรุปว่านั่นคือสกิลทั้งหมด ลองกดค้างด้วย เพราะบางตัวเปลี่ยนความสามารถไปอีกแบบเลย

4) TARGETING MODE — เล็งแบบไหนก็ใช้กติกาการโดนเดียวกัน

ไปที่ Options → Mods → Project JoJo แล้วเลือกได้ 3 แบบ:

  • Mouse / Pointer — ใช้ทิศเคอร์เซอร์
  • Facing Direction — ใช้ทิศที่ตัวละครหัน เหมาะกับคนที่ไม่อยากพึ่งเมาส์หรือใช้ camera/view mod
  • Controller Aim — ใช้แกนเล็ง/โจมตีของจอย ถ้าสติกอยู่ใน dead-zone จะ fallback ไปทิศตัวละคร

การเปลี่ยนโหมดเล็งไม่ได้เปลี่ยนระยะ ไม่ทำให้ล็อกทะลุกำแพง และไม่ทำให้ projectile หักไปโดนเป้าเองโดยไม่มีแนว

ตัวอย่าง: ใช้ Facing Direction แล้วมีซอมบี้ยืนขวางหน้าตัวเป้าหมายที่ไกลกว่า ตัวหน้าอาจรับการโจมตีก่อนเหมือนเดิม เพราะระบบยังดู First-Contact

5) DIRECTIONAL FIRST-CONTACT

สกิลที่เป็นแนวโจมตีใช้ระยะจริงของตัวเอง แล้วตรวจสิ่งแรกที่สัมผัสแนวโจมตี ไม่เอาระยะจากตำแหน่งเมาส์มา “ตัด” ท่ายาวให้สั้น แต่ก็ไม่ให้สกิลข้ามสิ่งที่ควรขวาง

ตัวอย่าง: Star Finger ไปได้ไกลกว่าหมัดปกติ แต่ถ้ามีซอมบี้ยืนตรงแนวข้างหน้า มันไม่ควรปล่อยให้คุณชี้เมาส์เลยตัวหน้าแล้วตีตัวหลังแบบฟรี ๆ

6) BARRAGE CONTACT / CLASH / GUARD

Barrage Contact มีช่วงผ่อนเล็กน้อยเพื่อไม่ให้การรัวหมัดหลุดเพราะเฟรม/เป้าขยับจิ๋ว ๆ และสามารถชดเชย hit บางส่วนเมื่อเฟรมช้า

Barrage Clash เกิดเมื่อ Barrage ฝั่งโจมตีที่รองรับชนกันในระยะ/มุมที่เหมาะสม ฮิตที่ชนจะหักล้างกันก่อนดาเมจปกติ

Barrage Guard เป็นแนวป้องกันด้านหน้าระหว่าง Barrage ของ Stand ที่รองรับ ปัด projectile บางชนิด เช่น The World Knife, Silver Chariot Rapier Shot และ Crazy Diamond Glass/Homing

ตัวอย่าง: หันหน้าแล้ว Barrage รับมีดจากด้านหน้าได้ ไม่ได้แปลว่าคุณกันมีดจากด้านหลัง, ระเบิด AOE, ไฟทั้งวง หรือ THREE FREEZE ได้ทั้งหมด

7) TIME STOP

Star Platinum หยุดเวลา 5 วินาที และ The World 9 วินาที เป้าที่ถูกหยุดจะถูกตรึง ดาเมจที่ต้องรอจะสะสมไว้แล้วค่อยลงตอนเวลาเดินต่อ และ projectile ที่อยู่ในพื้นที่หยุดเวลาจะค้างกลางทางก่อนเดินทางต่อภายหลัง

ผู้ใช้ SP/TW ที่ติดอยู่ใน Time Stop ของอีกคนยังมีระบบตอบโต้ของ Time Stop ตัวเองตามกติกาของมอด ไม่ได้แปลว่าสามารถเดินได้ฟรีตลอด Stop ของคนอื่น

ตัวอย่าง: มีดกำลังบินไปหาเป้า แล้ว Time Stop เริ่มตอนมันอยู่กลางทาง มีดจะค้างที่จุดนั้น พอเวลาเดินต่อจึงไปต่อ ไม่ควรวาร์ปข้ามช่วงหยุด

8) TIME STOP vs TIME ERASE

Time Stop กับ Time Erase ไม่ได้เปิดทับกันแบบสองพลังเต็มพร้อมกัน ถ้า Time Stop กำลังเริ่ม/ทำงานอยู่ King Crimson ไม่สามารถเปิด Full Time Erase ใหม่แบบข้ามกติกาได้

ถ้า Erase เริ่มก่อน เวลาของ Stop จะถูกเอาไปหักกับเวลาที่ Erase เหลือก่อน ถ้า Stop ยาวกว่า ส่วนที่เหลือจึงกลายเป็นเวลาหยุดจริง

ตัวอย่าง: Erase เหลือ 4 วิ แล้วมี Stop 9 วิชนเข้ามา 4 วิแรกใช้หัก Erase เหลือ Stop จริงประมาณ 5 วิ แทนที่จะได้ Erase 4 + Stop 9 ซ้อนเต็ม ๆ

9) STAND LEVEL — Progress แยกทุก Stand

Stand แต่ละตัวเก็บเลเวล LV.1 → LV.100 แยกกัน เลเวลต่ำเริ่มที่ประมาณครึ่งหนึ่งของดาเมจเต็มและค่อย ๆ เพิ่มไปจน Full Power ที่ LV.100 การฆ่าซอมบี้ด้วย Stand ให้ EXP

เปลี่ยน Stand ไม่ลบ Progress ของตัวเก่า ถ้าปิด Stand Level System ใน Sandbox ทุก Stand ใช้ Full Power แต่ Progress ที่เคยเก็บไว้ยังถูกเก็บ ไม่ได้โดนลบทิ้ง

10) SUMMONED STAND DEFENSE

ขณะ Stand ที่ระบบลงทะเบียนถูกเรียก เจ้าของรับ NET damage ลดลง 33% โดยอิงความเสียหายจริงหลังระบบเกม/มอดอื่นจัดการแล้ว

นี่เป็น damage reduction ไม่ใช่ invulnerability — โดนรุม, โดนกัดหลายครั้ง หรือยืนผิดตำแหน่งก็ยังตายได้

11) PvP / SAFETY

ดาเมจที่ลด HP ผู้เล่นเคารพ PvP / Safety ของ Project Zomboid แต่ Project JoJo แยก “ดาเมจ” ออกจาก “Utility / Crowd Control” บางอย่าง จึงมีผลที่อาจทำงานได้โดยไม่ทำ HP damage

ตัวอย่างของระบบที่ต้องดูเงื่อนไขเฉพาะ ได้แก่ Time Stop, THREE FREEZE, Space Pull, Epitaph/Reposition, First Bomb attachment และคำสั่ง utility ของ Addon

ตัวอย่าง: The Hand ดึงเพื่อนออกจากฝูงได้ในสถานการณ์ที่ระบบอนุญาต โดยการ Pull ไม่จำเป็นต้องหมายถึงทำ HP damage ใส่เพื่อน

12) รถ / สิ่งของในโลก / Safeguard

Stand attacks ยังมีการชนกับรถและสิ่งของตามโลก แต่ระบบพยายามแยก “การชนเพื่อหยุดท่า/projectile” ออกจาก “การทำลายสถานะวัตถุ” เพื่อไม่ให้การโจมตีถี่ ๆ ไปพังรถหรือวัตถุ custom แบบผิดเจตนา

วัตถุ vanilla ที่รองรับจริง เช่นประตู หน้าต่าง barricade ต้นไม้ หรือ object ที่มี path เฉพาะ ยังสามารถใช้ interaction ที่ออกแบบไว้ได้

13) CLIENT OPTIONS — ของแต่ละคน

ใน Options → Mods → Project JoJo ผู้เล่นปรับได้เอง:

  • Stand Targeting Mode: Mouse / Facing / Controller
  • Stand HUD: Normal / Minimal / Hidden
  • HUD Opacity: 20–100%
  • HUD Scale: 70–150%
  • Personal Project JoJo Volume: 0–100%
  • Keybinds ส่วนตัว

Reset Visual / Audio / Targeting คืนค่าหน้าตา/เสียง/การเล็งโดยไม่แตะ keybinds และ Reset Keybinds ใช้คืนปุ่ม Caps Lock + 1–4 แยกต่างหาก

หน้าจอที่จำเป็นต่อ gameplay เช่น ATUM minigames, HARVEST Search และ Heaven's Door Book/Command ยังใช้งานได้แม้เลือก Hidden HUD

14) SANDBOX SETTINGS — ค่าร่วมของโลก/เซิร์ฟเวอร์

Arrow Drop Multiplier — ปรับความหายากของ Arrow

Stand Damage — ปรับดาเมจรวมของ Stand

Stand Level System — เปิด/ปิด Progress LV.1–100

Give Stand Arrow on Join — ให้ Arrow ตอนเข้าเกม

Infinite Stand Arrow — Arrow ไม่เสีย Condition หลังใช้สำเร็จ

Super Arrow — ปิดปกติ; เปิดแล้วเปลี่ยนจากสุ่มเป็นรายการเลือก Stand ที่โหลดอยู่จริง

Addon บางตัวอาจมี Sandbox ของตัวเองด้วย เช่น HARVEST มีตัวปรับความเร็วการฟื้นฝูง โดยไม่จำเป็นต้องเปลี่ยนสูตร Search

ส่วนเสริมทางการ

ATUM — อ่านการโจมตี, Soul Mark, Mind Gauge และ Gamble ผ่าน RPS / Baseball / Racing

HARVEST — บริหารฝูงสูงสุด 500 ตัว, Search Command และการคุมพื้นที่

HEAVEN'S DOOR — เปิด Book, ใช้ REWRITE เขียนคำสั่ง และควบคุม AI/งานของซอมบี้ที่ถูกเขียน

จำง่าย ๆ: ถ้าเป็นค่า “ทุกคนในโลกต้องใช้เหมือนกัน” ให้มองหา Sandbox ถ้าเป็น “หน้าจอ/เสียง/วิธีเล็งของฉัน” ให้มองหา Client Options
