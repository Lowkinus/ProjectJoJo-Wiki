HARVEST

HARVEST 只有一份主资源：最多 500 个单位的共享 colony。Shot、Swarm、Storm 与 Search 都会竞争这一资源。

当前中文完整指南 • 与 TH / EN 结构对齐
Addonv0.4.26
Colony max500
Searchx1–x500
资源原则Combat + Search shared

如何获得 HARVEST

启用 Project JoJo Core 与 HARVEST addon，然后使用普通 Stand Arrow。HARVEST 会加入共享 Stand Pool；开启 Super Arrow 且 addon 已启用时，也会进入选择列表。

操作

CAPS LOCK — Summon / Dismiss
1 — HARVEST SHOT
2 — NEEDLE SWARM
3 — HARVEST SEARCH COMMAND
4 — HARVEST STORM

战斗遵循 Core Targeting Mode。Search Command 属于 gameplay UI，使用鼠标选择 template、数量与 crew。

COLONY — 0 / 500

战斗与 Search 共用最多 500 Harvest。派去 Search 的单位会被 reserved，在任务返回或 Recall 前降低可回复上限。

  • 静止：grace period 后 0.80 / sec
  • 坐下 / Vehicle：4.05 / sec
  • Rest：9.00 / sec
  • Sleep：14.40 / sec

Walk/Run 不是普通回复状态。HARVEST regeneration Sandbox option 会缩放 colony recovery，但不会直接加速 Search。

例：派 150 个去 Search 后，可用回复上限约为 350；系统不会免费再生成另一份 150 人 crew。

SKILL 1 — HARVEST SHOT

消耗 1 Harvest。发出一个单位做快速远程骚扰，轻伤 + mini knockback/CC；按住可连续逐个发送。

支持的 Barrage Guard 可以从正面防住 Shot。

SKILL 2 — NEEDLE SWARM

最低投入：7 Harvest。按住可继续增加单位。选中的群体附着到一个目标，等待后一起刺击；投入越大回报越高。

目标死亡/消失或在结算前超出有效 leash 时，pending group 会取消，reserved 单位由系统退回。

SKILL 3 — HARVEST SEARCH COMMAND

打开 Search Command，选择你 inventory 里真实存在的 InventoryItem作为模板，再选需要的数量与派遣 crew。

Template handling

Search 不限于药品。它会检查 nested bags，并尽量区分关键状态，例如满/半/空液体容器、condition/used-state 与相关武器状态，而不只是按 FullType 混在一起。

对于 modded/runtime item，authority 会在 START SEARCH 预留 crew 之前预检请求的 item 能否安全重建；不支持时应给兼容性提示，而不是先扣队伍再失败。

Quantity / Crew

  • Quantity：x1–x500
  • x1–x20 = 最低 20 Harvest
  • x21–x500 = 最低 crew 等于请求数量
  • 超过最低 crew 会加快 Search work
  • 整个 batch 总重量增加运输时间

HARVEST Stand Level 可通过成长降低设计好的 Search-work 部分；出发、返回与交付不会被压成瞬间传送。

ACTIVE JOBS / RECALL

多个任务可独立存在。UI 显示 phase/ETA；RECALL 只取消对应 job，立即释放它 reserved 的 Harvest，并丢弃尚未交付的 item。

Search 音效按 job 独立并跟随实际 job 位置，所以多个同时任务可正确播放；个人 Project JoJo Volume 同样生效。

SKILL 4 — HARVEST STORM

最低投入：33 Harvest。把 colony 的一部分投入自身周围做重复范围压制、mini knockback 与人群打断；投入越大持续越久，直到设计上限。

Barrage Guard 对每个 guarding player 独立判断：某个玩家成功 Guard 只会挡掉他自己的 Storm hit，不会删掉整场 Storm。

如何管理 COLONY

不要把 500 当作每次都该打光的弹药。它是一份预算，要在活过当前战斗与派工人为未来拿资源之间分配。

例：300 个正在 Search 时只剩 200 可战斗；如果这些又大部分投入超大 Storm，在任务回来/Recall 前，Shot 与 Needle Swarm 几乎没资源。

CLIENT / SANDBOX OPTIONS

HARVEST 遵循 Core 的 Normal / Minimal / Hidden HUD、HUD Opacity/Scale、Personal Volume 与 Targeting Mode；Search Command 因为是 gameplay UI 始终可用。

Addon 还提供 Harvest Regeneration Speed，只缩放 colony recovery，不会加速 Search 或绕过 reservation ceiling。

简单循环：看剩余 Colony → 决定这场战斗值得投入多少 → 记住每个 Search crew 回来前都不属于你的战斗预算。
