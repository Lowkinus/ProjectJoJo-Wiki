替身之箭选中了你。然后呢？

新手指南

看完这一页，你就已经足够开始玩。拿到替身后，再打开对应详情页看更深的技能规则与例子。

BUILD 42+SP / HOST / MP
01 • STAND ARROW

找到替身之箭

替身之箭会出现在世界战利品里，也会低概率由僵尸掉落。默认 1x 时僵尸概率约 1 / 250。Garage、tool crate 与 mechanic storage 都值得检查。

02 • USE IT

一支 Arrow 有 3 次成功使用

Condition：3/3 → 2/3 → 1/3 → 消失。普通情况下会从已加载替身中随机。重新抽替身不会清掉旧替身的进度。

服务器开启 Super Arrow 后，会出现替身选择列表；除非同时开启 Infinite Stand Arrow，否则仍只有三次成功使用。

03 • CONTROLS

先召唤，再用 1–4

CAPS LOCK 召唤/收回替身，主键盘 1 / 2 / 3 / 4 对应技能。

记得尝试 Tap 与 Hold：同一个键可能是两种完全不同动作，例如 Skill 4 Tap = Time Dash，Full charge = Time Stop。

04 • AIM

选择你喜欢的瞄准方式

在 Options → Mods → Project JoJo 选择 Mouse / Pointer、Facing Direction 或 Controller Aim。它只改变输入方向，不会绕过碰撞与 first-contact。

05 • FIRST CONTACT

攻击线上的第一个东西很重要

技能按自己的真实射程工作，但攻击线上的第一个有效身体/世界碰撞会阻挡后面的目标。墙、门、窗和车辆仍然重要。

06 • LEVEL

每个替身独立成长

每个替身分别保存 Lv.1–100。由替身造成的僵尸击杀给予 EXP；切换替身不会删除旧替身等级。

07 • BARRAGE

Barrage 不只是伤害

支持的 Barrage 可以与另一个攻击型 Barrage 发生 Clash；部分 Barrage 还会产生 Barrage Guard，从前方挡住支持的投射物。

08 • TIME

Time Stop 不只暂停角色

SP 停时 5 秒、TW 9 秒。停止区域中的角色与投射物会暂停，延迟伤害会在时间恢复时结算。

09 • PVP

Safety 保护 HP；Utility 有自己的规则

HP 伤害尊重 Project Zomboid PvP/Safety。Freeze、Pull、位移等 Utility/CC 可能有独立规则，测试队友前先看替身详情页。

10 • HUD

把界面调成适合你的屏幕

可选 Normal / Minimal / Hidden HUD、透明度 20–100%、缩放 70–150%、个人 Project JoJo 音量 0–100% 与自定义按键。这些不会改变服务器平衡。

11 • SERVER SETTINGS

世界拥有者决定成长节奏

Sandbox 包括 Arrow Drop、Stand Damage、Stand Level、Arrow on Join、Infinite Stand Arrow、Super Arrow，以及部分 Addon 自己的设置。

例：生存服可以让 Arrow 稀有并保留等级成长；JoJo 主打服务器可以加入就给 Arrow，并开启 Super Arrow 直接选替身。

你已经可以开始玩了。回到替身列表，打开你实际抽到的替身页；每个技能、数值与实际用途都在那里。
