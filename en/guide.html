PROJECT JOJO — CURRENT SYSTEM GUIDE

Super Arrow — optional Sandbox Stand selection

OFF by default. Normal Stand Arrows keep their random roll. When the world/server enables Super Arrow, using an Arrow shows a server-authoritative choice list built from the currently registered Stand Pool. Core Stands and enabled supported addons are listed automatically.

The selected Stand is still validated by authority before assignment. Arrow Condition still uses the normal 3-use system unless Infinite Stand Arrow is also enabled.

Targeting — mouse is optional

Open Options → Mods → Project JoJo and choose Mouse / Pointer, Facing Direction, or Controller Aim.

Mouse / Pointer is the classic/default mode and uses the cursor direction. Facing Direction uses the direction the player character is physically facing, so combat no longer depends on a visible cursor. It is useful for keyboard/controller players and for immersive camera/view mods such as Project Viewpoint where the cursor may be hidden or intentionally ignored. Controller Aim reads Project Zomboid's controller aiming axis / attack indicator and falls back to Facing Direction while the stick is inside the dead-zone.

All three modes still feed the same Directional First-Contact rules. The skill keeps its real range; the first valid body/contact on the attack line wins; walls, doors, windows and vehicles still block attacks where appropriate. Facing Direction is not a through-wall auto-lock.

Barrage steering

Barrages update from the selected Targeting Mode while active: cursor in Mouse mode, player facing in Facing Direction, controller vector in Controller Aim. Existing contact maintenance, Barrage Guard and Barrage Clash rules remain unchanged.

Personal HUD & Audio

Stand HUD can be Normal / Minimal / Hidden, with 20–100% opacity, 70–150% scale and 0–100% personal Project JoJo volume. These are client preferences, not Sandbox authority. Required addon gameplay screens remain usable even with Hidden HUD.

Reset buttons

Reset Visual / Audio / Targeting restores HUD Mode = Normal, HUD Opacity = 100%, HUD Scale = 100%, Personal Volume = 100% and Targeting Mode = Mouse / Pointer. It does not change keybinds.

Reset Keybinds separately restores Caps Lock and top-row 1 / 2 / 3 / 4. Both buttons save through Native Mod Options.

Summoned Stand Defense

While a registered Stand is summoned, the owner takes 33% less net damage. The refund is calculated from observed health/body-part loss after vanilla/other-mod reductions.

World / Vehicle Safety

Stand attacks still collide with vehicles, but rapid environment hits no longer mutate vehicle durability/state. Unknown custom-map objects are protected unless they explicitly opt in to Stand damage. Known vanilla doors/windows/trees/barricades/thumpables continue to use their supported damage paths.

Core combat

Directional First-Contact, Barrage Contact, Barrage Guard, Time Stop, Time Erase, Barrage Clash, PvP / Safety integration and multiplayer synchronization remain shared systems.

Stand progression

Each Stand keeps separate Lv.1–100 progression. Lv.1 starts at 50% of the balanced level-scaled damage and Lv.100 reaches full power. Switching Stands keeps previous Stand progress.

Official addons

ATUM — Soul Marks, Mind Gauge, prediction and RPS/Baseball/Racing wagers.

HARVEST — 500-unit colony, Search Command, modded-item template handling, level-scaled Search and area control.

HEAVEN'S DOOR — book rewriting, persistent commands, Scripted Written-Zombie AI and Book Traps.

Server vs client settings

Sandbox controls shared gameplay balance such as Arrow Drop Rate, Stand Damage, Levels, Arrow on Join, Infinite Arrow and the optional Super Arrow choice mode. Client Options control Targeting Mode, Stand HUD mode/scale/opacity, personal Project JoJo volume and personal keybinds.
