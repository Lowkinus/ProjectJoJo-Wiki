ระบบกลางปัจจุบันของ Project JoJo v0.23.0.246 และ Addon ทางการ

Build 42.21 • Core v0.23.0.246

PROJECT JOJO — คู่มือระบบปัจจุบัน

Targeting

Options → Mods → Project JoJo มี Mouse / Pointer, Facing Direction และ Controller Aim. Facing/Controller ส่งทิศเข้า Directional First-Contact จึงเลือกเป้าหมาย/จุดปะทะแรกจริงและยังติดกำแพง หน้าต่าง รถ ตามปกติ. Controller Aim อ่านแกนเล็งของจอยในเกมและ fallback เป็น Facing Direction ตอนอนาล็อกอยู่ใน dead-zone.

HUD / เสียงส่วนตัว

Stand HUD เลือก Normal / Minimal / Hidden, Opacity 20–100%, Scale 70–150% และ Personal Project JoJo Volume 0–100%. ทั้งหมดเป็น Client Preference ไม่ใช่ Sandbox. UI ที่ต้องใช้เล่นจริงของ Addon ยังคงเปิดได้.

Summoned Stand Defense

ระหว่างเรียก Stand ที่ลงทะเบียนอยู่ เจ้าของได้รับ ดาเมจสุทธิลดลง 33% โดยคำนวณจาก Health/Body Part loss ที่เกิดขึ้นจริงหลังระบบลดดาเมจอื่น.

World / Vehicle Safety

สกิล Stand ยังชนรถ แต่ rapid environment hit จะไม่แก้ durability/state ของรถซ้ำ ๆ อีก. Object แผนที่จากมอดที่ระบบไม่รู้จักจะปลอดภัยโดยค่าเริ่มต้น เว้นแต่ opt-in ให้ Stand ทำลายได้. ประตู/หน้าต่าง/ต้นไม้/สิ่งกีดขวาง vanilla ที่รองรับยังใช้ damage path ของมันตามเดิม.

Core combat

Directional First-Contact, Barrage Contact, Barrage Guard, Time Stop, Time Erase, Barrage Clash, PvP / Safety และ Multiplayer synchronization ยังเป็นระบบกลาง.

Stand progression

แต่ละ Stand เก็บ Lv.1–100 แยกกัน เลเวลต่ำดาเมจน้อยกว่าและ Lv.100 ถึง full level scaling. เปลี่ยน Stand แล้ว Progress ตัวเก่าไม่หาย.

Official addons

ATUM — Soul Mark, Mind Gauge, Prediction และเกม RPS/Baseball/Racing.

HARVEST — Colony 500 ตัว, Search Command, Search ที่เร็วขึ้นตาม Stand Level และ AOE control.

Server vs Client settings

Sandbox ใช้กับบาลานซ์ร่วม เช่น Arrow Drop Rate, Stand Damage, Levels, Arrow on Join, Infinite Arrow. Targeting, HUD และ Personal Volume เป็นค่าของแต่ละ Client.
