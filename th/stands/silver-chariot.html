PLAYSTYLE • นักดาบเร็ว • Speed Gauge • ยิง Rapier

SILVER CHARIOT

สายดาบที่ “การเคลื่อนที่” คือระบบทรัพยากร ยิ่งวิ่ง/สปรินต์ Speed Gauge ยิ่งฟื้นเร็ว และ Gauge ถูกใช้กับ Rush/Sweep

ปรับคู่มือตามไฟล์ล่าสุด • Core v0.23.0.280
ความยากกลาง
Speed สูงสุด100
Rush ใช้18
Sweep ใช้25

SPEED GAUGE

Idle 0.1/s • Walk 1/s • Run 11/s • Sprint 20/s

ยืนนิ่งแทบไม่ฟื้น Speed การเดิน/วิ่งจริงคือวิธีเติม Gauge ให้เร็ว

ตัวอย่าง: หลังใช้ Sweep ไป ให้สปรินต์วนสั้น ๆ ในพื้นที่ปลอดภัยแทนการยืนนิ่งรอ Gauge

Skill 1 — STAB

CD 0.22s • Range 3.1

แทงเป้าเดี่ยวเร็วและไม่กิน Speed Gauge

ตัวอย่าง: ช่วงกำลังเติม Gauge ใช้ Stab ทำดาเมจไปก่อน แล้วเก็บสกิลกิน Gauge ไว้ตอนพร้อม

Skill 2 — RAPIER RUSH

CD 3s • Range 3.4 • Cost 18

รัวดาบกดเป้าหมายเร็วแต่กิน Speed 18 ถ้าจะใช้ซ้ำต้องขยับเติมทรัพยากรระหว่างไฟต์

ตัวอย่าง: รัวใส่เป้าหนึ่งตัว ถอนออกไปวิ่งเติม Gauge แล้วกลับเข้ามารอบใหม่

Skill 3 — CIRCLE SWEEP

CD 3.5s • Area • Cost 25

กวาดดาบรอบตัวสำหรับหลายเป้าและกิน Speed มากกว่า Rush

ตัวอย่าง: ใช้ตอนโดนล้อมจริง ๆ ถ้าเสีย 25 Speed เพื่อซอมบี้ตัวเดียวถือว่าเปลืองจุดเด่นของ Stand

Skill 4 — RAPIER SHOT

CD 5.2s • Range 8.2

ยิงดาบ Rapier เป็นโปรเจกไทล์จริงหนึ่งเล่ม ทำให้ Silver Chariot มีทางเล่นระยะไกล และถูก Barrage Guard ที่รองรับปัดได้

ตัวอย่าง: ยิงตัวอันตรายก่อนเข้าระยะประชิด แล้วใช้ความเร็วตัดสินใจว่าจะบุกต่อหรือถอย

วิธีคิดเวลาเล่น STAND นี้

ไม่ต้องจำศัพท์ยาก

จำวงจรง่าย ๆ ว่าอะไรใช้เติมทรัพยากร อะไรใช้ทรัพยากร และสกิลไหนแก้สถานการณ์ตรงหน้า

ใช้ตัวอย่างเป็นแนวทาง

ตัวอย่างด้านบนไม่ใช่คอมโบบังคับ แต่ใช้บอกว่าระบบนั้นมีไว้แก้ปัญหาอะไร แล้วคุณค่อยปรับตามไฟต์จริง
