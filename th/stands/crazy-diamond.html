ความยากสูง
เหมาะกับคนที่ชอบสลับบทบาทระหว่างตัวตี กับตัวช่วยทีม และชอบระบบ Mark ต่อเนื่อง
Restore Gaugeสูงสุด 100
Passive0.01 / วิ
Mark60 วิ

RESTORE GAUGE

Punch +0.30Rush +0.09375 / hitGlass +0.375

เกจฟื้นเองช้ามาก ประมาณ 1 แต้มต่อ 100 วิ ทางหลักคือออกไปตีจริงแล้วค่อยเอาเกจกลับมาช่วยทีม ค่าใช้ Restore Punch 6.25, Restore Rush 1.25 ต่อ heal tick และ Glass Homing 6.25

สกิล 1 — DORAAA / RESTORE PUNCH

CD 0.37 วิระยะ 2.8ชาร์จเต็ม 1.2 วิ

Attack Mode เป็นหมัดปกติ ส่วน Restore Mode ฮีลประมาณ 18 และชาร์จเต็มประมาณ 36 เสียเกจเมื่อ Restore สำเร็จเท่านั้น และ Crazy Diamond ไม่ใช้หมัดนี้ฮีลตัวเอง

สกิล 2 — DORA RUSH / RESTORE RUSH

CD 5 วิ17 / 25 hitAttack = Guard

Attack Mode เป็น Barrage และเปิด Barrage Guard; Restore Mode ฮีลประมาณ 4 ต่อ tick หรือราว 8.4 ตอนชาร์จเต็ม เสีย 1.25 Gauge ต่อ tick ที่ฟื้นจริง และไม่เข้า Barrage Clash

สกิล 3 — ATTACK / RESTORE MODE

CD 0.25 วิสลับทันทีเปลี่ยนสกิล 1/2/4

โหมด Attack เอาไว้หาเกจและทำดาเมจ โหมด Restore เปลี่ยน Punch/Rush เป็นการฟื้นและเปลี่ยน Glass Shot เป็น Glass Homing

สกิล 4 ATTACK — GLASS SHOT

CD 5.2 วิระยะ 9Mark 60 วิ

ยิงตามแนวเมาส์ ถ้าโดนตัวละครจริงจะ Mark ตัวนั้น ถ้าไม่โดนแล้วไปชนฉาก ระบบจำจุดกระทบเป็น Mark แทน มี Mark ได้ครั้งละหนึ่งเป้า

สกิล 4 RESTORE — GLASS HOMING

CD 7 วิใช้ 6.25 Gaugeความเร็ว 7.15 ช่อง/วิ

ต้องมี Mark และอยู่ประมาณชั้นเดียวกัน เศษแก้วจะพุ่งออกตามทิศเมาส์ก่อนแล้วค่อยเลี้ยวกลับหา Mark มันเดินทางจริง จึงชนกำแพง รถ หรือโดนตัวอื่นบังได้ การใช้สำเร็จจะต่ออายุ Mark กลับไป 60 วิ

Restore ไม่ได้มีไว้ฮีลคนอย่างเดียว: ระบบปัจจุบันยังรองรับการกู้สภาพของวัตถุหลายชนิด เช่นชิ้นส่วนรถ condition ไอเท็ม อาหาร ประตู หน้าต่าง barricade และของในโลกที่ระบบรู้จัก

วิธีเล่นจริง / กลยุทธ์

วงจรหลัก

Attack Mode → Punch/Barrage เติม Gauge → สลับ Restore ตอนมีเหตุผล → กลับ Attack ก่อนเกจแห้ง นี่คือหัวใจของตัวนี้

Glass Setup

ยิง Glass Shot ให้โดนตัวที่อยากตาม → สลับ Restore → ยิง Homing จากมุมที่อีกฝ่ายคิดว่าเรายิงไม่ถึง เพราะลูกแก้วต้องวิ่งจริง ระวังมีตัวอื่นรับแทน

เล่นทีม

อย่าเท Gauge หมดกับ Restore Rush ถ้าไม่จำเป็น เก็บอย่างน้อยพอสำหรับ Punch/Homing จะยืดเวลาเล่น Support ได้เยอะ

Barrage Guard

ถ้าต้องกันโปรเจกไทล์ ต้องอยู่ Attack Mode เพราะ Restore Rush ไม่เปิด Guard อย่าสลับโหมดผิดตอนมีมีดบินมา

จำไว้: เกจฟื้นเองแทบไม่ช่วย ถ้าเล่นเป็นหมออย่างเดียวโดยไม่ออกไปตี สุดท้ายจะไม่มีอะไรให้ใช้
