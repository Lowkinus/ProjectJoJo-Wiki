ATUM

ATUM ไม่ได้ชนะด้วยดาเมจตรงอย่างเดียว จุดเด่นคืออ่านจังหวะของคู่ต่อสู้ ทำ Soul Mark แล้วลากสถานการณ์เข้าสู่ RPS, Baseball หรือ Racing ที่มีกติกาของตัวเอง

เริ่มใช้ ATUM ยังไง

เปิด Project JoJo Core พร้อม ATUM Addon แล้วใช้ Stand Arrow ปกติ ATUM จะเข้ารวมใน Stand Pool ไม่มี Arrow แยกสำหรับ ATUM ถ้าโลกเปิด Super Arrow และ Addon นี้ทำงานอยู่ ATUM จะขึ้นในรายการเลือกอัตโนมัติ

CONTROLS

CAPS LOCK — เรียก / เก็บ Stand
1 — Punch
2 — Barrage
3 — Mind Read
4 — Gamble

การโจมตีปกติใช้ Targeting Mode ของ Core: Mouse / Pointer, Facing Direction หรือ Controller Aim ส่วนหน้าจอมินิเกมเป็น gameplay UI และยังใช้ pointer/ปุ่มของเกมตามที่หน้าจอนั้นต้องการ

MIND GAUGE — 0 / 100

Mind Point เป็นทรัพยากรของ Skill 3 การเปิด Mind Read ใช้ 1 แต้ม จึงไม่ใช่สกิลที่ควรกดทิ้งแบบไม่มีแผน

  • ชนะ RPS / Baseball: ได้ +0 ถึง +3
  • ชนะ Racing: ได้ +2 ถึง +5
  • FULL-S3 ทายถูกและชนะ: +1 เพิ่ม

ตัวอย่าง: ถ้าคุณเหลือ Mind น้อยและกด Read ทุกครั้งที่เห็นศัตรูเดินมา ในจังหวะที่ต้องอ่านจริงอาจไม่มีแต้มเหลือ

SKILL 1 — PUNCH

หมัดประชิดพื้นฐาน ใช้กดดันและเป็น reference ของระยะสัมผัสจริงที่หลายระบบของ ATUM ใช้ร่วมกัน

SKILL 2 — BARRAGE

รัวหมัดประชิดของ ATUM ใช้ระบบ Barrage กลางของ Project JoJo เช่นการเล็งตาม Targeting Mode และ interaction ที่รองรับ

SKILL 3 — MIND READ

Tap / ปล่อยก่อน FULL — DODGE READ

ใช้ 1 Mind Point แล้วเปิดหน้าต่างอ่านการโจมตีประมาณ 10 วินาที ระบบไม่ได้ทำงานเพราะเป้า “เดินมาใกล้” — ต้องมีการโจมตีจริงที่เข้าเงื่อนไข

ถ้าอ่านการโจมตีของ เป้าที่ไม่ใช่ผู้เล่น สำเร็จ ATUM จะหลบตามระบบและทำ Soul Mark 3 นาที ให้ผู้โจมตีตัวนั้น ผู้เล่นไม่ถูก Soul Mark

ตัวอย่าง: ซอมบี้กำลังเข้าระยะกัด → เปิด DODGE READ → ถ้าการกัดจริง trigger การอ่าน ซอมบี้ตัวนั้นถูก Mark แล้วสามารถถูกดึงเข้าเดิมพันภายหลัง

Hold จน FULL — GAMBLE READ

ใช้ 1 Mind Point เพื่อเตรียมเส้นทางทาย YES / NO สำหรับ Gamble ไม่ใช่โหมดหลบแบบ Tap เมื่อ Gamble สัมผัสเป้าจริง การทายที่เตรียมไว้จึงถูกใช้

ถ้ายกเลิก Read ที่ยังไม่ถูก trigger/ใช้ก่อนหมดเวลา ระบบคืน Mind Point 1 แต้ม แต่ Read ที่ถูกใช้ไปแล้วหรือหมดเวลาไม่คืน

SOUL MARK / MULTI-SOUL GAMBLE

Soul Mark แยกตามเจ้าของ ATUM แต่ละคน เมื่อ Gamble เริ่ม ระบบมองหาเป้าที่ถูก Mark ซึ่งยังมีชีวิตและอยู่ใกล้เป้าหลักในระยะที่ระบบรองรับ แล้วผูกพวกมันเข้ากับเดิมพันเดียวกัน

หน้าจอมินิเกมยังเล่นกับ “เป้าหลัก” แต่ผลของ Soul Extraction สามารถกระจายไปยัง marked souls ที่ถูก bind ตั้งแต่เริ่ม Gamble ได้

จำนวนเป้าที่ bind ถูกล็อกตอนเกมเริ่ม ไม่ใช่ว่าซอมบี้ที่เดินเข้ามาทีหลังจะถูกดูดเข้าพนันกลางเกมเอง

SKILL 4 — GAMBLE / AUTO GAMBLE

Tap 4 ต้องสัมผัสเป้าจริงก่อนจึงเริ่ม Gamble แล้วเซิร์ฟเวอร์สุ่มหนึ่งใน 3 เกม:

  • Rock Paper Scissors
  • Baseball
  • Racing

Hold Skill 4 จน FULL เปิด/ปิด AUTO GAMBLE PASSIVE ขณะเปิดอยู่ Tap-4 แบบปกติถูกล็อก และ DODGE READ ที่สำเร็จสามารถท้าผู้โจมตีตัวจริงเข้าพนันโดยอัตโนมัติ

FULL S3 → Tap S4 คือคอมโบ Prediction ที่เพิ่มช่วง YES/NO ก่อน Gamble

RPS — ROCK PAPER SCISSORS

ผู้ถูกท้ามีเวลาตอบตามหน้าจอ ถ้าเป็น AI การเลือกจัดการจากฝั่ง authority FULL-S3 prediction จะเพิ่มช่วงอ่าน YES/NO ตามระบบทายของ ATUM

ใช้เมื่อไหร่: เป็นเกมที่อ่านง่ายที่สุด เหมาะกับการ Gamble ที่ไม่ต้องบริหาร HP รถหรือ timing ของการตีลูก

BASEBALL

Pitcher เลือก HIGH / MIDDLE / LOW ถ้าฝั่งผู้เล่นไม่ตอบในเวลาที่กำหนด ระบบสามารถสุ่ม pitch ต่อให้เกมเดินต่อ แทนการตัดสินแพ้ชนะด้วย timeout แบบง่าย ๆ

ฝั่งตีเลือกจังหวะ/ตำแหน่งให้ตรง Pitch การตีถูกในช่วงท้ายมีเงื่อนไข Home Run ที่ดีกว่า และผล Prediction ใช้คำตอบ pitch ที่ถูกล็อกไว้จริง

RACING

เป็นเกมยาวที่สุด จึงให้ Mind reward ฐานสูงกว่าเกมอื่น ผู้เล่นบริหารรถด้วย BOOST / ATTACK / BLOCK และมี Launch Mash ช่วงเปิดเกมด้วยการกด Skill 1 รัวเพื่อสะสมโบนัสออกตัวภายใต้เพดาน/diminishing returns

รถที่ HP หมดหรือหลุดเงื่อนไขสนามเป็นฝ่ายแพ้ แต่ฝั่งที่เหลือต้องเข้าเส้นชัยตามกติกา ไม่ใช่รถอีกคันหายแล้วชนะทันทีทุกกรณี

WINNER'S HIGH

ผู้เล่นมนุษย์ที่ชนะมินิเกมจะได้รับผลฟื้นสภาพอารมณ์ ปัจจุบัน Stress, Panic, Unhappiness และ Boredom ถูกล้างเป็น 0 และถ้า Build/Framework เปิดค่า Anger หรือ Fear ในรูปที่ระบบเข้าถึงได้ก็พยายามล้างเป็น 0 ด้วย

Winner's High ไม่ใช่การฮีลร่างกาย จึงไม่เติม Hunger, Thirst, Fatigue, Pain และไม่รักษาบาดแผล

ตัวอย่าง: ถ้าตัวละครเครียด/เบื่อ/ไม่มีความสุขมากจากการเอาตัวรอด ชนะเกม ATUM แล้วอารมณ์ด้านลบกลุ่มนั้นหาย แต่ขาหักหรือหิวอยู่ก็ยังเหมือนเดิม

MINIGAME PROTECTION

ผู้เข้าร่วมจะถูกป้องกัน/phase จากการต่อสู้ภายนอกชั่วคราวระหว่างเกม เพื่อไม่ให้มินิเกมพังเพราะมีคนที่สามเข้ามาตี และจะคืน visibility/protection เมื่อเกมจบหรือระบบ cleanup ทำงาน

CLIENT OPTIONS

ATUM ใช้ Stand HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Project JoJo Volume และ Targeting Mode ของ Core หน้าจอมินิเกมยังเปิดได้เพราะเป็น gameplay UI ที่จำเป็น

วิธีคิดเวลาเล่น: ATUM ไม่ใช่ “กด 4 แล้วบังคับชนะ” วงจรที่ดีคืออ่านจังหวะ → สร้าง Mark/เก็บข้อมูล → เลือกว่าจะ Gamble ตอนใด → บริหาร Mind ให้มีพอสำหรับครั้งต่อไป
