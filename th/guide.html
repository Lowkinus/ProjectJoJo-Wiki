ระบบกลางปัจจุบันของ Project JoJo v0.23.0.250 และ Addon ทางการ

Build 42.21 • Core v0.23.0.250

PROJECT JOJO — คู่มือระบบปัจจุบัน

Super Arrow — Sandbox สำหรับเลือก Stand

ค่าเริ่มต้นปิด ศรจะสุ่มเหมือนเดิม ถ้าโลก/เซิร์ฟเวอร์เปิด Super Arrow ตอนใช้ศรจะขึ้นรายชื่อ Stand ที่ลงทะเบียนและโหลดอยู่จริงให้เลือก โดย Core และ Official Addon ที่เปิดอยู่จะเข้ารายชื่ออัตโนมัติ

ฝั่ง Authority ยังตรวจ Stand ที่เลือกก่อนมอบจริง และ Condition ของศรยังใช้ระบบ 3 ครั้งตามเดิม เว้นแต่เปิด Infinite Stand Arrow เพิ่ม

Targeting — ไม่จำเป็นต้องใช้เมาส์

เข้า Options → Mods → Project JoJo แล้วเลือก Mouse / Pointer, Facing Direction หรือ Controller Aim

Mouse / Pointer คือแบบเดิมและเป็นค่าเริ่มต้น ใช้ทิศจากเคอร์เซอร์. Facing Direction ใช้ทิศที่ตัวละครกำลังหันหน้าแทนตำแหน่งเมาส์ จึงเหมาะกับคนเล่นคีย์บอร์ด/จอย หรือมอดกล้องแนว immersive อย่าง Project Viewpoint ที่ซ่อนหรือไม่อยากพึ่งเคอร์เซอร์. Controller Aim อ่านแกนเล็ง/Attack Indicator ของจอยใน Project Zomboid และ fallback เป็น Facing Direction เมื่ออนาล็อกอยู่ใน dead-zone

ทั้ง 3 แบบยังใช้กฎ Directional First-Contact เดียวกัน: สกิลใช้ระยะจริง ตัวหรือจุดปะทะแรกตามแนวโจมตีโดนก่อน และกำแพง ประตู หน้าต่าง รถ ยังคงบังท่าที่ควรโดนบัง. Facing Direction ไม่ใช่ auto-lock ทะลุกำแพง

Barrage steering

Barrage อัปเดตทิศตาม Targeting Mode ที่เลือกตลอดการรัว: ตามเมาส์ใน Mouse Mode, ตามหน้าตัวละครใน Facing Direction และตามแกนจอยใน Controller Aim. ระบบ Contact, Barrage Guard และ Barrage Clash เดิมยังอยู่

HUD / เสียงส่วนตัว

Stand HUD เลือก Normal / Minimal / Hidden, Opacity 20–100%, Scale 70–150% และ Personal Project JoJo Volume 0–100%. ทั้งหมดเป็น Client Preference ไม่ใช่ Sandbox และหน้าจอ Addon ที่จำเป็นต่อการเล่นยังเปิดได้แม้ซ่อน HUD

ปุ่ม Reset

Reset Visual / Audio / Targeting คืน HUD Mode = Normal, HUD Opacity = 100%, HUD Scale = 100%, Personal Volume = 100% และ Targeting Mode = Mouse / Pointer โดยไม่แตะ Keybind

Reset Keybinds แยกอีกปุ่ม คืน Caps Lock และ 1 / 2 / 3 / 4 แถวบน ทั้งสองปุ่มบันทึกผ่าน Native Mod Options

Summoned Stand Defense

ระหว่างเรียก Stand ที่ลงทะเบียนอยู่ เจ้าของได้รับ ดาเมจสุทธิลดลง 33% โดยคำนวณจาก Health/Body Part loss ที่เกิดขึ้นจริงหลังระบบลดดาเมจอื่น

World / Vehicle Safety

สกิล Stand ยังชนรถ แต่ rapid environment hit จะไม่แก้ durability/state ของรถซ้ำ ๆ อีก. Object แผนที่จากมอดที่ระบบไม่รู้จักจะปลอดภัยโดยค่าเริ่มต้น เว้นแต่ opt-in ให้ Stand ทำลายได้. ประตู/หน้าต่าง/ต้นไม้/สิ่งกีดขวาง vanilla ที่รองรับยังใช้ damage path ของมันตามเดิม

Core combat

Directional First-Contact, Barrage Contact, Barrage Guard, Time Stop, Time Erase, Barrage Clash, PvP / Safety และ Multiplayer synchronization ยังเป็นระบบกลาง

Stand progression

แต่ละ Stand เก็บ Lv.1–100 แยกกัน Lv.1 เริ่มที่ 50% ของดาเมจตามระบบเลเวลและ Lv.100 ถึงพลังเต็ม เปลี่ยน Stand แล้ว Progress ตัวเก่าไม่หาย

Official addons

ATUM — Soul Mark, Mind Gauge, Prediction และเกม RPS/Baseball/Racing

HARVEST — Colony 500 ตัว, Search Command, รองรับ Template จากมอด, Search เร็วขึ้นตาม Stand Level และ AOE control

HEAVEN'S DOOR — เปิดเป้าหมายเป็นหนังสือ เขียนคำสั่งถาวร คุม Written-Zombie AI และ Book Trap

Server vs Client settings

Sandbox ใช้กับบาลานซ์ร่วม เช่น Arrow Drop Rate, Stand Damage, Levels, Arrow on Join, Infinite Arrow และ Super Arrow สำหรับเลือก Stand. Client Options ใช้กับ Targeting Mode, Stand HUD, Scale/Opacity, Personal Volume และ Keybind ของผู้เล่นแต่ละคน
