ADDON • Mind Reading / Soul Marks / Gambling

ATUM

D’Arby’s mind-game Stand: read attacks, mark souls and turn contact into RPS, Baseball or Racing wagers.

Do you trust your instincts?

ATUM is a Project JoJo addon built around mind games, prediction, Soul Marks and gambling rather than raw physical power.

Singleplayer / Host / Multiplayer supported.

Use the current Project JoJo Core (v0.23.0.250 for this guide).

HOW TO GET ATUM

Use the normal Stand Arrow from Project JoJo. ATUM is part of the existing Stand pool; there is no separate ATUM Arrow.

If the server/world enables Super Arrow, ATUM appears in the Stand choice list automatically while this addon is enabled. With Super Arrow OFF, it remains part of the normal random Stand pool.

CONTROLS

CAPS LOCK — Summon / Dismiss

1 — Punch

2 — Barrage

3 — Mind Read

4 — Gamble

ATUM combat follows the Core's personal Mouse / Pointer / Facing Direction / Controller Aim targeting choice. If you do not want mouse aiming, Facing Direction makes ATUM attack where the character faces; Controller Aim follows the controller attack/aim vector. ATUM minigame controls remain normal gameplay UI and may still use the mouse where appropriate.

SKILL 3 — MIND READ

Tap / release before FULL — DODGE READ

Costs 1 Mind Point and arms a 10-second defensive read. A supported incoming attack can trigger the dodge.

A successful DODGE READ against a non-player attacker applies a Soul Mark for 3 minutes. Players are never Soul Marked.

Hold until FULL — GAMBLE READ

Costs 1 point and prepares the YES / NO prediction route for Skill 4. It is consumed when Gamble makes real contact. The YES/NO presentation is mouse-through and does not block the minigame controls underneath it.

Cancelling an unused active read before timeout refunds the 1 Mind Point.

SOUL MARK / MULTI-SOUL GAMBLE

Soul Marks are tracked independently per ATUM owner.

When a Gamble begins, ATUM binds every still-marked living non-player target within roughly 18 tiles and the allowed Z range into the same wager. The minigame UI still plays against the main target only.

  • ATUM wins → the normal target and every bound marked soul receive Soul Extraction
  • ATUM loses → 3-second blackout remains, while Skill Silence scales by 7 seconds × number of wager targets
  • The bound target count is locked when the Gamble starts

Skill 4's HUD can show how many marked targets are currently eligible to be pulled into a Gamble. AUTO GAMBLE PASSIVE state is shown on the same Skill 4 area.

SKILL 4 — GAMBLE / AUTO GAMBLE

Tap 4 lunges using the same contact reach as Punch. On real contact the server chooses one of three games with equal 1/3 odds:

  • Rock Paper Scissors
  • Baseball
  • Racing

Hold 4 to FULL toggles AUTO GAMBLE PASSIVE. While active, normal Tap 4 is disabled. A successful Tap-S3 DODGE READ automatically challenges the exact attacker that triggered the dodge.

FULL S3 → Tap 4 is the prediction combo.

GAMES

RPS — challenged side has 8 seconds; zombies choose server-side. FULL-S3 prediction adds the YES/NO read phase.

BASEBALL — Pitcher chooses HIGH / MIDDLE / LOW. If a player does not answer in time the server automatically randomizes the pitch. Correct swing wins; correct swing in the final 2 seconds guarantees HOME RUN, otherwise a correct hit has a 10% Home Run chance.

RACING — 8.8s intro + 4.5s READY + 36s main race. Manage 100 vehicle HP with BOOST, ATTACK and BLOCK. A hidden Launch Mash can begin as soon as the Racing screen opens; 5+ rapid Skill-1 taps arm an opening speed bonus with diminishing returns and a hard cap.

Racing is longer than the other games, so its base Mind reward is higher.

MIND GAUGE & REWARDS

Mind Gauge: 0 / 100

Skill 3 costs 1 point.

  • RPS / Baseball ATUM win: +0 to +3
  • Racing ATUM win: +2 to +5
  • Correct FULL-S3 prediction + win: +1 additional Mind Point

WINNER'S HIGH

The actual human winner of an ATUM minigame receives a small mental recovery bonus. It can reduce Stress, Unhappiness, Boredom and Panic. Racing gives the strongest Winner's High because it is the longest game.

If the ATUM owner used FULL S3, predicted correctly and still won, Winner's High is multiplied by ×1.25.

Winner's High never restores Hunger, Thirst, Fatigue, injuries, Pain or Sickness.

MINIGAME PROTECTION

Participants are temporarily protected/phased from normal outside combat while the game is active. Visibility and protection are restored after resolution. Required minigame UI remains visible even if the player uses Minimal/Hidden Stand HUD.

PROJECT JOJO CLIENT OPTIONS

ATUM follows the Core's Stand HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Project JoJo Volume and targeting mode. Core v0.23.0.250 also includes separate reset buttons for presentation/targeting and keybinds.
