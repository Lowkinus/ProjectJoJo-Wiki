คู่มือมือใหม่

อ่านหน้านี้ให้จบก็พอเริ่มเล่นได้ ส่วนรายละเอียดลึกของสกิลค่อยเปิดหน้าของ Stand ที่คุณสุ่มได้

BUILD 42+SP / HOST / MP
01 • STAND ARROW

หา Stand Arrow

Stand Arrow เจอได้จาก world loot และมีโอกาสดรอปจากซอมบี้ ที่ค่าเริ่มต้น 1x โอกาสดรอปจากซอมบี้ประมาณ 1 / 250 พื้นที่แนวโรงรถ กล่องเครื่องมือ และ mechanic storage เป็นจุดที่ควรลองหา

02 • USE IT

1 ดอกใช้สำเร็จได้ 3 ครั้ง

Condition จะเป็น 3/3 → 2/3 → 1/3 → หาย ปกติ Arrow สุ่ม Stand จากตัวที่โหลดอยู่ การเปลี่ยน Stand ไม่ลบ Progress ของ Stand เก่า

ถ้าเซิร์ฟเปิด Super Arrow จะมีรายการให้เลือก Stand แทนการสุ่ม แต่ Arrow ยังมี 3 use เหมือนเดิม เว้นแต่เปิด Infinite Stand Arrow เพิ่มด้วย

03 • CONTROLS

เรียก Stand แล้วใช้ 1–4

CAPS LOCK เรียก/เก็บ Stand และเลขแถวบน 1 / 2 / 3 / 4 คือสกิล

ลองทั้งกดสั้นและกดค้าง เพราะปุ่มเดียวกันอาจเป็นคนละท่า เช่น Time Dash กับ Time Stop

04 • AIM

เลือกวิธีเล็งที่ถนัด

ที่ Options → Mods → Project JoJo เลือก Mouse / Pointer, Facing Direction หรือ Controller Aim ได้ วิธีเล็งเปลี่ยน “ทิศ input” แต่ไม่เปลี่ยนกติกาการชน

ตัวอย่าง: Facing Direction เหมาะกับ Project Viewpoint เพราะโจมตีตามทิศตัวละครโดยไม่ต้องจ้องเคอร์เซอร์

05 • FIRST CONTACT

ตัวแรกที่ขวางแนวมักสำคัญที่สุด

สกิลใช้ระยะจริงของตัวเอง แต่ตรวจสิ่งแรกบนแนวโจมตี กำแพง ประตู หน้าต่าง รถ หรือสิ่งมีชีวิตด้านหน้าอาจขวางท่าได้

06 • LEVEL

แต่ละ Stand มีเลเวลของตัวเอง

Stand เก็บ LV.1–100 แยกกัน ฆ่าซอมบี้ด้วย Stand เพื่อรับ EXP เปลี่ยน Stand แล้วเลเวลตัวเก่าไม่หาย

07 • BARRAGE

รัวหมัดไม่ได้มีไว้ทำดาเมจอย่างเดียว

Barrage บางตัว Clash กับ Barrage ของผู้เล่นอีกคนได้ และบาง Stand เปิด Barrage Guard เพื่อปัด projectile ที่รองรับจากด้านหน้า

ตัวอย่าง: The World Knife ที่วิ่งเข้าหน้าผู้เล่นอาจถูก Guard ปัดได้ แต่ยิงจากด้านหลังหรือเป็น AOE ไม่ได้ใช้กฎเดียวกัน

08 • TIME

Time Stop หยุดมากกว่าตัวละคร

SP หยุด 5 วิ, TW 9 วิ เป้าที่ถูกหยุดและ projectile ในพื้นที่จะค้าง ดาเมจบางส่วนจะรอแล้วลงเมื่อเวลาเดินต่อ

09 • PVP

Safety กันดาเมจ แต่ Utility มีเงื่อนไขของมัน

HP damage เคารพ PvP/Safety แต่ CC/Utility เช่น Freeze, Pull หรือ Reposition อาจใช้กติกาเฉพาะ อ่านหน้าของ Stand ก่อนเอาไปทดลองกับเพื่อน

10 • HUD

ปรับหน้าจอและเสียงของตัวเองได้

เลือก HUD Normal / Minimal / Hidden, opacity 20–100%, scale 70–150%, personal volume 0–100% และตั้งปุ่มได้ ค่าเหล่านี้ไม่ไปเปลี่ยนของเพื่อนหรือ Sandbox เซิร์ฟเวอร์

11 • SERVER SETTINGS

เจ้าของโลกปรับความยากของระบบได้

Sandbox มี Arrow Drop, Stand Damage, Stand Level, Arrow on Join, Infinite Stand Arrow และ Super Arrow รวมถึงตัวเลือกของ Addon บางตัว

ตัวอย่าง: เซิร์ฟ Survival จริงจังอาจทำศรหายากและใช้ Level; เซิร์ฟเล่น JoJo ล้วนอาจแจก Arrow ตอนเข้าและเปิด Super Arrow ให้เลือกตัว

เริ่มเล่นได้แล้ว: พอรู้ 11 ข้อนี้ ให้กลับไปหน้าแรกแล้วกด Stand ที่คุณได้ หน้า Stand จะอธิบายทีละสกิลพร้อมตัวอย่างว่าจะใช้ตอนไหน
คู่มือระบบเต็ม →Time Stop, Erase, PvP, Guard, Sandbox และ Client Options แบบละเอียดเลือก Stand →ความสามารถ ตัวเลข และตัวอย่างของ Stand แต่ละตัว
