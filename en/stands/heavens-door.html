HEAVEN'S DOOR

Open a target like a book, build REWRITE, then turn written orders into movement, restrictions, knowledge, item control and Scripted Zombie behavior.

HEAVEN'S DOOR v0.1.62 is the release-integration build for Project JoJo Core v0.23.0.250+.

Singleplayer / Host / Multiplayer supported.

HOW TO GET HEAVEN'S DOOR

Use the normal Project JoJo Stand Arrow. With normal Sandbox rules Heaven's Door is part of the random registered Stand pool. If Super Arrow is enabled and this addon is loaded, HEAVEN'S DOOR appears in the choice list automatically.

CONTROLS

CAPS LOCK — Summon / Dismiss

1 — BARRAGE

2 — PAGE OPEN BARRAGE

3 TAP — PAGE TOUCH / open the target's book on real contact

3 FULL — WRITE MYSELF

4 TAP — place BOOK TRAP

4 HOLD — collect your existing BOOK TRAP

CORE TARGETING / CLIENT OPTIONS

Heaven's Door uses the same Mouse / Pointer, Facing Direction and Controller Aim system as the Core. Contact skills still pass through Directional First-Contact instead of becoming through-wall auto-lock.

The passive REWRITE lane follows Core HUD Normal / Minimal / Hidden, HUD Opacity and HUD Scale. In Minimal mode the addon-specific resource lane stays hidden so only the shared Stand name/cooldowns remain. In Hidden mode the passive Stand HUD is hidden completely.

The Book / Command UI remains visible because it is gameplay UI. Heaven's Door sounds use the Core Personal Project JoJo Volume.

REWRITE — 0 / 100

Heaven's Door uses a 100-point REWRITE resource and regenerates 3 points per second. Written commands spend REWRITE based on their effect.

SKILL 1 — BARRAGE

Close-range Heaven's Door rush using the Core rush/contact pipeline. Normal Barrage uses 10 hits; full charge extends it to 18 hits and increases damage. It inherits Core Stand Level, global Stand Damage, PvP/Safety and multiplayer authority.

SKILL 2 — PAGE OPEN BARRAGE

A second rush focused on opening the target's book through repeated physical contact. It uses the same current range and charge structure as Skill 1 but lower per-hit damage.

SKILL 3 — PAGE TOUCH / WRITE MYSELF

Tap: a physical zero-damage touch with real contact range. On a valid target it opens the Book interface. Tap uses the normal Skill-3 cooldown.

Full charge: opens Heaven's Door on yourself. The self-write route is intentionally separate from the tap cooldown.

Once a target's book is successfully opened, that opened-book record is persistent instead of expiring after a short UI timer.

WRITTEN COMMANDS

The Book groups commands into Mind / Memory, Orders, Restrictions, Body Commands, Knowledge, Items and Special. Availability depends on the target type and capabilities.

  • Mind / Memory: calm, focus, reduce boredom/unhappiness, stay awake, feel no pain/fear, blindness and Forget / Ignore Me.
  • Orders: Come, Follow, Go Away, Run Forward/Backward, turn away, crouch/stand/shout, Zombie Run/Walk, Guard Me and Attack Them.
  • Restrictions: Do Not Move, Do Not Run, Do Not Attack, Do Not Attack Me, and temporary Stand lock for compatible players.
  • Body: hunger/thirst, Forget How to Breathe, Trip Over, Hurt Yourself, Fly Away and Run Into.
  • Knowledge: temporary 5× XP learning for a selected supported skill; it does not grant a permanent level for free.
  • Items: drop held item, remove a worn item, or give an inventory item when supported.

SCRIPTED WRITTEN-ZOMBIE AI

Guard/Attack orders keep Heaven's Door ownership of Written Zombies instead of releasing them back to ordinary prey selection. The v0.1.61 Target Ownership hotfix is preserved in v0.1.62: if an ATTACK THEM victim becomes another Written Ally, the attacker retargets or waits safely instead of turning back on the writer.

RUN INTO also cancels cleanly if its actor-target disappears instead of converting that loss into a false wall impact.

COMMAND PHYSICS POLISH

RUN INTO and FLY AWAY use physical/ragdoll-style reactions where the target supports them, with safe native fall/knock fallbacks. TRIP avoids the old double-knock behavior, FORGET HOW TO BREATHE deals timed damage without knockdown spam, and HURT YOURSELF deals its damage without forcing an extra fall.

Harmful command damage goes through Project JoJo central damage, so Stand Level, global Stand Damage and PvP/Safety remain authoritative.

SKILL 4 — BOOK TRAP

Tap 4 places the current Book Trap at range. It persists and can deliver up to 10 pulses/hits according to its trap rules. Hold 4 collects the existing trap; charging no longer exists to enlarge the placement range.

SHARED CORE SYSTEMS

Heaven's Door v0.1.62 is registered in the Core Stand Pool and StandDefs, so it participates in Stand progression, the optional 33% summoned Stand net-damage defense, Client Options and Super Arrow selection when installed.
