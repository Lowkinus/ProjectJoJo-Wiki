CRAZY DIAMOND

Crazy Diamond 不是被动治疗。先在 Attack Mode 战斗补 Restore，再把资源花在治疗、修复与 Glass Homing。

RESTORE GAUGE

Max 100 • very slow passive refill

被动回复故意很慢。真正的攻击型 CD 命中才是主要补给来源：Punch、Rush 与 Glass 在真实命中时都会增加 Restore。

示例：把整条 Gauge 用来治疗后，应回 Attack Mode 打人补资源，而不是等几分钟被动回复。

Skill 1 — DORAAA / RESTORE PUNCH

CD 0.37s • Range 2.8

Attack Mode 造成伤害并补 Gauge；Restore Mode 治疗另一个有效目标，而且只有成功治疗时才花 Gauge。

示例：两场战斗之间用快速 Restore Punch 精确治疗，比用 Rush 一次倒光资源更好控制。

Skill 2 — DORA RUSH / RESTORE RUSH

CD 5s • 17 / 25 hits

Attack Rush 是攻击并产生 Barrage Guard；Restore Rush 变成连续治疗 tick，不参与 Barrage Clash。

示例：有飞刀/投射物来袭时，如果你需要 Barrage Guard 就保持 Attack Mode；Restore Rush 不是防御版本。

Skill 3 — ATTACK / RESTORE

Instant toggle

切换 Skill 1、2、4 的功能。Attack 负责产生资源；Restore 负责把资源花在支援。

示例：养成按 Skill 2 前先看模式的习惯，同一个键可能是“打人”也可能是“治疗”。

Skill 4 — GLASS SHOT / GLASS HOMING

CD 5.2s • Range 9

Attack Mode 发射玻璃并建立 mark；Restore Mode 消耗 Restore 发射玻璃，先直线飞行再弯向 mark。墙、车辆和身体仍可截住它。

示例：先给高耐久目标做 mark，换角度后切 Restore 发 Homing，让回来的路径更难预测。

这个替身应该怎么理解？

不要只背术语

先理解循环：什么会产生资源、什么会消耗资源、眼前的问题该由哪一个技能解决。

把示例当作思路

示例不是唯一连段，而是用来解释机制为什么存在；实战时根据距离、资源和敌人数量调整。
