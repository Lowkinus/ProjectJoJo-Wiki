PROJECT JOJO WIKI — VISITOR COUNTER PATCH
===========================================

ไฟล์นี้ทำสำหรับ:
https://github.com/Lowkinus/ProjectJoJo-Wiki
https://lowkinus.github.io/ProjectJoJo-Wiki/

วิธีติดตั้งแบบสั้น
------------------
1) แตก ZIP นี้
2) ใน GitHub repo เปิดโฟลเดอร์ assets
3) อัปโหลดไฟล์ assets/style.css จากแพตช์นี้ทับ style.css เดิม
4) กลับไปหน้า root ของ repo แล้วอัปโหลด stats.html
5) Commit changes
6) รอ GitHub Pages อัปเดต แล้วเปิดเว็บตามปกติ

เมื่อ style.css ใหม่ทำงาน:
- ทุกหน้าที่ใช้ style.css เดียวกันจะเรียก visitor counter อัตโนมัติ
- มุมขวาล่างจะแสดงจำนวนคนที่ออนไลน์อยู่ ณ ตอนนั้น
- ใช้ Tracker ID เดียวกันทั้ง EN / TH / Guide / Stand pages

แดชบอร์ดสามารถดู:
- Users online
- History
- Popular pages / Readers
- Pageviews
- Visitor sessions
- Countries
- Devices

หมายเหตุ:
- สถิติจะเริ่มเก็บตั้งแต่วันที่ติดแพตช์ ไม่สามารถย้อนนับคนก่อนหน้าได้
- Pageviews = จำนวนครั้งที่เปิดหน้า จึงรวมการเปิดซ้ำ
- Sessions = จำนวนรอบการเข้าชม เหมาะกว่าสำหรับดูจำนวนการเข้ามาเป็นรอบ ๆ
- ไม่ใช่การระบุตัวบุคคล และจำนวน "คนไม่ซ้ำตลอดกาล" ไม่ควรถูกตีความว่าแม่น 100%
- free stats page ของ whos.amung.us เป็นสาธารณะ
