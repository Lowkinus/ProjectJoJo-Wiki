第一次使用 Project JoJo

快速开始

1. 找到 Stand Arrow

默认 1x 掉落设置下，僵尸基础掉落率约为 1/250，并且也可能在世界战利品中出现。

2. Arrow 有 3 次成功使用

普通 Arrow：3/3 → 2/3 → 1/3 → 消失。只有成功使用才会消耗次数；Infinite Stand Arrow 可关闭这个消耗。

3. 召唤替身

默认使用 Caps Lock 召唤/收回替身。技能默认使用 1–4。

4. 选择瞄准方式

Mouse / Pointer、Facing Direction、Controller Aim。Project Viewpoint 玩家如果不想依赖可见鼠标，可以优先使用 Facing Direction。

5. 了解 Stand Level

每个替身独立保存 Lv.1–100。当前 Mastery 设计为 Lv.1 约 50% 伤害，Lv.100 约 120% 伤害，并可缩短部分技能冷却。

6. 先学共享战斗规则

Directional First-Contact、Barrage Clash、Barrage Guard、Time Stop/Time Erase 与 PvP/Safety 会影响很多替身。

最重要的提示

不要只看技能名字

技能可能有双动作

部分技能通过不同输入方式触发第二种动作。HUD 会使用简短的 技能/技能 名称，例如 CROSS FIRE/FIRE TRAP。

被召唤的替身提供防御

已注册替身处于召唤状态时，替身使者受到的净伤害降低 33%。

多人游戏

核心目标为 Singleplayer / Host / Multiplayer。PvP 玩家伤害尊重 Project Zomboid PvP/Safety，但部分控制/位移类效果有独立规则。
