PROJECT JOJO WIKI — v353 MOBILE LAYOUT FIX / คำแนะนำการอัปโหลด

1. สำรองรีโพซิทอรี ProjectJoJo-Wiki เดิมก่อน
2. แตก ZIP นี้ลงทับรีโพซิทอรีเดิม แล้วอัปโหลดไฟล์ที่แก้ทั้งหมด
3. สำคัญ: หน้า th/index.html และ en/index.html ในรีโพซิทอรีเดิมยังอ้าง
   ../assets/hero-ranking.js?v=444
   ให้เปลี่ยน v=444 เป็น v=353 หลังอัปโหลด ถ้าเว็บมือถือยังโหลดสคริปต์รุ่นเก่า
   (การ์ดไม่แสดงหรือไม่ใช้เลย์เอาต์ใหม่)
4. เปิดเว็บไซต์ใน Private/Incognito และเช็กบนมือถืออีกครั้ง

เปลี่ยนเฉพาะมือถือ: การ์ดเป็นรูปด้านบนและข้อความด้านล่าง, เมนูเลื่อนซ้ายขวาได้,
รูปไม่ดันขอบจอ, แยกป้ายมุมบนขวาจากเลขการ์ด
คอมพิวเตอร์ยังใช้ดีไซน์ Poster เดิม

แพตช์นี้ไม่ใช่เว็บไซต์เต็ม ต้องแตกทับของเดิม ไม่ใช่ใช้แทนรีโพซิทอรี
หากไม่เห็นการเปลี่ยนแปลงบนมือถือหลังอัปโหลด ให้ตรวจ cache/script version
