CRAZY DIAMOND

สาย:
Support Bruiser / Heal / Repair

ความยาก:
ค่อนข้างสูง ถ้าจะใช้ Restore System ให้คุ้มจริง

เหมาะกับ:
เล่นทีม หรือคนที่อยากเป็นทั้งนักสู้ หมอ และช่างในตัวเดียว

สรุปง่าย ๆ

นายไม่ต้องเลือก

เป็นทั้งหมดได้เลย

สกิล 3 — ATTACK / RESTORE MODE

Cooldown ประมาณ

0.25 วิ

ใช้เปลี่ยนระหว่าง

ATTACK MODE

และ

RESTORE MODE

Punch กับ Barrage จะเปลี่ยนหน้าที่ตาม Mode ปัจจุบัน

ถ้าเล่น Crazy Diamond จริงจัง

ฝึกเปลี่ยน Mode ให้คล่อง

อย่าเปิด Restore Mode แล้วเดินตามเพื่อนทั้งเกม

เพราะ Gauge หลักของนายไม่ได้เกิดจากการยืนรอ

RESTORE GAUGE

สูงสุด

100

Passive Regeneration ช้ามาก

ประมาณ

+1 ทุก 100 วิ

วิธีหา Gauge หลักคือกลับไปสู้ใน Attack Mode

Attack Mode ได้ประมาณ

Punch โดน

+0.5

Barrage

+0.15625 ต่อ Hit

Glass Shot

+0.625

ค่าใช้ Restore

Restore Punch

6.25 เมื่อรักษา/ซ่อมสำเร็จ

Restore Barrage

1.25 ต่อ Successful Heal Tick

ถ้า Restore แล้วจริง ๆ ไม่มีอะไรเปลี่ยน

ระบบจะพยายามไม่หัก Gauge ทิ้งฟรี

สกิล 1 — PUNCH / RESTORE PUNCH

Cooldown ประมาณ

0.37 วิ

Attack Mode

เป็นหมัดโจมตีปกติ

Restore Mode

จะพยายาม Heal / Repair เป้าที่นายเล็งอยู่ตอนจังหวะ Contact จริง

Restore Punch ปกติ

ประมาณ 18 Heal Power

ชาร์จเต็ม

ประมาณ 36

ระหว่าง Animation ก่อนหมัดถึงเป้า

นายยังสามารถขยับ Aim ได้

เพราะงั้นไม่ต้องเลือกเป้าตั้งแต่ต้น Animation แล้วภาวนาให้ Stand ไม่ไปโดนผิดคน

สกิล 2 — DORA BARRAGE / RESTORE BARRAGE

Cooldown ประมาณ

5 วิ

Attack Mode

เป็น Barrage สำหรับต่อสู้

Restore Mode

เป็น Healing Barrage หลาย Tick

ระหว่าง Restore Barrage

นายสามารถขยับ Cursor ไปหาเป้าหมายอื่นได้

เพราะงั้นถ้ามีเพื่อนบาดเจ็บหลายคน

สามารถเปลี่ยนเป้าระหว่างการรัวได้

Crazy Diamond เปิดคลินิกเคลื่อนที่

แค่หมอเสียงดังไปหน่อย

และใช้กำปั้นในการรักษา

สกิล 4 — GLASS SHOT

Cooldown ประมาณ

5.2 วิ

ระยะประมาณ

9 ช่อง

เป็น Projectile ระยะไกล

ใน Attack Mode ยังช่วยเพิ่ม Restore Gauge ด้วย

เหมาะตอน

  • ไม่อยากเข้า Melee
  • ต้องการเก็บ Gauge
  • ต้องการจบเป้าที่อยู่ไกล
  • มีอะไรอยู่ไกลแล้วสมควรเจอเศษแก้ว

RESTORE ซ่อมอะไรได้บ้าง?

Living Target ที่รองรับ เช่น

  • ผู้เล่นคนอื่น
  • Zombie
  • NPC / Living Character ที่รองรับ

แต่

Crazy Diamond ไม่สามารถรักษาเจ้าของตัวเองด้วย Normal Restore

กฎของ Josuke ยังอยู่ครบ

นอกจาก Living Target แล้ว

Restore System ยังรองรับ World Target หลายประเภท เช่น

  • Vehicle
  • World Item
  • Window
  • Door
  • Barricade
  • Tree
  • Thumpable Object
  • Object ที่มี Health / Condition และระบบรองรับ

Vehicle สามารถ Restore Condition ของ Part ได้

Item สามารถ Restore Condition ได้

อาหารที่ระบบรองรับสามารถ Restore สถานะ Spoiled / Burnt ได้ด้วย

ใช่

นายอุตส่าห์หา

  • ตู้เย็น
  • เครื่องปั่นไฟ
  • น้ำมัน

มาครึ่งเมือง

แล้ว Josuke เดินมาบอกว่า

"ไม่เป็นไร"

วิธีเล่น CRAZY DIAMOND เป็นทีม

อย่าใช้ Restore Gauge หมดกับรอยขีดข่วนทุกครั้ง

เล่น Attack Mode

ช่วยทีมสู้

หา Gauge

แล้วเก็บ Restore ไว้ตอน

  • เพื่อนเจ็บหนัก
  • มีเหตุฉุกเฉิน
  • รถเสีย
  • Equipment สำคัญพัง
  • ต้อง Restore ของที่มีมูลค่าจริง ๆ

Crazy Diamond จะเก่งมากถ้านายมอง Restore Gauge เป็น Resource ที่ต้องบริหาร

ไม่ใช่ Healing Fountain ฟรี
