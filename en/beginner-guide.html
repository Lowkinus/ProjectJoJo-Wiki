THE ARROW PICKED YOU. NOW WHAT?

BEGINNER GUIDE

Finish this page and you know enough to start. Open your Stand's page later for the deeper skill rules and examples.

BUILD 42+SP / HOST / MP
01 • STAND ARROW

Find a Stand Arrow

Stand Arrows can appear in world loot and rarely drop from zombies. At default 1x the zombie chance is roughly 1 / 250. Garages, tool crates and mechanic storage are good places to check.

02 • USE IT

One Arrow has three successful uses

Condition goes 3/3 → 2/3 → 1/3 → gone. Normally the Arrow randomly chooses from loaded Stands. Rerolling does not erase old Stand progression.

If the server enables Super Arrow, the Arrow shows a Stand choice list instead of rolling randomly. It still has three uses unless Infinite Stand Arrow is also enabled.

03 • CONTROLS

Summon, then use 1–4

CAPS LOCK summons/dismisses your Stand. Top-row 1 / 2 / 3 / 4 are the skills.

Try both tap and hold. One key can contain two very different actions, such as Time Dash on tap and Time Stop on full charge.

04 • AIM

Choose the targeting style you prefer

Under Options → Mods → Project JoJo, choose Mouse / Pointer, Facing Direction or Controller Aim. This changes the input direction, not collision rules.

05 • FIRST CONTACT

The first thing on the line matters

Skills use their real reach, but the first valid body/world contact on the line can block the attack. Walls, doors, windows and vehicles still matter.

06 • LEVEL

Every Stand has separate progression

Stands store Lv.1–100 independently. Stand-caused zombie kills grant EXP. Switching Stands does not erase the old Stand's level.

07 • BARRAGE

A Barrage is more than damage

Supported Barrages can Clash with another offensive Barrage, and some create Barrage Guard to stop supported projectiles from the front.

08 • TIME

Time Stop pauses more than characters

SP stops for 5 seconds and TW for 9. Frozen actors and projectiles in the stopped area pause, and delayed damage resolves when time starts again.

09 • PVP

Safety protects HP; utility has its own rules

HP damage respects Project Zomboid PvP/Safety. Utility/CC such as Freeze, Pull or repositioning can have separate rules, so read the Stand page before testing it on friends.

10 • HUD

Make the interface fit your screen

Choose Normal / Minimal / Hidden HUD, opacity 20–100%, scale 70–150%, personal Project JoJo volume 0–100%, and your own keybinds. These do not change server balance.

11 • SERVER SETTINGS

The world owner controls the progression style

Sandbox includes Arrow Drop, Stand Damage, Stand Level, Arrow on Join, Infinite Stand Arrow and Super Arrow, plus settings exposed by some addons.

Example: A survival server can keep Arrows rare and progression enabled; a JoJo-focused server can give an Arrow on join and enable Super Arrow for direct selection.

You are ready to start. Go back to the Stand list and open the page for the Stand you actually received. That page explains every move and practical use.
