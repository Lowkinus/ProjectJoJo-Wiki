HARVEST

Manage up to 500 Harvest across combat, delayed single-target pressure, Search jobs and sustained area control.

Need something small... very small... like five hundred of them?

HARVEST is a colony Stand focused on swarm management, ranged harassment, item searching and crowd control.

Singleplayer / Host / Multiplayer supported.

Use the current Project JoJo Core (v0.23.0.250 for this guide).

HOW TO GET HARVEST

Use the normal Stand Arrow. HARVEST is part of Project JoJo's existing Stand pool; there is no separate Harvest Arrow.

If the server/world enables Super Arrow, HARVEST appears in the Stand choice list automatically while this addon is enabled. With Super Arrow OFF, it remains part of the normal random Stand pool.

CONTROLS

CAPS LOCK — Summon / Dismiss

1 — HARVEST SHOT

2 — NEEDLE SWARM

3 — SEARCH ITEM

4 — HARVEST STORM

Combat skills follow the Core's Mouse / Pointer, Facing Direction or Controller Aim setting. Facing Direction is useful when you do not want a visible cursor; Search Command remains normal UI and still uses pointer interaction.

COLONY — 0 / 500

HARVEST uses one shared colony of up to 500. Combat and Search draw from the same pool. Units away on Search remain reserved and lower the regeneration ceiling until they return or are recalled.

Walking/running stops colony recovery. Current base recovery is:

  • Still: 0.80 / sec after 0.65s grace
  • Seated / Vehicle: 4.05 / sec
  • Rest: 9.00 / sec
  • Sleep: 14.40 / sec

The Harvest Regeneration Sandbox setting scales recovery from 25% to 500%. It does not accelerate Search and cannot regenerate over units that are away.

SKILL 1 — HARVEST SHOT

Cost 1 Harvest. Fast ranged harassment with light damage and knockback / mini-CC. Hold to keep sending one Harvest at a time. Barrage Guard can defend against it.

SKILL 2 — NEEDLE SWARM

Minimum 7 Harvest. Hold to add exactly +1 Harvest per step; the real interval gets faster the longer you hold. The selected swarm latches to one target for about 9 seconds before striking together. Bigger commitments increase final damage.

If the target dies/disappears or breaks the leash before resolution, the pending swarm is cancelled and reserved units are refunded.

SKILL 3 — HARVEST SEARCH COMMAND

Press Skill 3 to open the dedicated Search Command screen.

Search uses actual InventoryItems already inside your inventory as templates, including items inside nested bags. It is not limited to medicine or bandages.

Template rows separate important item state instead of grouping only by FullType. That allows full / half-full / empty fluid containers or Propane Tanks, different condition/used-state items and relevant weapon state to remain distinct when their stored state differs.

For compatibility with mods that replace or modify item scripts, HARVEST no longer treats a simple ScriptManager lookup as the UI whitelist. The authoritative side preflights recreation when START SEARCH is pressed. If a modded/runtime item genuinely cannot be rebuilt safely, the player receives an explicit compatibility-limit message before Harvest is reserved.

ORDER SIZE

  • Quantity: x1 → x500
  • x1–x20 = minimum 20 Harvest
  • x21–x500 = minimum crew equals quantity
  • Assigning more than minimum makes the search work faster
  • Total batch weight adds transport time

STAND LEVEL SEARCH SPEED

Search work scales with HARVEST's Stand Level: Lv1 uses the authored search time and scales linearly until Lv100 uses 50% of that search-work time. Outbound travel, return travel and delivery time are not accelerated by level.

ACTIVE JOBS / RECALL

The same UI shows active jobs, phase and ETA. RECALL cancels only that job, returns its reserved Harvest immediately and discards undelivered items from that cancelled job.

Search audio is job-based and positional, so multiple jobs can play their own deployment/return/delivery cues. Personal Project JoJo Volume also applies to Search 3D audio.

SKILL 4 — HARVEST STORM

Minimum 33 Harvest. Commit part of the colony around yourself for sustained repeated area pressure, mini knockback and crowd interruption.

A minimum Storm is the light baseline; larger allocations increase its duration smoothly up to the 38-second cap at a full 500-Harvest commitment. Barrage Guard can defend the guarding player from Storm hits without cancelling the Storm for everyone else.

PROJECT JOJO CLIENT OPTIONS

HARVEST follows Stand HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Project JoJo Volume and Targeting Mode from the Core. The Search Command screen remains available because it is required gameplay UI. Core v0.23.0.250 also includes separate reset buttons for presentation/targeting and keybinds.
