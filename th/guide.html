STAND ARROW — หาศรยังไง?

ถ้าเล่นค่าปกติ ซอมบี้มีโอกาสดรอปศรประมาณ 1 / 250 นอกจากนั้นศรยังเข้า loot table ของกล่องหลายแบบด้วย

  • น่าหากว่าเพื่อน: Garage / Tool / Mechanic storage
  • หาได้ทั่วไป: ตู้ ห้องนอน ชั้นวาง โต๊ะ โรงเรียน ออฟฟิศ และกล่องจิปาถะหลายประเภท
  • ในรถ: มี แต่ตั้งใจให้หายากกว่ากล่องเครื่องมือ

ศรหนึ่งดอกมี Condition 3 และใช้สำเร็จได้ 3 ครั้ง การสุ่มจะกิน Condition หลังสุ่ม Stand สำเร็จเท่านั้น ถ้าระบบล้มเหลวกลางทางจะไม่หักศรมั่ว ๆ

Sandbox มี Arrow Drop Multiplier และ Infinite Stand Arrow ถ้าเล่นกับเพื่อนแล้วไม่อยากให้ทุกคืนกลายเป็นทริปล่าศร ก็ปรับตรงนี้ได้เลย

ปุ่มพื้นฐาน

CAPS LOCK — เรียก / เก็บ Stand
1 / 2 / 3 / 4 — สกิล 1–4 บนเลขแถวบน ไม่ใช่ Numpad

หลายสกิลใช้ระบบชาร์จแบบ “แตะ = ท่าหนึ่ง / ชาร์จเต็ม = อีกท่าหนึ่ง” เช่น Time Dash → Time Stop, The Hand Dash → Pull หรือ KQ First Bomb → SHA เพราะงั้นถ้าท่ามันออกไม่เหมือนที่คิด เช็กก่อนว่ากดสั้นหรือกดเต็ม

STAND LEVEL

แต่ละ Stand เก็บเลเวลแยกกันตั้งแต่ Lv.1 → Lv.100 Lv.1 ใช้ดาเมจประมาณ 50% ของค่าบาลานซ์ แล้วเพิ่มแบบเส้นตรงจนเต็ม 100% ที่ Lv.100

  • ฆ่าซอมบี้ด้วย Stand = +1 EXP ให้ Stand ที่ใช้อยู่
  • Lv.1 ต้อง 5 EXP และจำนวนที่ต้องใช้จะ +1 ทุก 4 เลเวล
  • สุ่ม Stand ใหม่ด้วยศร ไม่ลบ เลเวล/EXP ของ Stand เก่า
  • ถ้ากลับมาได้ Stand เดิม จะเล่นต่อจากค่าที่เคยเก็บไว้
  • การตายรีเซ็ต progression ของ Stand ทั้งหมดของตัวละครนั้น
  • ถ้าปิด Stand Level ใน Sandbox ทุก Stand จะทำงานเหมือน Lv.100

DIRECTIONAL FIRST-CONTACT

เมาส์ทำหน้าที่กำหนด ทิศทาง มากกว่าจะเป็น “จุดล็อกเป้า” สกิลใช้ระยะสูงสุดจริงของตัวเอง แล้วตรวจว่าร่างไหนสัมผัสแนวโจมตีก่อน

  • เป้ายืน ล้ม และคลานใช้ hit capsule ที่เหมาะกับท่า
  • Cursor ใกล้ตัวไม่ตัดท่ายาวให้สั้นลง
  • ถ้ามีตัวอื่นยืนขวางก่อน ตัวนั้นรับท่าแทน
  • กำแพง ประตู หน้าต่าง และรถยังตัดแนวตามจริง
  • AOE บางตัวอย่าง KQ Detonate และ MR Cross Fire เป็นข้อยกเว้นของกฎแนวตรง เพราะมันเป็นพื้นที่ระเบิด/ไฟ

BARRAGE CONTACT + CLASH

Barrage หันตามเมาส์ได้ระหว่างรัว ไม่ได้จำตัวเก่าเป็นล็อกถาวร ถ้าช่วงหนึ่งไม่มีเป้า ระบบเผื่อ contact เดิมสั้น ๆ ราว 240 ms พร้อมเผื่อด้านข้าง 0.30 ช่อง เพื่อไม่ให้เฟรมสั่นนิดเดียวแล้วหมัดวืดทั้งชุด

ถ้าเกม/เซิร์ฟเวอร์กระตุก ระบบตาม hit ที่ค้างได้สูงสุด 3 hit ต่อ update แต่เป้าใหม่ที่สัมผัสแนวจริงยังมีสิทธิ์ก่อนทันที

Barrage Clash

Barrage ฝั่งโจมตีที่รองรับสามารถชนกันได้เมื่อผู้เล่นอยู่ใกล้ประมาณ 5.25 ช่อง และเล็ง/หันเข้าหากันจริง ช่วง Clash hit จะถูกใช้ต้านกันก่อน Restore Rush ของ Crazy Diamond ไม่ใช่ Barrage โจมตีจึงไม่เข้า Clash

BARRAGE GUARD / ปัดโปรเจกไทล์

Stand ที่เปิด Guard ตอนนี้คือ Star Platinum, The World, Crazy Diamond (Attack Barrage), Silver Chariot และ King Crimson

  • แนวกว้างรวมประมาณ 2.5 ช่อง
  • ต้องเป็นโปรเจกไทล์ที่วิ่งจากด้านหน้าและตัดแนวบังจริง
  • รองรับตรง ๆ: TW Knife, SC Rapier Shot, CD Glass / Glass Homing
  • ไม่กัน Explosion, area fire, ERASE area หรือ THREE FREEZE
  • Crazy Diamond Restore Rush ไม่เปิด Guard
ปืนเกมหลัก: มี native per-hit hook แล้ว แต่ยังต้องเทสสด B42 บน SP / Host / Dedicated ให้ครบก่อนนับว่ารองรับสมบูรณ์ทุกเคส
โปรเจกไทล์มอดอื่น: ไม่ได้รองรับอัตโนมัติ ต้องเชื่อม JJS_BarrageGuard.interceptProjectile(attacker,sx,sy,ex,ey,z)

TIME STOP / TIME ERASE

Star Platinum: Time Stop 5 วิ • The World: 9 วิ • King Crimson: Time Erase 10 วิ

Time Stop เป็นระบบระดับโลกของมอด: หยุดผู้เล่น ซอมบี้ รถ และ mover ที่รองรับ ดาเมจที่ตีใส่เป้าหมายตอนหยุดจะถูกพักไว้แล้วปล่อยตอนเวลาทำงานต่อ

ถ้า SP/TW ถูก Time Stop ของอีกคน ผู้ใช้ยังชาร์จ Time Stop ของตัวเองเต็มได้เพื่อเปิด “ช่วงขยับของตัวเอง” ตามเวลาของ Stop ที่กดออกมา พอเวลาของตัวเองหมด ถ้า Stop เดิมยังเหลือก็กลับไปหยุดต่อ

Stop vs Erase

Time Stop ที่กำลังเริ่มหรือทำงานอยู่จะกัน KC ไม่ให้เปิด Time Erase ใหม่ แต่ถ้า Erase มาก่อนแล้ว Stop ตามมา ระบบเอา “ระยะเวลา Stop” ไปหักกับ “เวลา Erase ที่เหลือ”

  • Stop สั้นกว่า Erase → Stop หายไป และ Erase ยังอยู่
  • เท่ากัน → ยกเลิกกันพอดี
  • Stop ยาวกว่า → Erase จบ แล้วเวลาที่เหลือของ Stop ทำงานต่อ

MULTIPLAYER / PVP / SAFETY

ดาเมจ HP ของ Stand ยังเคารพ PvP/Safety ของ Project Zomboid อยู่ ไม่ได้มีระบบลัดไปหักเลือดหลังเกมกันไว้แล้ว

แต่ Utility/CC ที่ไม่ได้ทำ HP damage อาจยังทำงาน เช่น THREE FREEZE, Space Pull หรือ Epitaph reposition ตามกฎของสกิลนั้น First Bomb ถือเป็น setup เชิงรุก จึงไม่ให้ผู้เล่นที่ PvP/Safety ป้องกันมายืนขวางแล้วแย่ง Mark จากเป้าที่กำลังเล็ง

SANDBOX OPTIONS

  • Sound Volume — ระดับเสียงของมอด
  • Arrow Drop Multiplier — ปรับความถี่ของศรทั้ง loot/zombie
  • Stand Damage % — ตัวคูณดาเมจฝั่งเซิร์ฟเวอร์
  • Stand Level Enabled — ปิดแล้วทุก Stand ทำงานเหมือน Lv.100
  • Test Arrow On Join — ตัวเลือกสำหรับเทส
  • Infinite Stand Arrow — ศรไม่เสีย Condition
