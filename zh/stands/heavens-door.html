如何获得 HEAVEN'S DOOR

把 Heaven's Door addon 与主 Project JoJo mod 一起启用，使用普通 Stand Arrow；它会加入已注册的随机 Stand Pool。服务器开启 Super Arrow 时，只要 addon 已加载，也会出现在直接选择列表。

玩法循环

1 — OPEN A BOOK
通过接触累积共享 Book hit，使用 Page Open Barrage、Page Touch，或让 Book Trap 累积。
2 — INSPECT THE TARGET
打开 Book UI 检查目标，并选择该目标类型真正能执行的命令。
3 — WRITE
花 REWRITE 写立即命令、延迟命令或 proximity trigger。
4 — REOPEN
写入成功会消耗当前打开的书；下一条命令前必须重新打开。

REWRITE — 0 / 100

REWRITE 是爆发储备，不是快速被动回蓝。新角色开始为 100；大多数普通命令约花 1–2，最强效果最高约 4.44。

普通回复：成功写入后先等待 15 秒，之后仅以 0.02 / sec 回复；再次写入会重置 15 秒等待。

阅读回复：只有角色正在通过 Project Zomboid 原生阅读动作真正阅读普通书籍/文学物时，才以 1.0 / sec 快速回复。打开 Heaven's Door 目标书、Book UI、S2/S3/S4 书效果、选择命令或只是携带书都不算。停止/完成/取消原生阅读后快速回复立即结束；Heaven's Door 不增加单独 READ BOOK 按钮。

因此你可以满储备进战斗连续写很多命令，但持续使用最终会真正耗尽；要快速充能，就需要脱战并花真实游戏时间读普通书。

OPEN-BOOK RULES

Heaven's Door 的各接触路线共享 Book progress，需要 10 个有效 Book hit。普通 Barrage 可贡献 hit 但不会自己打开书；Page Open Barrage 与 Book Trap 是 opener；Page Touch 0 direct damage 立即打开有效目标；WRITE MYSELF 打开自己。

目标打开后不会因为 UI 挂着就过期；成功写入命令会消耗/关闭这本书。失败写入不会伪装成功。

SKILL 1 — BARRAGE

快速近战 Rush：10 hits、约 2.6 tiles、5s cooldown。直接伤害较轻并贡献共享 Book hit，但本身不是 opener。

SKILL 2 — PAGE OPEN BARRAGE

开书 Rush：10 hits、约 2.6 tiles、6s cooldown。每 hit 伤害比 Skill 1 低，但共享 Book progress 达到 10 时会通过此路线打开目标。

SKILL 3 — PAGE TOUCH / WRITE MYSELF

Tap：约 2.75 tiles 的 0-damage physical touch；真实接触有效目标会立刻开书，并使用 Skill-3 cooldown。

Full charge：打开自己的 Heaven's Door 书，用于自我 buff、knowledge 与 self-directed orders。

SKILL 4 — BOOK TRAP

Tap 可在约 18 tiles 内放一个持续 trap；Hold 0.5s 收回现有 trap。Trap 每 2 秒检查一次 AOE，共享总预算 10 Book hits。

每个有效 actor 在一个 pulse 中消耗 1 hit。若七个 actor 在圈内会一次消耗七个；只剩三 hit 时只影响最近三名。10 hit 用完后 trap 消失，可放新的。

远程 trap 在作者超出正常 write range 时完成开书，会提供短暂 7 秒接近窗口；进入正常写入范围后转成持续 Book UI。

WRITING MODES

命令可立即执行、延迟 5 / 10 / 20 / 30 / 60 秒，或作为一次性 proximity trigger，在支持的 player 或 mob 进入正常写入范围时触发。

写入预留命令时就花 REWRITE。对于 delayed/proximity order，只有命令真正成功执行时才开始 cooldown，因此等待期间不会提前烧冷却。

Combat confirmation：命令真正执行时作者头上出现绿色信息，例如 Zombie: blinded。限时效果结束、取消或被覆盖时出现红色对应结束信息，例如 Zombie: can see again。Delayed order 只是在等待时不会显示假成功。

SCRIPTED WRITTEN-ZOMBIE AI

Written combat/work order 会持续拥有僵尸控制权，而不是直接交还 vanilla prey selection。GUARD / ATTACK / PROTECT 使用 target blacklist 与 ownership 规则，避免指定目标消失后 written zombie 随便转头咬作者。

FORGET / IGNORE ME 使用主动 disengagement：开头一段时间不断清除对作者的仇恨/反应记忆并写入 breakaway route，之后整段效果持续把作者放在 blacklist；因此比只清一次 target 更强。

Work order 生效期间，僵尸进入安全 worker state 并停止普通猎食战斗。Fetch/clean/tree 工作会重试 path 与替代 approach tile，不会因为 fence、wall 或长路径延迟就立刻取消。

PvP / DAMAGE / MULTIPLAYER

直接有害命令伤害通过 Project JoJo 中央 damage path，因此 Stand Level、global Stand Damage 与 PvP/Safety 仍然 authoritative。某些非伤害 rewrite control 在普通 PvP damage 关闭时仍可允许，但不会用伤害绕过 PvP。

Target state、delayed order、effect、worker AI、trap、REWRITE 与 Book UI state 都为 Singleplayer / Host / Multiplayer 同步。

PLAYSTYLE TIPS

  • 不要把 REWRITE 当被动 spam。满储备进场、积极花掉，再创造阅读窗口。
  • S3 是最干净的单体 opener。S2 适合同时施压；S4 适合提前布置区域或开多目标。
  • Delay 最适合计划下一场战斗。接触前先写，看到绿色执行通知再入场。
  • 把 written zombie 当工具。Guard/Attack/Work 在策略上经常比另一条直接伤害命令更强。
