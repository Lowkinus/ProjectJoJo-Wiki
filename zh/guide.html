客户端设置

CLIENT OPTIONS

Targeting Mode

Mouse / Pointer：按光标方向。
Facing Direction：按角色朝向。
Controller Aim：使用手柄攻击/瞄准轴，并在死区使用角色朝向。

HUD

Normal / Minimal / Hidden；透明度 20–100%；缩放 70–150%。HARVEST Search、ATUM 小游戏、Heaven's Door Book/Command 等必要界面不会因为隐藏被动 HUD 而消失。

Personal Audio

Project JoJo 个人音量 0–100%，属于玩家本地偏好，不改变服务器平衡。

Sandbox

WORLD / SERVER SETTINGS

Super Arrow

默认关闭。关闭时随机抽取已加载 Stand Pool；开启时使用 Arrow 会打开已注册替身选择列表。它不会让 Arrow 变成无限使用。

Arrow Drop Multiplier

默认 1x 的僵尸基础掉落率约为 1/250，同时还有世界战利品来源。

Stand Damage

调整整个世界/服务器的替身总体伤害，不需要逐技能修改。

Stand Level System

开启：每个替身分别保存 Lv.1–100。关闭：替身按完整强度运行，但已保存进度不会被删除。

Give Stand Arrow on Join

可让玩家加入时直接获得 Arrow，适合不想让所有人先刷箭的服务器。

Infinite Stand Arrow

普通 Arrow 3 次成功使用后消失；开启后成功使用不会减少 Condition。

共享战斗系统

COMBAT RULES

Directional First-Contact

技能只在真实射程内检查攻击线上的第一个有效接触。墙、身体与前方阻挡物仍然重要。

Barrage Clash

支持的 Barrage 在距离足够近、双方确实互相面对/瞄准时会发生碰撞；碰撞命中先互相抵消。

Barrage Guard

支持的 Barrage 会形成前方防线，能挡下特定投射物。侧面、背面与范围效果不使用同一规则。

Time Stop

Star Platinum 5 秒，The World 9 秒。冻结角色、移动投射物与延迟伤害在时间恢复后继续结算。

Time Stop vs Time Erase

两者不会无条件叠加。Erase 先开始时，Stop 的持续时间会先抵消剩余 Erase 时间。

Summoned Stand Defense

召唤已注册替身时，替身使者受到的净伤害降低 33%。

PvP / Safety

玩家 HP 伤害尊重 Project Zomboid PvP/Safety。冻结、拉拽、位移等 Utility/CC 可能有独立限制。

Vehicle / World Safety

攻击尊重车辆与世界碰撞，同时有保护逻辑避免高频替身命中破坏不支持的车辆/custom object 状态。
