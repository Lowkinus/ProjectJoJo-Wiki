HEAVEN'S DOOR

Open living targets like books, spend REWRITE to change behavior and body states, or turn written zombies into workers, guards and attackers.

HEAVEN'S DOOR v0.2.13 is the current Beta / Testing guide and requires Project JoJo Core v0.23.0.253+.

Singleplayer / Host / Multiplayer supported.

OPEN HEAVEN'S DOOR ↗

HOW TO GET HEAVEN'S DOOR

Install the Heaven's Door addon together with the main Project JoJo mod. Use the normal Stand Arrow; Heaven's Door joins the registered random Stand pool. If the server enables Super Arrow, it also appears in the direct choice list while the addon is loaded.

THE PLAY LOOP

1 — OPEN A BOOK
Build shared Book hits with contact, use Page Open Barrage, Page Touch, or let Book Trap build hits.
2 — INSPECT THE TARGET
Open the Book UI to inspect the target and choose a command that target can actually perform.
3 — WRITE
Spend REWRITE on an immediate order, a delayed order, or a proximity trigger.
4 — REOPEN
A successful written command consumes the open book. Open it again before writing the next command.

Contact skills use Project JoJo's Mouse / Pointer, Facing Direction or Controller Aim targeting and Directional First-Contact rules.

REWRITE — 0 / 100

REWRITE is a burst reserve, not a fast passive mana bar. A fresh Heaven's Door character starts with 100. Most normal commands cost around 1–2; the strongest effects cost more, up to about 4.44.

Passive recovery: after a successful write, normal recovery waits 15 seconds. After that it recovers only 0.02 / sec. Writing again restarts the 15-second wait.

Reading recovery: fast recovery comes only while your character is actually reading a normal Project Zomboid book/literature item through the game's own reading action. While that real reading action is running, REWRITE recovers at 1.0 / sec. Opening a Heaven's Door target Book, opening the Heaven's Door Book UI, S2/S3/S4 book effects, selecting commands, or simply carrying a book do not count. Stop, finish, or cancel the normal reading action and the fast recovery ends. Heaven's Door does not add a separate READ BOOK button for this.

This economy lets you enter a fight with a large reserve and issue many commands, but sustained use eventually drains it. To recharge quickly, disengage and spend real game time reading normal literature.

OPEN-BOOK RULES

Book progress is shared between Heaven's Door contact routes. 10 valid Book hits are required. Normal Barrage can contribute hits but does not open the book by itself; Page Open Barrage and Book Trap are opener routes. Page Touch opens a valid target immediately with zero direct damage. WRITE MYSELF opens your own book.

Once the target is opened, the book does not expire just because the UI is left open. A successful written command consumes/closes that book. Failed writes do not pretend they succeeded.

SKILL 1 — BARRAGE

Fast close-range rush: 10 hits, roughly 2.6 tiles, 5s cooldown. It deals light direct damage and contributes to the shared Book-hit progress, but it is not an opener on its own.

SKILL 2 — PAGE OPEN BARRAGE

Book-opening rush: 10 hits, roughly 2.6 tiles, 6s cooldown. Damage per hit is lower than Skill 1, but when shared Book progress reaches 10 this route opens the target.

SKILL 3 — PAGE TOUCH / WRITE MYSELF

Tap: a zero-damage physical touch at about 2.75 tiles. Real contact opens a valid target immediately. The normal Page Touch route uses the Skill-3 cooldown.

Full charge: opens your own Heaven's Door book so self-buffs, knowledge and self-directed orders can be written without finding another target.

SKILL 4 — BOOK TRAP

Tap places one persistent trap up to roughly 18 tiles away. Hold for 0.5s to collect the existing trap. The trap checks its AOE every 2 seconds and has a shared budget of 10 Book hits total.

Each valid actor inside the AOE consumes one hit in that pulse. Seven actors can consume seven of the ten hits at once; if only three hits remain, only the three nearest valid actors are affected and the rest are untouched. When the 10-hit budget is exhausted, the trap disappears and a new one can be placed.

If a remote trap finishes opening a target while the writer is outside normal write range, Heaven's Door gives a short 7-second approach window. Reach normal write range to convert it into the persistent open Book UI.

WRITING MODES

Commands can execute immediately, after 5 / 10 / 20 / 30 / 60 seconds, or as a one-shot proximity trigger when a supported player or mob enters the normal write range.

REWRITE is spent when the written order is reserved. For delayed/proximity orders, the command cooldown begins only when that order actually executes successfully, so waiting does not burn the cooldown early.

Combat confirmation: when an order truly executes, a green message appears above the writer, for example Zombie: blinded. When a timed effect ends or is cancelled/overwritten, a red effect-specific message appears, for example Zombie: can see again. Delayed orders do not show a fake success message while they are only waiting.

SCRIPTED WRITTEN-ZOMBIE AI

Written combat and work orders keep control of the zombie instead of handing it straight back to vanilla prey selection. GUARD / ATTACK / PROTECT use target blacklists and ownership rules so a written zombie does not casually turn on its writer when a target disappears.

FORGET / IGNORE ME uses active disengagement: for the opening moments Heaven's Door repeatedly clears writer aggro/reaction memory and writes a breakaway route, then keeps the writer blacklisted for the rest of the effect. This is stronger than simply clearing the target once, because the zombie is actively pushed away from reacquiring the writer.

While a work order is active, the zombie enters a safe worker state and stops using normal prey-combat behavior. Fetch/clean/tree jobs retry paths and alternate approach tiles instead of cancelling just because a fence, wall or long route delayed them.

PvP / DAMAGE / MULTIPLAYER

Direct harmful command damage goes through Project JoJo's central damage path, so Stand Level, global Stand Damage and PvP/Safety remain authoritative. Some non-damage rewrite controls are allowed even when ordinary PvP damage is disabled, but damage itself is not used as a bypass.

Target state, delayed orders, effects, worker AI, traps, REWRITE and Book UI state are synchronized for Singleplayer / Host / Multiplayer.

PLAYSTYLE TIPS

  • Do not treat REWRITE as passive spam. Enter with a reserve, spend it aggressively, then create a reading window.
  • S3 is the cleanest single-target opener. S2 is better when you also want pressure; S4 is for preparing space or opening several targets.
  • Delay is strongest when you plan the next fight. Write before contact, then enter when the green execution notification appears.
  • Use written zombies as tools. Guard/Attack/Work orders are often stronger strategically than another direct-damage command.
