HARVEST

บริหาร Harvest สูงสุด 500 ตัวระหว่างการต่อสู้ Needle, Search Job และ Storm คุมฝูง

อยากได้อะไรตัวเล็ก ๆ ไหม... เล็กมาก... สักห้าร้อยตัว?

HARVEST เป็น Colony Stand ที่เน้นบริหารฝูง ก่อกวนระยะไกล ค้นหาไอเท็ม และคุมพื้นที่

รองรับ Singleplayer / Host / Multiplayer

คู่มือนี้อิง Core ปัจจุบัน v0.23.0.250

วิธีได้ HARVEST

ใช้ Stand Arrow ปกติ HARVEST อยู่ใน Stand Pool ของ Project JoJo อยู่แล้ว ไม่มี Harvest Arrow แยก

ถ้าโลก/เซิร์ฟเวอร์เปิด Super Arrow และ Addon นี้เปิดอยู่ HARVEST จะขึ้นในรายชื่อ Stand ให้เลือกอัตโนมัติ ถ้าปิด Super Arrow ตัวนี้ยังอยู่ใน Stand Pool สำหรับการสุ่มตามปกติ

ปุ่ม

CAPS LOCK — เรียก / เก็บ Stand

1 — HARVEST SHOT

2 — NEEDLE SWARM

3 — SEARCH ITEM

4 — HARVEST STORM

สกิลต่อสู้ใช้ Mouse / Pointer, Facing Direction หรือ Controller Aim จาก Core. ถ้าไม่อยากเห็นเมาส์ ใช้ Facing Direction ได้ ส่วน Search Command ยังเป็น UI ปกติและใช้ Pointer สำหรับกดเมนู

COLONY — 0 / 500

HARVEST ใช้ Colony เดียวสูงสุด 500 ตัว ทั้งการต่อสู้และ Search ใช้กองเดียวกัน ตัวที่ถูกส่งออกไป Search จะถูกจองไว้และลดเพดานการฟื้นจนกว่าจะกลับมาหรือถูก Recall

เดิน/วิ่งจะไม่ฟื้น Colony ค่า Recovery พื้นฐานปัจจุบัน:

  • ยืนนิ่ง: 0.80 / วิ หลังนิ่ง 0.65 วิ
  • นั่ง / อยู่ในรถที่แทบไม่เคลื่อน: 4.05 / วิ
  • Rest: 9.00 / วิ
  • Sleep: 14.40 / วิ

Sandbox Harvest Regeneration ปรับความเร็ว Recovery 25–500% แต่ไม่เร่ง Search และไม่สามารถฟื้นทับจำนวนที่กำลังออกงานได้

SKILL 1 — HARVEST SHOT

ใช้ 1 Harvest ยิงก่อกวนระยะไกล ดาเมจเบา + knockback/mini-CC กดค้างเพื่อส่งทีละตัวต่อเนื่อง และ Barrage Guard ป้องกันได้

SKILL 2 — NEEDLE SWARM

ขั้นต่ำ 7 Harvest กดค้างเพื่อเพิ่มทีละ +1 จริง ๆ โดยช่วงเวลาระหว่างการเพิ่มจะสั้นลงเมื่อชาร์จนานขึ้น ฝูงเกาะเป้าหมายประมาณ 9 วิแล้วแทงพร้อมกัน ยิ่งลงทุนมากดาเมจท้ายยิ่งสูง

ถ้าเป้าตาย/หาย/หลุด leash ก่อนระเบิดผล ฝูงที่ค้างจะยกเลิกและคืน Harvest

SKILL 3 — HARVEST SEARCH COMMAND

กด Skill 3 เพื่อเปิดหน้าจอ Search Command โดยตรง

ระบบ Search ใช้ InventoryItem ที่มีอยู่จริงใน Inventory เป็น Template รวมของที่อยู่ในกระเป๋าซ้อนได้ ไม่ได้จำกัดเฉพาะ Bandage หรือยา

Template แยกตามสถานะสำคัญแทนการรวมแค่ FullType เช่น Propane Tank / Fluid Container ที่เต็ม ครึ่ง หรือว่าง, Condition / Used state และสถานะอาวุธที่เกี่ยวข้องสามารถแยกเป็นคนละ Template ได้เมื่อ state ต่างกัน

เพื่อรองรับมอดที่แก้/แทน Item Script, HARVEST จะไม่ใช้ ScriptManager lookup ธรรมดาเป็น whitelist ของ UI อีก ฝั่ง Authority จะ preflight ตอนกด START SEARCH ถ้าไอเท็มจากมอดหรือ runtime item นั้นสร้างกลับอย่างปลอดภัยไม่ได้จริง จะขึ้นข้อความ compatibility limit ก่อนหัก/จอง Harvest

ORDER SIZE

  • จำนวน x1 → x500
  • x1–x20 ใช้ขั้นต่ำ 20 Harvest
  • x21–x500 ขั้นต่ำเท่ากับจำนวนที่สั่ง
  • ส่งเกินขั้นต่ำช่วยเร่งช่วงค้นหา
  • น้ำหนักรวมทั้ง Batch เพิ่มเวลาขนกลับ

STAND LEVEL SEARCH SPEED

Stand Level ช่วยลดช่วง Search Work แบบเส้นตรง: Lv1 ใช้เวลาเดิม และ Lv100 เหลือ 50% ของช่วงค้นหา แต่เวลาเดินทางออก/กลับและช่วงส่งของไม่ถูกเร่งด้วย Level

ACTIVE JOBS / RECALL

หน้าเดียวกันแสดงงานทั้งหมด Phase และ ETA กด RECALL ยกเลิกเฉพาะงานนั้น คืน Harvest ที่จองทันที และของที่ยังไม่ได้ส่งของงานนั้นจะหายไป

เสียง Search แยกตาม Job และตามตำแหน่งงานจริง งานหลายงานจึงเล่นเสียงพร้อมกันได้ และ Personal Project JoJo Volume มีผลกับเสียง Search 3D ด้วย

SKILL 4 — HARVEST STORM

ขั้นต่ำ 33 Harvest ปล่อยฝูงรอบตัวเพื่อสร้างแรงกดดัน AOE ต่อเนื่อง มี repeated hit / mini knockback / crowd interruption

ยิ่งส่งเยอะระยะเวลายิ่งยาวจนถึงเพดาน 38 วิเมื่อใช้เต็ม 500 Barrage Guard สามารถป้องกัน Hit ของผู้เล่นที่กำลัง Guard โดยไม่ยกเลิก Storm ต่อเป้าอื่น

PROJECT JOJO CLIENT OPTIONS

HARVEST รองรับ Stand HUD Normal / Minimal / Hidden, HUD Opacity/Scale, Personal Project JoJo Volume และ Targeting Mode ของ Core โดย Search Command UI จะยังแสดงเพราะเป็นหน้าจอที่จำเป็นต่อการเล่น Core v0.23.0.250 มีปุ่ม Reset การแสดงผล/เสียง/Targeting และ Reset Keybind แยกกัน
