PROJECT JOJO — FULL SYSTEM GUIDE

Shared rules for Singleplayer / Host / Multiplayer: Stand Arrows, targeting, Barrage systems, temporal systems, progression, PvP and Official Addons.

New in .284: LV.1 remains 50% Damage, LV.100 now reaches 120%, the new XP curve is about 1,059 Stand kills, and many skills gain level-based cooldown mastery. Open the full cooldown table →

1) STAND ARROW

Default zombie drop is roughly 1/250. One Arrow has 3 successful uses: 3/3 → 2/3 → 1/3 → removed. Super Arrow changes random roll into a loaded-Stand selection list; Infinite Stand Arrow prevents Condition loss.

2) CONTROLS / CHARGE

CAPS LOCK summons/dismisses. 1–4 activate skills. Many skills have Tap/Hold behavior: SP/TW Skill 4 is Time Dash / Time Stop, while KC Skill 4 is Time Dash / Time Erase.

3) TARGETING / FIRST CONTACT

Mouse, Facing Direction and Controller Aim are supported. Input mode does not bypass collision or first-contact rules.

4) BARRAGE CLASH / GUARD

Supported offensive Barrages can clash and consume hits against each other. SP/TW/CD/SC/KC have frontal Barrage Guard against supported projectiles such as TW Knife, SC Rapier and CD Glass. It is not 360-degree immunity.

5) TIME STOP

SP stops time for 5 sec; TW for 9 sec. Frozen actors, animations and supported projectiles pause, while deferred damage resolves when time resumes. Core .282+ adds hard animation freeze, an incoming-damage firewall and MP projectile temporal parity.

6) TIME STOP vs TIME ERASE

Temporal powers do not stack freely. Existing Time Erase duration is consumed by incoming Time Stop according to the temporal authority rules. KC Time Erase lasts 10 sec; at LV100 its Skill 4 cooldown reaches 20 sec.

7) STAND LEVEL / MASTERY

Every Stand stores LV.1–100 separately. Only Stand zombie kills grant EXP. LV.1 = 50% damage and LV.100 = 120%. Authored base cooldowns gradually move toward skill-specific Mastery targets. Rerolling does not erase old Stand progress.

8) SUMMONED STAND DEFENSE

While a registered Stand is summoned, its owner receives 33% NET damage reduction. This is not invulnerability.

9) PvP / SAFETY

HP damage respects Project Zomboid PvP/Safety, while certain utility/CC interactions have separate rules: Time Stop, THREE FREEZE, Space Pull, Epitaph and Official Addon commands.

10) CLIENT OPTIONS / SANDBOX

Client: Targeting Mode, HUD mode, opacity, scale, personal volume and keybinds. Sandbox: Arrow Drop, Stand Damage, Stand Level, Arrow on Join, Infinite Arrow, Super Arrow and addon-specific settings.
