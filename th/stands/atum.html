ATUM

รีเช็กกับโค้ด Addon v0.24.0.042 + Project JoJo Core v0.23.0.237

ตัวเลขด้านล่างมาจากค่าจริงใน Addon ปัจจุบัน ATUM ใช้ระบบ Damage / Level / PvP / Safety / First-Contact / Multiplayer ของมอดหลัก ไม่ได้สร้าง Combat resolver แยกอีกชุด

สกิล 1 — PUNCH

CD 0.44 วิระยะ 2.80Base Damage 0.12ชาร์จเต็ม 1.15 วิ

หมัดพื้นฐาน ใช้ First-Contact ของ Project JoJo ตรง ๆ: Target Radius 1.05, Aim Snap 1.35 และมี Hit Delay 155 ms ก่อนตรวจสัมผัสจริง ชาร์จเต็มเพิ่มดาเมจ ×1.85 และแรงกระแทก ×1.45

ดาเมจชาร์จเต็ม: 0.12 × 1.85 = 0.222 ก่อน Level / Sandbox / PvP / Crit scaling ของมอดหลัก

สกิล 2 — BARRAGE

CD 5.1 วิระยะ 3.100.034 / hit14 hitชาร์จเต็ม 1.65 วิ

Rush เลี้ยวตามเมาส์สด ใช้ First-Contact และระบบเป้าหมายของมอดหลัก Interval ระหว่าง hit = 140 ms และ Start Delay = 120 ms

ปกติ: 14 × 0.034 = 0.476 theoretical raw total ถ้าโดนครบทุก hit

ชาร์จเต็ม: 22 hit และดาเมจต่อ hit ×1.18 → 0.04012 ต่อ hit หรือประมาณ 0.88264 theoretical raw total ก่อน Level / Sandbox / PvP / Crit

สกิล 3 — MIND READ / YES–NO

CD 0 วิระยะเวลา 10 วิใช้ 1 Mind PointDodge Grace 0.5 วิ

เปิด Future Read เป็นเวลา 10 วิ ถ้า Gauge = 0 จะกดไม่ได้ กด Skill 3 ซ้ำในระหว่างที่ยังทำงานอยู่จะ ปิดฟรี ไม่เสียแต้มเพิ่มและไม่มีคูลดาวน์

Mind Read เป็น one-use dodge ด้วย เมื่อการโจมตี Stand ที่รองรับ commit มาถึง ATUM สถานะจะถูกใช้เพื่อหลบ 1 ครั้ง แล้วขยับผู้โจมตีออกด้านข้างใกล้จุดเดิมของเขา — ไม่ดึงมือปืนหรือผู้เล่นระยะไกลเข้าหา ATUM

ระยะตรวจ attacker ปกติสูงสุด 4.25 ช่อง ส่วนผู้เล่นรองรับได้ไกลถึง 35 ช่องเพื่อให้กระสุน/ท่าระยะไกลใช้ Future Read ได้ โดยการขยับ attacker อยู่ใกล้ตำแหน่งเดิมของตัวเอง

MIND GAUGE

เริ่ม 0สูงสุด 100S3 ใช้ 1ชนะเกม +0 ถึง +3

ทุกครั้งที่เจ้าของ ATUM ชนะ Skill 4 หลังผลแพ้ชนะถูก resolve แล้ว จะสุ่มแต้ม Mind Gauge 0–3 และเล่น Finish Point

ถ้าใช้ S3 → S4 แล้วทายใจถูก จากนั้นยังชนะเกมอยู่ รางวัลจะถูกบังคับให้ได้อย่างน้อย +1 เพื่อมีโอกาสคืนแต้มที่ใช้เปิด Mind Read

สกิล 4 — GAMBLE

CD 3 วิระยะ 2.80Contact Damage 0Hit Delay 155 ms

ATUM พุ่งหมัดด้วยค่า First-Contact เดียวกับ Skill 1 ทุกอย่าง — Range 2.80 / Target Radius 1.05 / Aim Snap 1.35 / Hit Delay 155 ms — แต่ contact นี้ทำดาเมจ 0 และใช้เพื่อเปิดเกมเท่านั้น

เมื่อโดนเป้าหมายจริง เซิร์ฟเวอร์จะสุ่ม Rock Paper Scissors / Baseball / Racing ด้วยโอกาสเท่ากัน 1/3 ต่อเกม และเมื่อเกมเริ่มแล้ว กด 4 ซ้ำเพื่อ Cancel ไม่ได้

SOUL EXTRACTION — ถ้า ATUM ชนะเกิดอะไรขึ้น?

ม็อบ / NPC

ผู้แพ้ที่เป็นเป้าหมายจะโดน ATUM Finisher ค่า 9999 ผ่าน damageLivingTarget — ในคอนเซปคือ ATUM ดึงวิญญาณของผู้แพ้ และเป้าหมายตาย

ผู้เล่นที่ PvP อนุญาต

ถ้า PvP / Safety อนุญาต HP damage ผู้เล่นที่แพ้จะโดน Finisher แบบเดียวกันและเสียชีวิต

ผู้เล่นที่ Safety ป้องกัน

ถ้ากฎ PvP ป้องกัน HP damage จะ ไม่ถูกฆ่า แต่โดน Blackout 3 วิแทน เพื่อไม่ให้ Skill 4 ข้ามกฎ PvP/Safety ของมอดหลัก

ถ้าเจ้าของ ATUM แพ้

เจ้าของ ATUM จะไม่ถูก Finisher ของตัวเอง แต่ Skill ทั้ง 4 ถูก Silence/Lock เป็นเวลา 7 วิ และตอน resolve จะโดน Blackout 3 วิ

ลำดับจบเกมปัจจุบัน

แสดงผลแพ้/ชนะประมาณ 0.5 วิ → ปิด UI จริง → ยังซ่อน/กันดาเมจต่อ 0.5 วิ → คืนผู้เล่นกลับโลก → อีก 0.5 วิจึง resolve ผู้แพ้ / Soul Finisher → ถ้า ATUM ชนะจึงเล่น Finish Point และสุ่ม Mind Gauge 0–3

ROCK PAPER SCISSORS

เวลาเลือก

ฝั่งที่ถูกท้าได้เวลา 8 วิในการเลือก Rock / Paper / Scissors ถ้าเป็นซอมบี้ เซิร์ฟเวอร์จะสุ่มคำตอบแทน

เจ้าของ ATUM

มีตัวจับเวลา 8 วิบน UI เพื่อสร้างแรงกดดัน แต่ในโค้ดปัจจุบัน timer ฝั่งเจ้าของเป็น visual pressure ไม่ได้ auto-forfeit แบบฝั่งผู้ถูกท้า

S3 → S4

มีช่วงทายใจแยก 5 วิ ถ้าทายถูกขึ้น YES และรู้คำตอบจริง ถ้าทายผิดขึ้น NO และอย่างน้อยรู้ว่าตัวเลือกที่เพิ่งทาย “ไม่ใช่” คำตอบ

เสมอ

ถ้าออกเหมือนกันจะเป็น Tie ไม่มี Soul Finisher และไม่มีรางวัล Mind Gauge จากการชนะ

BASEBALL

Intro

เปิดภาพ/เสียงก่อนประมาณ 6.6 วิ แล้วค่อยเริ่มช่วงเลือกจริง ไม่หักเวลาตัดสินระหว่าง Intro

HIGH / MIDDLE / LOW

ช่วงเลือกจริง 8 วิ เป้าหมายเลือกตำแหน่งลูก และ ATUM ต้องเลือกตีให้ตรง ถ้าตรง = Hit / ATUM ชนะ ถ้าผิด = Miss / ATUM แพ้

HOME RUN

ถ้าตีถูก มีโอกาส Home Run 10% ตามปกติ และถ้าตีถูกใน 2 วินาทีสุดท้าย จะการันตี Home Run

ผลเชิงระบบ

Hit และ Home Run ต่างเป็น “ATUM ชนะ” เหมือนกันในระบบ Soul Finisher / Gauge; Home Run คือผลพิเศษด้านภาพและเสียง ไม่ได้สุ่มแต้มเพิ่มต่างหาก

RACING

Intro8.8 วิ
Ready4.5 วิ
Main Race36 วิ
Vehicle HP100
Base Speed5.7
1 — BOOST

กดค้าง ไม่มีคูลดาวน์ ใช้ HP ประมาณ 2.2 → 4.6 ต่อวินาที ตามเวลาที่ค้าง Ramp เต็มใน 2.2 วิ ความเร็วตัวเองไล่จาก ×1.28 ถึง ×1.95 และทำให้อีกคันเสีย relative pace ถ้ามีแค่ฝ่ายเดียว Boost ถ้าทั้งสอง Boost พร้อมกัน ความได้เปรียบด้านความเร็วจะหักล้าง แต่ทั้งคู่ยังเสีย HP

Launch Boost ลับ

ช่วง Ready กด BOOST รัวให้ครบ 5 ครั้งในหน้าต่าง 1.4 วิ จะได้บูสฟรีตอนเริ่มประมาณ 2 วิ ถ้า S3 ทาย Boost/No Boost ของคู่แข่งถูก จะเพิ่มโบนัสอีก +2 วิ

2 — ATTACK

ชาร์จเตือน 1.5 วิ → Dash 260 ms → Return 350 ms, CD 4.8 วิ ถ้าโดนปกติทำดาเมจรถ 16 และลด progress 0.55 พร้อม Slow 1.1 วิที่ ×0.78

ATTACK vs BLOCK

ถ้าอีกคัน Block ถูกจังหวะ ผู้โจมตีโดน Counter Damage 12 แทน ถ้าทั้งสอง Attack ชนกันจะ Clash และทั้งสองเสีย 8 HP

3 — BLOCK

เสีย 4 HP ตอนกด เปิด 100% protection window 0.75 วิ และมี CD 5 วิ

ชนกันด้วยเมาส์

การเอารถเบียดกันปกติ ไม่ทำดาเมจ ระบบจะแยกรถออกจากกันเท่านั้น ดาเมจรถมาจาก ATTACK / Counter / HP cost / ตกถนน

แพ้ทันที

HP รถเหลือ 0 = แพ้ทันที และถ้าออกนอกถนนในช่วงที่ยังบังคับเมาส์ได้ จะถูกตั้ง HP เป็น 0 และแพ้ทันที

Final Stretch

Main Race ต้องวิ่งครบ 36 วิ ก่อน Finish Road ถึงจะมา ระบบ Fade 0.76 วิและจำระยะห่างจริงไว้ รถตามถูกวางเป็นจุดเริ่ม รถนำอยู่หน้าตาม gap เดิม แล้วเส้นชัยอยู่ห่างจากรถนำอีก 26 progress โดยช่วง Final ปิดการเลี้ยวเมาส์ เหลือ BOOST / ATTACK / BLOCK แข่งกันเข้าเส้นจริง

AI Difficulty

สุ่ม EASY 10% / MEDIUM 20% / HARD 30% / HARDCORE 40% ระดับสูงจะตัดสินใจเรื่อง Boost / Attack / Block และการบริหาร HP ดีกว่า

DAMAGE / LEVEL หมายความว่ายังไง?

ตัวเลข Damage ด้านบนคือ raw skill damage ใน Config ก่อนระบบกลางของ Project JoJo คูณเพิ่ม/ลด ระดับ Stand ใช้ Damage Multiplier จาก 50% ที่ Lv.1 → 100% ที่ Lv.100 แบบเส้นตรง ถ้าปิด Stand Level จะนับเป็น Max Level ทันที และยังมี Sandbox Stand Damage, PvP multiplier และ Critical ที่อาจเปลี่ยนดาเมจจริงอีกชั้น

วิธีเล่นจริง / กลยุทธ์

อย่าเผา Mind Point

S3 ไม่มีคูลดาวน์ก็จริง แต่แต้มไม่ฟรี ถ้ายังไม่มีภัยหรือยังไม่พร้อมกด S4 เก็บ Gauge ไว้ก่อนจะคุ้มกว่า

S3 → S4 คือหัวใจ

อ่านใจ → สัมผัสเป้าด้วย Gamble → ใช้ YES/NO ลดความเสี่ยง → ชนะเกม → ดึงวิญญาณ → ลุ้นแต้มคืน 0–3

Baseball เล่นกับเวลา

เลือกให้ถูกสำคัญที่สุด แต่ถ้ามั่นใจแล้ว การรอเข้า 2 วิสุดท้ายแล้วยังตีถูกจะเปลี่ยนเป็น Home Run การันตี

Racing อย่ากดแต่ Boost

HP คือทั้งพลังชีวิตและเชื้อเพลิง ถ้าเผา Boost จนต่ำมาก คุณจะเปิดช่องให้ ATTACK ปิดงานทันที

จำไว้: Skill 4 เป็นเกมเดิมพันจริง — ถ้า ATUM ชนะ เป้าหมายที่กฎ PvP อนุญาตจะโดน Soul Finisher; ถ้า ATUM แพ้ เจ้าของจะถูกปิด Skill 7 วิ และเสียจังหวะหนักมาก
