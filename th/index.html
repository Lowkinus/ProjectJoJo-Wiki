CLIENT OPTIONS & SANDBOX

วิธีเล็ง Stand

Mouse / Pointer = ใช้ทิศเคอร์เซอร์ • Facing Direction = ใช้ทิศที่ตัวละครหัน • Controller Aim = ใช้แกนเล็งของจอย ถ้าสติกอยู่ใน dead-zone จะกลับไปใช้ทิศตัวละคร

ตัวอย่าง: ถ้าเล่น Project Viewpoint แล้วไม่อยากพึ่งเคอร์เซอร์ ให้ใช้ Facing Direction การโจมตีจะไปทางที่ตัวละครหัน แต่กำแพงและตัวที่ยืนขวางยังมีผลตามปกติ

HUD / เสียงส่วนตัว

เลือก HUD แบบ Normal / Minimal / Hidden, ปรับความโปร่งใส 20–100%, ขนาด 70–150% และเสียง Project JoJo ของตัวเอง 0–100% ได้ ค่าเหล่านี้เป็นของผู้เล่นแต่ละคน ไม่ได้เปลี่ยนบาลานซ์เซิร์ฟเวอร์

แม้ซ่อน HUD หน้าจอที่จำเป็นต่อการเล่น เช่น HARVEST Search, ATUM minigame และ Heaven's Door Book/Command ยังเปิดได้

Super Arrow

ปิดเป็นค่าเริ่มต้น เมื่อปิด Stand Arrow จะสุ่มจาก Stand Pool ที่โหลดอยู่ตามปกติ เมื่อเจ้าของโลกเปิด Super Arrow การใช้ Stand Arrow จะเปิดรายการให้เลือก Stand จากตัวที่ลงและลงทะเบียนอยู่จริง รวม Addon ที่เปิดใช้งานด้วย

สำคัญ: Super Arrow เปลี่ยนจาก “สุ่ม” เป็น “เลือก” แต่ไม่ได้ทำให้ Arrow ใช้ไม่หมด — 1 Arrow ยังมี 3 successful uses เว้นแต่จะเปิด Infinite Stand Arrow เพิ่มอีกตัวเลือก

Arrow Drop Multiplier

ใช้ปรับความหายากของ Stand Arrow ในโลก ค่าเริ่มต้นของดรอปซอมบี้อยู่ประมาณ 1/250 ที่ 1x และยังมีโอกาสเจอจาก world loot ด้วย

ตัวอย่าง: อยากให้ Stand เป็นของหายากใน Survival ให้คงค่าต่ำ ๆ; เซิร์ฟที่อยากให้ทุกคนได้ลอง Stand เร็วขึ้นสามารถเพิ่ม multiplier ได้

Stand Damage

ปรับความแรงรวมของดาเมจจาก Stand สำหรับโลก/เซิร์ฟเวอร์ ไม่ใช่การปรับเฉพาะผู้เล่นคนเดียว

ถ้ารู้สึก Stand แรงเกินสำหรับเซิร์ฟที่เน้น Survival ลดค่านี้ได้โดยไม่ต้องแก้สกิลทีละ Stand

Stand Level System

เปิด = แต่ละ Stand เก็บ LV.1–100 แยกกัน โดยเลเวลต่ำเริ่มอ่อนกว่าพลังเต็ม • ปิด = Stand ใช้พลังเต็มทันที แต่ Progress ที่เคยสะสมไว้ยังเก็บอยู่

ตัวอย่าง: Star Platinum LV.70 และ The World LV.20 เป็นคนละ Progress เปลี่ยน Stand แล้ว LV.70 ของ SP ไม่หาย

Give Stand Arrow on Join

ถ้าเปิด ผู้เล่นจะได้รับ Stand Arrow ตอนเข้าเกมตามระบบที่กำหนด เหมาะกับเซิร์ฟที่ไม่อยากให้ทุกคนต้องฟาร์มศรก่อนเริ่มใช้ระบบมอด

Infinite Stand Arrow

ปกติ Arrow ใช้สำเร็จได้ 3 ครั้ง: 3/3 → 2/3 → 1/3 → หาย ถ้าเปิด Infinite Stand Arrow จะไม่เสีย Condition เมื่อใช้งานสำเร็จ

Reset Options / Keybinds

Reset Visual / Audio / Targeting คืน HUD, opacity, scale, personal volume และ Targeting Mode โดยไม่แตะปุ่มสกิล • Reset Keybinds คืน Caps Lock และปุ่ม 1–4 แยกต่างหาก

สิ่งที่ควรรู้ก่อนเข้าฝูง

DIRECTIONAL FIRST-CONTACT

สกิลใช้ระยะจริงของตัวเองและตรวจ “สิ่งแรกที่ขวางแนวโจมตี” ก่อน ไม่ได้ล็อกเป้าทะลุกำแพงเพราะเอาเมาส์ชี้ไปไกล

BARRAGE CLASH

Barrage ฝั่งโจมตีที่รองรับสามารถชนกันได้เมื่ออยู่ใกล้และหัน/เล็งเข้าหากันจริง ฮิตที่ชนกันจะหักล้างกันก่อนดาเมจปกติ

BARRAGE GUARD

Barrage ของ Stand ที่รองรับสร้างแนวกันด้านหน้า จึงปัด projectile บางชนิดได้ เช่น TW Knife, SC Rapier Shot และ CD Glass แต่ด้านข้าง/ด้านหลังและ AOE ไม่ได้ใช้กติกาเดียวกัน

TIME STOP

SP หยุดเวลา 5 วิ, TW 9 วิ คน/สิ่งที่ถูกหยุดและโปรเจกไทล์ในพื้นที่จะค้าง ดาเมจที่พักไว้จะลงเมื่อเวลาเดินต่อ

TIME STOP vs TIME ERASE

สองระบบเวลาไม่ทับกันแบบไม่มีเงื่อนไข ถ้า Erase เริ่มก่อน เวลาของ Stop จะถูกนำไปหักกับเวลาที่ Erase เหลือก่อน

SUMMONED STAND DEFENSE

ขณะ Stand ที่ลงทะเบียนถูกเรียก เจ้าของรับ NET damage ลดลง 33% เป็นการลดดาเมจ ไม่ใช่อมตะ

PvP / SAFETY

ดาเมจผู้เล่นเคารพ PvP/Safety ของ Project Zomboid แต่ Utility/CC บางชนิดมีเงื่อนไขของตัวเอง เช่นการหยุด ดึง หรือย้ายตำแหน่ง อ่านรายละเอียดในหน้าสกิลก่อนใช้กับเพื่อน

VEHICLE / WORLD SAFETY

การโจมตีมีการชนกับรถและโลก แต่มี safeguard กันการโจมตีถี่ ๆ ไปทำสถานะรถหรือวัตถุ custom ที่ไม่รองรับเสียหายแบบมั่ว
