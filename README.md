# Project JoJo Wiki — GitHub Pages Ready

Static bilingual wiki for Project JoJo (Project Zomboid Build 42+).

## Publish

Recommended repository name: `ProjectJoJo-Wiki`

1. Create a public repository named `ProjectJoJo-Wiki`.
2. Upload all files from this folder to the repository root.
3. GitHub → Settings → Pages.
4. Build and deployment → Deploy from a branch.
5. Branch: `main`, folder: `/ (root)`.
6. Save.

Expected URL for the connected GitHub account:

`https://lowkinus.github.io/ProjectJoJo-Wiki/`

Then replace `PROJECT_JOJO_WIKI_URL` inside `STEAM_WORKSHOP_SHORT.txt`.

## Updating

- Stands/content: `assets/data.js`
- System text/changelog/UI translations: `assets/app.js`
- Visual design: `assets/style.css`
