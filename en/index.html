LATEST SYSTEMS

CORE SYSTEMS v237

DIRECTIONAL FIRST-CONTACT

Mouse defines direction while contact checks use the skill's true maximum range. The first body intersecting the attack corridor is selected first.

BARRAGE CONTACT

Barrage may retain contact for ~240 ms when no new target is found, with 0.30-tile side tolerance and up to 3 catch-up hits per update.

BARRAGE GUARD

Enabled for SP / TW / CD / SC / KC • about 2.5 tiles total width • only supported projectiles crossing the guard from the front are deflected.

FIREARMS / MOD PROJECTILES

Vanilla firearms have a native per-hit hook but still need live B42 validation across SP/Host/Dedicated. Third-party projectiles need API integration.
