HEAVEN'S DOOR

เปิดเป้าหมายเป็นหนังสือ สะสม REWRITE แล้วเขียนคำสั่งด้านการเคลื่อนที่ ข้อห้าม ความรู้ ไอเท็ม และ Scripted Zombie AI

HEAVEN'S DOOR v0.1.62 คือรุ่น Release Integration สำหรับ Project JoJo Core v0.23.0.250+

รองรับ Singleplayer / Host / Multiplayer

วิธีได้ HEAVEN'S DOOR

ใช้ Stand Arrow ปกติของ Project JoJo ถ้าใช้กฎปกติ Heaven's Door จะอยู่ใน Registered Stand Pool สำหรับการสุ่ม ถ้าเปิด Super Arrow และเปิด Addon นี้อยู่ HEAVEN'S DOOR จะขึ้นในรายชื่อให้เลือกอัตโนมัติ

ปุ่ม

CAPS LOCK — เรียก / เก็บ

1 — BARRAGE

2 — PAGE OPEN BARRAGE

3 TAP — PAGE TOUCH / สัมผัสจริงเพื่อเปิดหนังสือเป้าหมาย

3 FULL — WRITE MYSELF

4 TAP — วาง BOOK TRAP

4 HOLD — เก็บ BOOK TRAP ที่วางอยู่

ระบบเล็ง / CLIENT OPTIONS กลาง

Heaven's Door ใช้ระบบ Mouse / Pointer, Facing Direction และ Controller Aim จาก Core เหมือน Stand อื่น สกิลสัมผัสยังผ่าน Directional First-Contact ไม่ได้กลายเป็น Auto-lock ทะลุกำแพง

เกจ REWRITE ที่เป็น Passive HUD รองรับ Normal / Minimal / Hidden, HUD Opacity และ HUD Scale แล้ว Minimal จะเหลือเฉพาะชื่อ Stand/คูลดาวน์กลาง ส่วน Hidden จะซ่อน Passive HUD ทั้งหมด

Book / Command UI ยังเปิดตามปกติ เพราะเป็น Gameplay UI และเสียง Heaven's Door ใช้ Personal Project JoJo Volume ของ Core

REWRITE — 0 / 100

มี REWRITE สูงสุด 100 และฟื้นพื้นฐาน 3 ต่อวินาที คำสั่งที่เขียนใช้ REWRITE ตามความแรงของผล

SKILL 1 — BARRAGE

รัวหมัดระยะใกล้ผ่าน Rush/Contact กลางของ Core ปกติ 10 Hit และชาร์จเต็มเป็น 18 Hit พร้อมเพิ่มดาเมจ ใช้ Stand Level, Stand Damage, PvP/Safety และ Multiplayer Authority กลาง

SKILL 2 — PAGE OPEN BARRAGE

Rush สำหรับเปิดหนังสือเป้าหมายผ่านการสัมผัสจริง ใช้โครงระยะ/ชาร์จเดียวกับ Skill 1 แต่ดาเมจต่อ Hit ต่ำกว่า

SKILL 3 — PAGE TOUCH / WRITE MYSELF

Tap: สัมผัสทางกายภาพแบบ 0 Damage ถ้าโดนเป้าหมายที่รองรับจะเปิด Book UI และใช้คูลดาวน์ Skill 3 ปกติ

Full Charge: เปิด Heaven's Door กับตัวเอง เส้นทาง Self Write แยกจากคูลดาวน์ Tap

เมื่อเปิดหนังสือเป้าหมายสำเร็จแล้ว Record การเปิดหนังสือจะคงอยู่ ไม่หมดเพียงเพราะ UI เปิดนาน

WRITTEN COMMANDS

คำสั่งแบ่งเป็น Mind / Memory, Orders, Restrictions, Body Commands, Knowledge, Items และ Special โดยแสดงตามชนิด/ความสามารถของเป้าหมาย

  • Mind / Memory: ลด Panic/Stress/เบื่อ/เศร้า, Stay Awake, No Pain/No Fear, Blind และ Forget / Ignore Me
  • Orders: Come, Follow, Go Away, Run Forward/Backward, หันหลัง, นั่ง/ยืน/ตะโกน, Zombie Run/Walk, Guard Me, Attack Them
  • Restrictions: Do Not Move/Run/Attack, Do Not Attack Me และล็อก Stand ชั่วคราวกับผู้เล่นที่รองรับ
  • Body: Hunger/Thirst, Forget How to Breathe, Trip, Hurt Yourself, Fly Away, Run Into
  • Knowledge: โบนัสเรียน Skill ที่เลือก 5× ชั่วคราว ไม่แจกเลเวลถาวรฟรี
  • Items: ให้ทิ้งของในมือ ถอดเสื้อผ้าบางชิ้น หรือส่งของใน Inventory เมื่อเป้าหมายรองรับ

SCRIPTED WRITTEN-ZOMBIE AI

Guard/Attack จะถือ Ownership ของ Written Zombie ในระบบ Heaven's Door ไม่ปล่อยกลับไปเลือกเหยื่อ Vanilla เอง รุ่น v0.1.62 เก็บ Target Ownership Hotfix จาก v0.1.61 ไว้ครบ: ถ้าเหยื่อของ ATTACK THEM กลายเป็น Written Ally อีกตัว ผู้โจมตีจะหาเป้าใหม่หรือรออย่างปลอดภัย แทนการหันกลับมาหาคนเขียน

RUN INTO ถ้า Actor-target หายจะยกเลิกสะอาด ไม่ตีความเป็นชนกำแพงปลอม

COMMAND PHYSICS POLISH

RUN INTO / FLY AWAY ใช้ Physics/Ragdoll reaction เมื่อเป้ารองรับและมี Native fallback, TRIP ตัด Double-knock, FORGET HOW TO BREATHE ทำดาเมจเป็นช่วงโดยไม่ Knockdown spam และ HURT YOURSELF ไม่บังคับล้มเพิ่ม

ดาเมจคำสั่งอันตรายผ่าน Central Damage ของ Project JoJo จึงยังอิง Stand Level, Global Stand Damage และ PvP/Safety

SKILL 4 — BOOK TRAP

Tap 4 วาง Book Trap ตามระยะปัจจุบัน ตัว Trap คงอยู่และส่งผลได้สูงสุด 10 Pulse/Hit ตามกฎของมัน Hold 4 คือเก็บ Trap ที่วางอยู่ ไม่ใช้ชาร์จเพื่อขยายระยะแล้ว

ระบบกลาง

Heaven's Door v0.1.62 ลงทะเบียนใน Core Stand Pool/StandDefs แล้ว จึงใช้ Stand progression, Summoned Stand Defense ลดดาเมจสุทธิ 33%, Client Options และเข้า Super Arrow อัตโนมัติเมื่อ Addon เปิดอยู่
