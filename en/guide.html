This page explains Project JoJo's shared systems in plain language: what each rule does, what the player needs to know, and examples for the parts that can be confusing.

PROJECT JOJO — FULL SYSTEM GUIDE

1) STAND ARROW — Getting a Stand

Stand Arrows can appear in world loot and rarely drop from zombies. At the default 1x setting, the base zombie drop is roughly 1 in 250. Garages, tool crates, mechanic shops and mechanic storage are good places to look; vehicle loot is intentionally rarer.

The Arrow uses Project Zomboid Condition directly: 3/3 → 2/3 → 1/3 → gone. In simple terms, one Arrow has three successful uses and Condition is spent after a successful Stand assignment.

Example: Rerolling from Star Platinum to The World does not delete Star Platinum's progression. If that character gets SP again later, the old SP progression remains.

2) SUPER ARROW — Random roll or direct choice

Super Arrow is OFF by default. With it disabled, using a Stand Arrow rolls randomly from the Stand Pool currently loaded by the game.

When the world/server enables Super Arrow, the same Arrow opens a choice list built from Stands that are actually registered. Core Stands and enabled official addons appear automatically; an addon that is not installed/enabled cannot be selected.

The chosen Stand is still validated by authority so Singleplayer, Host and Multiplayer use the same assignment rules.

Do not confuse it with Infinite Arrow: Super Arrow changes “random” into “choose.” The Arrow still loses Condition normally unless Infinite Stand Arrow is enabled separately.

3) BASIC CONTROLS / Tap vs Hold

CAPS LOCK summons or dismisses the Stand. Top-row 1 / 2 / 3 / 4 are Skills 1–4.

Many moves have different tap and full-charge results. Star Platinum/The World Skill 4 is Time Dash on tap and Time Stop on full hold; King Crimson Skill 4 is Dash on tap and Time Erase on full hold.

Example: When you roll a new Stand, do not test each key only once and assume that is the full kit. Try both tap and hold.

4) TARGETING MODE

Open Options → Mods → Project JoJo and choose:

  • Mouse / Pointer — attack direction follows the cursor.
  • Facing Direction — attack direction follows the character's facing. Useful for controller/keyboard play and view mods where you do not want to rely on a cursor.
  • Controller Aim — uses the controller aim/attack axis and falls back to Facing Direction inside the dead-zone.

Changing the input method does not change skill range, remove walls, or turn attacks into through-wall auto-lock.

5) DIRECTIONAL FIRST-CONTACT

Line/contact skills use their real authored reach, then check the first valid contact on that attack line. A nearby cursor no longer shortens a long move, but the move also cannot skip a body or wall that should block it.

Example: Star Finger reaches farther than a punch, but a zombie standing directly in front can still be the first thing hit even if the cursor is placed past it.

6) BARRAGE CONTACT / CLASH / GUARD

Barrage Contact keeps a small grace window so rapid hits do not vanish because a target moves a tiny amount or a frame arrives late.

Barrage Clash lets supported offensive Barrages collide when fighters are close enough and genuinely aiming/facing into each other. Colliding hits cancel before normal damage.

Barrage Guard creates a forward defense line during supported Barrages. It can stop specific projectiles such as The World Knife, Silver Chariot Rapier Shot and Crazy Diamond Glass/Homing.

Example: Guarding the front against a knife does not mean rear shots, explosions, large fire areas or THREE FREEZE use the same rule.

7) TIME STOP

Star Platinum stops time for 5 seconds; The World for 9. Frozen actors are pinned, delayed damage is released when time moves again, and moving projectiles inside the stopped area pause before resuming from the same point.

SP/TW users caught inside another Time Stop have their own time-power interaction; this does not mean they simply walk for free through someone else's entire Stop.

8) TIME STOP vs TIME ERASE

Time Stop and Time Erase do not freely run at full strength on top of each other. An active/pending Stop blocks a new full Erase. If Erase already existed, incoming Stop duration is spent against the remaining Erase time first; only excess becomes real stopped time.

Example: If Erase has 4 seconds remaining and a 9-second Stop arrives, roughly the first 4 seconds cancel against Erase and only the remaining portion becomes stopped time.

9) STAND LEVEL

Every Stand stores its own Lv.1–100 progression. Lower levels start around half of full level-scaled damage and climb toward full power at Lv.100. Stand-caused zombie kills grant EXP.

Switching Stands does not erase old progression. Turning the Stand Level System OFF makes Stands operate at full power while saved progression remains preserved.

10) SUMMONED STAND DEFENSE

While a registered Stand is summoned, the owner takes 33% less net damage, based on actual damage after vanilla/other-mod reductions. It is damage reduction, not invulnerability.

11) PvP / SAFETY

HP/lethal player damage respects Project Zomboid PvP/Safety. Project JoJo also distinguishes damage from utility/crowd control, so some non-damaging interactions have their own rules.

Examples that need their specific Stand rules include Time Stop, THREE FREEZE, Space Pull, Epitaph/reposition, First Bomb attachment and addon utility commands.

12) VEHICLE / WORLD SAFETY

Stand attacks still respect vehicles and world collision, while safeguards separate “this object blocks the attack” from “the attack should mutate this object's durability/state.” Unsupported custom objects are protected instead of being randomly damaged.

13) CLIENT OPTIONS — Per-player settings
  • Stand Targeting Mode: Mouse / Facing / Controller
  • Stand HUD: Normal / Minimal / Hidden
  • HUD Opacity: 20–100%
  • HUD Scale: 70–150%
  • Personal Project JoJo Volume: 0–100%
  • Personal keybinds

Reset Visual / Audio / Targeting restores presentation/audio/targeting without touching keybinds. Reset Keybinds separately restores Caps Lock and Skills 1–4.

Required gameplay UI such as ATUM minigames, HARVEST Search and Heaven's Door Book/Command stays available even if the passive Stand HUD is Hidden.

14) SANDBOX SETTINGS — Shared world/server settings

Arrow Drop Multiplier — controls how rare Stand Arrows are.

Stand Damage — controls overall Stand damage.

Stand Level System — enables/disables Lv.1–100 progression scaling.

Give Stand Arrow on Join — optional starting Arrow.

Infinite Stand Arrow — prevents Condition loss after a successful Arrow use.

Super Arrow — OFF by default; when enabled, turns random rolling into a list of currently registered Stands.

Some addons expose their own Sandbox settings too. For example, HARVEST has regeneration-speed tuning without turning that option into Search-speed acceleration.

Official addons

ATUM — attack reading, Soul Marks, Mind Gauge and RPS/Baseball/Racing wagers.

HARVEST — a shared colony of up to 500 units, Search Command and area control.

HEAVEN'S DOOR — open Books, spend REWRITE on commands, and control written-zombie behavior/jobs.

Simple rule: if everyone in the world needs the same value, look under Sandbox. If it is your own HUD, audio or aiming method, look under Client Options.
