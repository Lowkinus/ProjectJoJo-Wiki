PROJECT JOJO — FULL SYSTEM GUIDE

TARGETING MODES

Mouse / Pointer uses the cursor direction. Facing Direction uses where the character is facing. Controller Aim uses the controller attack/aim vector and falls back to facing when the stick is neutral.

Practical note: Changing the input does not change the combat rules. A wall is still a wall, and the first valid body in the line still matters.

DIRECTIONAL FIRST-CONTACT

Skills use their real maximum reach and check the attack line for the first valid contact. This keeps long moves from becoming short just because the cursor is close, while still preventing impossible target selection through bodies and obstacles.

Practical note: Example: aim a 5-tile Star Finger past a zombie standing 2 tiles away. The close zombie can take the hit first because it physically blocks the line.

BARRAGE CLASH

Supported offensive Barrages can collide when two players are close enough and genuinely aiming/facing into each other. Clash beats cancel each other before normal damage.

Practical note: Example: two players rush straight into each other; instead of both Barrages freely dealing every hit, matching hits can clash.

BARRAGE GUARD

Supported Barrages create a forward guard about 2.5 tiles wide in total. TW Knife, Silver Chariot Rapier Shot and Crazy Diamond Glass are directly supported, with vanilla firearm handling also integrated through the native hit path.

Practical note: Example: keep the projectile in front of your Barrage. Side/rear attacks, explosions, area fire and THREE FREEZE are not the same thing and are not blocked by this rule.

TIME STOP

Star Platinum stops time for 5 seconds; The World for 9. Frozen targets are pinned. Damage is saved and released when time resumes. Projectiles inside the stopped-time area pause and later continue.

Practical note: Example: a TW knife can be frozen in mid-flight. When time resumes it continues from where it stopped instead of teleporting to the target.

TIME STOP vs TIME ERASE

A full Time Stop cannot simply start on top of an active/pending Time Erase. If Erase existed first, the Stop spends its duration against the Erase time; only excess Stop time remains afterward.

Practical note: Think of it as two timers fighting each other, not both powers running fully at the same time.

SUMMONED STAND DEFENSE

While a registered Stand is summoned, its owner receives 33% less NET damage. The reduction is based on the real health/body-part loss after the game and other systems have already modified the hit.

Practical note: This is defense, not invulnerability. Heavy damage, multiple enemies and bad positioning can still kill you.

STAND LEVELS

Each Stand has separate Lv.1–100 progression. Lv.1 starts around 50% of the balanced level-scaled damage and Lv.100 reaches 100%. Stand-caused zombie kills grant EXP.

Practical note: Example: you can level The World, switch to Harvest, then return to The World later without losing The World progression.

VEHICLES & WORLD OBJECTS

Stand attacks respect world/vehicle collision. The current safety layer avoids rapidly corrupting vehicle durability/state while still allowing supported vanilla doors, windows, trees, barricades and thumpable objects to use their intended Stand interactions.

Practical note: If a custom map object is unknown, the safer default is to protect it rather than destroy an object the mod does not understand.

SERVER vs CLIENT SETTINGS

Sandbox settings control shared gameplay balance such as Arrow drops, Stand damage, levels, Arrow on Join, Infinite Stand Arrow and Super Arrow. Client options control targeting, HUD mode/scale/opacity, personal volume and keybinds.

Practical note: A player can hide their own HUD without changing the server’s drop rate or another player’s HUD.
