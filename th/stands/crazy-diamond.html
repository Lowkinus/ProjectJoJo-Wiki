CRAZY DIAMOND

Crazy Diamond ไม่ใช่ฮีลเลอร์ยืนหลังอย่างเดียว ต้องสู้ใน Attack Mode เพื่อเติม Restore แล้วค่อยเอาแต้มไปฮีล ซ่อม หรือใช้ Glass Homing

ปรับคู่มือตามไฟล์ล่าสุด • Core v0.23.0.280
ความยากสูง
Restore สูงสุด100
ฟื้นเอง0.01/วิ
ระยะ Glass9 ช่อง

RESTORE GAUGE

Max 100 • very slow passive refill

การฟื้นเองช้ามาก จุดประสงค์คือให้สู้เพื่อเติม Gauge โดย Punch, Rush และ Glass ที่โดนจริงจะช่วยเพิ่ม Restore

ตัวอย่าง: ถ้าใช้ Gauge ฮีลจนหมด ให้กลับ Attack Mode แล้วออกไปตีเพื่อเติม แทนการยืนรอฟื้นเองหลาย ๆ นาที

Skill 1 — DORAAA / RESTORE PUNCH

CD 0.37s • Range 2.8

Attack Mode ใช้ทำดาเมจและเติม Gauge ส่วน Restore Mode เปลี่ยนหมัดเป็นฮีลเป้าที่รองรับและหัก Gauge เมื่อฮีลสำเร็จจริง

ตัวอย่าง: ระหว่างไฟต์ใช้ Restore Punch ฮีลทีละก้อนจะควบคุม Gauge ง่ายกว่ารัว Restore Rush ยาว ๆ

Skill 2 — DORA RUSH / RESTORE RUSH

CD 5s • 17 / 25 hits

Attack Rush เป็นรัวหมัดโจมตีและมี Barrage Guard ส่วน Restore Rush เปลี่ยนเป็นฮีลหลายฮิตและไม่ใช้ Barrage Clash

ตัวอย่าง: ถ้ากำลังโดนมีด/โปรเจกไทล์กดดันและต้องการ Guard ให้อยู่ Attack Mode เพราะ Restore Rush ไม่ใช่เวอร์ชันปัดของ

Skill 3 — ATTACK / RESTORE

Instant toggle

สลับหน้าที่ของสกิล 1, 2 และ 4 — Attack ใช้สร้างทรัพยากร Restore ใช้ทรัพยากรเพื่อซัพพอร์ต

ตัวอย่าง: ฝึกดูโหมดก่อนกดสกิล 2 เพราะปุ่มเดียวกันอาจหมายถึง “ตี” หรือ “ฮีล” คนละเรื่องเลย

Skill 4 — GLASS SHOT / GLASS HOMING

CD 5.2s • Range 9

Attack Mode ยิงเศษแก้วและสร้าง Mark ส่วน Restore Mode ใช้ Restore ยิงแก้วที่พุ่งตรงช่วงแรกแล้วค่อยโค้งไปหา Mark กำแพง รถ และตัวอื่นยังขวางได้

ตัวอย่าง: ยิงทำ Mark ใส่ตัวถึกก่อน แล้วเปลี่ยนมุม สลับ Restore และยิง Homing เพื่อให้วิถีกลับเข้าหาเป้าจากมุมที่เดายากขึ้น
